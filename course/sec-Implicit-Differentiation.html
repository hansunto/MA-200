    Section Implicit Differentiation

    In the previous sections, we have focused on finding derivatives of functions that are explicitly defined as \(y = f(x)\text{.}\) However, there are many situations where we encounter equations that define \(y\) implicitly in terms of \(x\text{.}\) In this section, we will explore how to find the derivative of \(y\) with respect to \(x\) when \(y\) is defined implicitly.
    🔗

    Definition 172. Explicit and Implicit Functions.

    Functions that express one variable directly in terms of another variable are called explicit functions. For example, \(y = \sqrt{x^2-1}\) or \(y = \sin x\text{.}\)
    🔗
    Some functions are defined by a relation between \(x\) and \(y\) where neither variable is isolated; these are called implicit functions. For example, \(x^2 + y^2 = 1\) or \(xy + 3x^3 = y^2\text{.}\)
    🔗
    🔗
    Consider the equation of a circle centered at the origin with radius \(r\text{:}\)
    🔗
    \(x^2 + y^2 = r^2\)
    🔗
    In this case, \(y\) is not explicitly defined as a function of \(x\text{,}\) but we can still find \(\dfrac{dy}{dx}\) using implicit differentiation. To do this, we will differentiate both sides of the equation with respect to \(x\text{,}\) treating \(y\) as a function of \(x\) (i.e., \(y = y(x)\)).
    🔗

    Example 173.

    How many different functions are determined implicitly by the equation \(x^2+y^2=1\text{?}\)
    🔗
    Solution.
    The equation \(x^2+y^2=1\) represents a circle, which fails the vertical line test and is therefore not a single function. However, it implicitly defines infinitely many functions.
    🔗
    The two most common "continuous" functions determined by this relation are found by solving for \(y\text{:}\)
    \begin{equation*} y = \sqrt{1-x^2} \quad \text{and} \quad y = -\sqrt{1-x^2} \end{equation*}
    These represent the upper and lower semicircles, respectively.
    🔗
    🔗
    🔗

    Example 174.

    Given \(x^2+y^2=1\text{,}\) find \(\dfrac{dy}{dx}\) by differentiating explicitly.
    🔗
    Solution.
    First, we solve the equation for \(y\) to get an explicit function:
    \begin{equation*} y^2 = 1 - x^2 \implies y = \pm\sqrt{1-x^2} \end{equation*}
    🔗
    We choose the positive branch \(y = (1-x^2)^{1/2}\) and differentiate using the Chain Rule:
    \begin{equation*} \frac{dy}{dx} = \frac{1}{2}(1-x^2)^{-1/2} \cdot (-2x) \end{equation*}
    \begin{equation*} \frac{dy}{dx} = \frac{-x}{\sqrt{1-x^2}} \end{equation*}
    🔗
    Since \(y = \sqrt{1-x^2}\text{,}\) we can substitute \(y\) back in to see the relationship:
    \begin{equation*} \frac{dy}{dx} = -\frac{x}{y} \end{equation*}
    🔗
    🔗
    🔗
    If the equation
    \begin{equation*} y^3+3y-4x^2=5x+2 \end{equation*}
    determines an implicit function \(f\text{,}\) then
    \begin{equation*} [f(x)]^3+3f(x)-4x^2=5x+2 \end{equation*}
    for every \(x\) in the domain of \(f\text{.}\) However, there is no obvious way to solve for \(y\) in terms of \(x\) to obtain \(f(x)\text{.}\)
    🔗

    Remark 175.

    It is possible to state conditions under which an implicit function exists and is differentiable. In this section, we will assume that a given equation in \(x\) and \(y\) determines a differentiable function \(f\) such that if \(f(x)\) is substituted for \(y\text{,}\) the equation is an identity for every \(x\) in the domain of \(f\text{.}\)
    🔗
    🔗

    Definition 176. Implicit Differentiation (Extended Power Rule).

    The derivative of \(f\) can be found by the method of implicit differentiation, in which we differentiate each term of the equation with respect to \(x\text{.}\) This involves treating \(y\) as a function of \(x\) and applying the Chain Rule, specifically when computing
    \begin{equation*} \frac{d}{dx}y^n=ny^{n-1}\cdot\frac{d}{dx}y=ny^{n-1}\cdot\frac{dy}{dx} \end{equation*}
    for all integers \(n\text{.}\)
    🔗
    🔗
    To find the derivative of \(y\) with respect to \(x\text{,}\) we will differentiate both sides of the equation \(x^2 + y^2 = 1\) with respect to \(x\text{.}\) Applying the differentiation rules, we get:
    🔗
    \begin{equation*} \dfrac{d}{dx}(x^2) + \dfrac{d}{dx}(y^2) = \dfrac{d}{dx}(1) \end{equation*}
    🔗
    This simplifies to:
    \begin{equation*} 2x + 2y \dfrac{dy}{dx} = 0 \end{equation*}
    🔗
    Solving for \(\dfrac{dy}{dx}\text{,}\) we find:
    \begin{equation*} \dfrac{dy}{dx} = -\dfrac{x}{y} \end{equation*}
    🔗
    This result shows that the derivative of \(y\) with respect to \(x\) can be found even when \(y\) is defined implicitly; notice that the derivative depends on both \(x\) and \(y\text{.}\) This method yields the same result as differentiating explicitly in Example 174, but it is often more efficient and can be applied to complex equations where solving for \(y\) explicitly is difficult or impossible.
    🔗

    Method of Implicit Differentiation.

    1. Differentiate both sides of the equation with respect to x, treating \(y\) as a differentiable function of \(x\text{.}\)
      🔗
      🔗
    2. Collect all terms containing \(\dfrac{dy}{dx}\) on one side of the equation and move all other terms to the other side.
      🔗
      🔗
    3. Factor out \(\dfrac{dy}{dx}\) and solve for it.
      🔗
      🔗
    🔗
    🔗

    Example 177.

    Suppose \(x^2 y + 2y^2 - x = 3\text{.}\) Find \(\dfrac{dy}{dx}\text{.}\)
    🔗
    Solution.
    First, we differentiate each term with respect to \(x\text{.}\) Note that the first term requires the Product Rule and the second requires the Chain Rule:
    \begin{equation*} \frac{d}{dx}(x^2 y) = x^2 y' + 2xy \quad \text{and} \quad \frac{d}{dx}(2y^2) = 4y y' \end{equation*}
    🔗
    Differentiating the entire equation produces:
    \begin{equation*} x^2 y' + 2xy + 4y y' - 1 = 0 \end{equation*}
    🔗
    Collect the terms containing \(y'\) on the left and move the rest to the right:
    \begin{equation*} (x^2 + 4y) y' = 1 - 2xy \end{equation*}
    🔗
    Finally, solve for \(y'\) by dividing:
    \begin{equation*} y' = \frac{1 - 2xy}{x^2 + 4y} \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 178.

    If \(x^2+y^2=4\text{,}\) find \(\frac{dy}{dx}\text{.}\) Then, find an equation of the tangent line to the circle \(x^2+y^2=4\) at the point \((2,0)\text{.}\)
    🔗
    Solution.
    First, we find \(\dfrac{dy}{dx}\) using implicit differentiation:
    \begin{equation*} 2x + 2y \dfrac{dy}{dx} = 0 \implies \dfrac{dy}{dx} = -\dfrac{x}{y} \end{equation*}
    🔗
    Next, we evaluate the derivative at the point \((2,0)\) to find the slope \(m\text{:}\)
    \begin{equation*} m = -\dfrac{2}{0} \end{equation*}
    Since the derivative is undefined at this point, the tangent line is vertical.
    🔗
    The equation of a vertical line passing through \((2,0)\) is:
    \begin{equation*} x = 2 \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 179.

    Assuming that the equation \(y^4+3y-4x^3=5x+1\) determines, implicitly, a differentiable function \(f\) such that \(y=f(x)\text{,}\) find its derivative.
    🔗
    Solution.
    We differentiate both sides with respect to \(x\text{,}\) treating \(y\) as a function of \(x\text{:}\)
    \begin{equation*} 4y^3 \frac{dy}{dx} + 3 \frac{dy}{dx} - 12x^2 = 5 \end{equation*}
    🔗
    Collect the \(\frac{dy}{dx}\) terms and factor:
    \begin{equation*} \frac{dy}{dx}(4y^3 + 3) = 5 + 12x^2 \end{equation*}
    🔗
    Solve for \(\dfrac{dy}{dx}\text{:}\)
    \begin{equation*} \dfrac{dy}{dx} = \dfrac{12x^2 + 5}{4y^3 + 3} \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 180.

    Find the equation of the tangent line to the graph of
    \begin{equation*} y^4+3y-4x^3=5x+1 \end{equation*}
    at the point \((1,-2)\text{.}\)
    🔗
    Solution.
    Using the derivative found in Checkpoint 179, we evaluate the slope \(m\) at the point \((1, -2)\text{:}\)
    \begin{equation*} m = \dfrac{12(1)^2 + 5}{4(-2)^3 + 3} = \dfrac{17}{-32 + 3} = \dfrac{17}{-29} \end{equation*}
    🔗
    Using the point-slope form \(y - y_1 = m(x - x_1)\text{:}\)
    \begin{equation*} y - (-2) = -\dfrac{17}{29}(x - 1) \end{equation*}
    \begin{equation*} y + 2 = -\dfrac{17}{29}x + \dfrac{17}{29} \end{equation*}
    🔗
    The final equation of the tangent line is:
    \begin{equation*} y = -\dfrac{17}{29}x - \dfrac{41}{29} \end{equation*}
    🔗
    🔗
    🔗

    Exercises Implicit Differentiation Exercises

    1.

    Find \(y'\) if \(4xy^3-x^2y+x^3-5x+6=0\text{.}\)
    🔗
    Solution.
    Differentiating each term with respect to \(x\) (using the Product Rule on the first two terms):
    \begin{equation*} (4y^3 + 12xy^2 y') - (2xy + x^2 y') + 3x^2 - 5 = 0 \end{equation*}
    Group the \(y'\) terms:
    \begin{equation*} y'(12xy^2 - x^2) = 5 - 3x^2 - 4y^3 + 2xy \end{equation*}
    \begin{equation*} y' = \frac{5 - 3x^2 - 4y^3 + 2xy}{12xy^2 - x^2} \end{equation*}
    🔗
    🔗
    🔗

    2.

    Find \(y'\) if \(y=x^2\sin y\text{.}\)
    🔗
    Solution.
    Apply the Product Rule and Chain Rule:
    \begin{equation*} y' = 2x\sin y + x^2(\cos y \cdot y') \end{equation*}
    Isolate \(y'\text{:}\)
    \begin{equation*} y' - x^2\cos y \cdot y' = 2x\sin y \end{equation*}
    \begin{equation*} y'(1 - x^2\cos y) = 2x\sin y \implies y' = \frac{2x\sin y}{1 - x^2\cos y} \end{equation*}
    🔗
    🔗
    🔗

    3.

    For \(y^3+x^2y^5-x^4=27\text{:}\)
    🔗
    (a)
    Find \(dy/dx\) using implicit differentiation.
    🔗
    Solution.
    \begin{equation*} 3y^2 \frac{dy}{dx} + (2xy^5 + 5x^2y^4 \frac{dy}{dx}) - 4x^3 = 0 \end{equation*}
    \begin{equation*} \frac{dy}{dx}(3y^2 + 5x^2y^4) = 4x^3 - 2xy^5 \implies \frac{dy}{dx} = \frac{4x^3 - 2xy^5}{3y^2 + 5x^2y^4} \end{equation*}
    🔗
    🔗
    (b)
    Find the slope of the tangent line to the curve at the point \((0,3)\text{.}\)
    🔗
    Solution.
    Substitute \(x=0\) and \(y=3\) into the derivative found above:
    \begin{equation*} m = \frac{4(0)^3 - 2(0)(3)^5}{3(3)^2 + 5(0)^2(3)^4} = \frac{0}{27} = 0 \end{equation*}
    The slope of the tangent line is \(0\text{.}\)
    🔗
    🔗
    🔗
    🔗

    4.

    Find \(y'\) if \(x^2y^4+3y-4x^3=5\cos x-1\text{.}\)
    🔗
    Solution.
    \begin{equation*} (2xy^4 + 4x^2y^3 y') + 3y' - 12x^2 = -5\sin x \end{equation*}
    \begin{equation*} y'(4x^2y^3 + 3) = 12x^2 - 2xy^4 - 5\sin x \end{equation*}
    \begin{equation*} y' = \frac{12x^2 - 2xy^4 - 5\sin x}{4x^2y^3 + 3} \end{equation*}
    🔗
    🔗

    5.

    Find \(y''\) if \(y=\cos(x)+\cos(y)\text{.}\)
    🔗
    Solution.
    First derivative:
    🔗
    \begin{equation*} y' = -\sin x - (\sin y \cdot y') \implies y'(1 + \sin y) = -\sin x \implies y' = \frac{-\sin x}{1 + \sin y} \end{equation*}
    Second derivative (using Quotient Rule):
    🔗
    \begin{equation*} y'' = \frac{-\cos x(1 + \sin y) - (-\sin x)(\cos y \cdot y')}{(1 + \sin y)^2} \end{equation*}
    To finish, substitute the expression for \(y'\) back into this equation.
    🔗
