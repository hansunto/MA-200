    Section The Chain Rule

    In this section, we will explore the Chain Rule, a fundamental differentiation rule that allows us to find the derivative of composite functions. The Chain Rule is essential for differentiating a wide variety of functions, including those involving exponentials, logarithms, trigonometric functions, and more complex compositions.
    🔗

    Definition 153. Composed Function.

    The composed function \(f \circ g\text{,}\) the composition of \(f\) and \(g\text{,}\) is defined as
    \begin{equation*} f\circ g(x)=f(g(x)), \quad \text{or} \quad (f\circ g)(x)=f[g(x)]. \end{equation*}
    🔗
    🔗

    Checkpoint 154.

    For \(f(x)=x^3\) and \(g(x)=1+x^2\text{,}\) find \(f\circ g(x)\) and \(g\circ f(x)\text{.}\)
    🔗
    Solution.
    To find \(f\circ g(x)\text{,}\) we substitute \(g(x)\) into \(f\text{:}\)
    \begin{equation*} f(g(x)) = f(1+x^2) = (1+x^2)^3 \end{equation*}
    To find \(g\circ f(x)\text{,}\) we substitute \(f(x)\) into \(g\text{:}\)
    \begin{equation*} g(f(x)) = g(x^3) = 1+(x^3)^2 = 1+x^6 \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 155.

    For \(f(x)=\sqrt{x}\) and \(g(x)=x-1\text{,}\) find \(f\circ g(x)\) and \(g\circ f(x)\text{.}\)
    🔗
    Solution.
    To find \(f\circ g(x)\text{,}\) we substitute \(g(x)\) into \(f\text{:}\)
    \begin{equation*} f(g(x)) = f(x-1) = \sqrt{x-1} \end{equation*}
    To find \(g\circ f(x)\text{,}\) we substitute \(f(x)\) into \(g\text{:}\)
    \begin{equation*} g(f(x)) = g(\sqrt{x}) = \sqrt{x}-1 \end{equation*}
    🔗
    🔗
    🔗

    Subsection Extended Power Rule

    The extended power functions, such as \(f(x) = (3x^2 + 2)^5\text{,}\) can also be differentiated using the Chain Rule.
    🔗
    The extended power rule states that if \(g(x) = [f(x)]^n\text{,}\) where \(f\) is a differentiable function and \(n\) is a constant, then the derivative of \(g\) with respect to \(x\) is given by:
    \begin{equation*} g'(x) = n(f(x))^{n-1} \cdot f'(x) \end{equation*}
    🔗

    Theorem 156. Extended Power Rule.

    Suppose that \(f(x)\) is a function of \(x\text{,}\) then for any real number \(k\text{,}\)
    \begin{equation*} \frac{d}{dx}[f(x)]^k = k[f(x)]^{k-1} \cdot \frac{d}{dx}f(x). \end{equation*}
    🔗
    🔗
    The chain rule tells you how to handle compositions. Generally speaking, if a function \(f(x)\) is obtained "in two steps" as a composition of two simpler functions \(u(x)\) and \(g(u)\text{,}\) it is represented as
    \begin{equation*} f(x) = g(u)\text{,} \end{equation*}
    where
    \begin{equation*} u = u(x) \end{equation*}
    is a function of \(x\text{.}\) Then
    \begin{equation*} \dfrac{df}{dx}=\dfrac{df}{du} \cdot \dfrac{du}{dx} \end{equation*}
    🔗

    Example 157.

    Identify the inner function \(u\) and find the derivative for each expression.
    🔗
    (a)
    \(y = \sqrt{x^2+1}\)
    🔗
    Solution.
    Let the inner function be \(u = x^2+1\text{.}\) Then \(y = u^{1/2}\text{.}\)
    🔗
    Applying the Extended Power Rule:
    \begin{equation*} \frac{dy}{dx} = \frac{1}{2}(x^2+1)^{-1/2} \cdot \frac{d}{dx}(x^2+1) \end{equation*}
    \begin{equation*} \frac{dy}{dx} = \frac{1}{2}(x^2+1)^{-1/2} \cdot (2x) = \frac{x}{\sqrt{x^2+1}} \end{equation*}
    🔗
    🔗
    🔗
    (b)
    \(y = \dfrac{5}{(1+x^2)^2}\)
    🔗
    Solution.
    Let the inner function be \(u = 1+x^2\text{.}\) Then \(y = 5u^{-2}\text{.}\)
    🔗
    Applying the Extended Power Rule:
    \begin{equation*} \frac{dy}{dx} = 5(-2)(1+x^2)^{-3} \cdot \frac{d}{dx}(1+x^2) \end{equation*}
    \begin{equation*} \frac{dy}{dx} = -10(1+x^2)^{-3} \cdot (2x) = \frac{-20x}{(1+x^2)^3} \end{equation*}
    🔗
    🔗
    🔗
    (c)
    \(f(x) = \tan^2 x = (\tan x)^2\)
    🔗
    Solution.
    Let the inner function be \(u = \tan x\text{.}\) Then the expression is \(f(x) = u^2\text{.}\)
    🔗
    Applying the Extended Power Rule:
    \begin{equation*} f'(x) = 2(\tan x)^{1} \cdot \frac{d}{dx}(\tan x) \end{equation*}
    \begin{equation*} f'(x) = 2\tan x \cdot \sec^2 x \end{equation*}
    🔗
    🔗
    🔗
    🔗

    Checkpoint 158.

    Differentiate the following functions.
    🔗
    (a)
    \(f(x)=(1+x^3)^{1/2}\)
    🔗
    Solution.
    Using the Extended Power Rule with \(u = 1+x^3\text{:}\)
    \begin{equation*} f'(x) = \frac{1}{2}(1+x^3)^{-1/2} \cdot \frac{d}{dx}(1+x^3) \end{equation*}
    \begin{equation*} f'(x) = \frac{1}{2}(1+x^3)^{-1/2} \cdot (3x^2) = \frac{3x^2}{2\sqrt{1+x^3}} \end{equation*}
    🔗
    🔗
    🔗
    (b)
    \(y=(1-x^2)^3-(1-x^2)^2\)
    🔗
    Solution.
    Differentiate each term using the Extended Power Rule:
    \begin{equation*} y' = 3(1-x^2)^2(-2x) - 2(1-x^2)^1(-2x) \end{equation*}
    \begin{equation*} y' = -6x(1-x^2)^2 + 4x(1-x^2) \end{equation*}
    Factoring out \(-2x(1-x^2)\text{:}\)
    🔗
    \begin{equation*} y' = -2x(1-x^2)[3(1-x^2) - 2] = -2x(1-x^2)(1-3x^2) \end{equation*}
    🔗
    🔗
    🔗
    (c)
    \(f(x)=(x-5)^4(7-x)^{10}\)
    🔗
    Solution.
    Apply the Product Rule \((uv)' = u'v + uv'\text{:}\)
    \begin{equation*} f'(x) = \left[4(x-5)^3(1)\right](7-x)^{10} + (x-5)^4\left[10(7-x)^9(-1)\right] \end{equation*}
    \begin{equation*} f'(x) = 4(x-5)^3(7-x)^{10} - 10(x-5)^4(7-x)^9 \end{equation*}
    Factoring out the common terms \(2(x-5)^3(7-x)^9\text{:}\)
    🔗
    \begin{equation*} f'(x) = 2(x-5)^3(7-x)^9 [2(7-x) - 5(x-5)] \end{equation*}
    \begin{equation*} f'(x) = 2(x-5)^3(7-x)^9 [14 - 2x - 5x + 25] = 2(x-5)^3(7-x)^9(39-7x) \end{equation*}
    🔗
    🔗

    Subsection The Chain Rule

    The Chain Rule is a fundamental differentiation rule that allows us to find the derivative of composite functions. If we have a function defined as \(h(x) = f(g(x))\text{,}\) where \(f\) and \(g\) are differentiable functions, then the derivative of \(h\) with respect to \(x\) is given by:
    \begin{equation*} h'(x) = f'(g(x)) \cdot g'(x) \end{equation*}
    🔗

    Theorem 159. The Chain Rule.

    The derivative of the composition \(f\circ g\) is given by
    \begin{equation*} \frac{d}{dx}[f\circ g(x)] = \frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x). \end{equation*}
    Alternatively, suppose that \(y=f(u)\) and \(u=g(x)\text{,}\) then
    \begin{equation*} \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}. \end{equation*}
    🔗
    🔗
    In other words, to differentiate a composite function, we first differentiate the outer function \(f\) with respect to its argument \(g(x)\text{,}\) and then multiply by the derivative of the inner function \(g\) with respect to \(x\text{.}\)
    🔗
    The Chain Rule is essential for differentiating a wide variety of functions, including those involving exponentials, logarithms, trigonometric functions, and more complex compositions. It allows us to break down complicated functions into simpler parts, making differentiation more manageable.
    🔗
    For example, if we want to differentiate \(h(x) = \sin(x^2)\text{,}\) we can identify \(f(u) = \sin(u)\) and \(g(x) = x^2\text{.}\) Applying the Chain Rule, we get:
    \begin{align*} h'(x) \amp = \cos(x^2) \cdot 2x \end{align*}
    🔗

    Example 160.

    The function \(h(x) = (x^2 - 2x)^3\) is decomposed as \(f(g(x))\) with
    \begin{equation*} f(u) = u^3 \quad g(x) = x^2 - 2x. \end{equation*}
    🔗
    Derivatives:
    \begin{equation*} f'(u) = 3u^2 \quad g'(x) = 2x - 2. \end{equation*}
    🔗
    Derivative of \(h(x)\) by the chain rule:
    \begin{equation*} h'(x) = (3(x^2 - 2x)^2) (2x - 2). \end{equation*}
    🔗
    🔗

    Example 161.

    The function \(h(x) = \sin(2x)\) is decomposed as \(f(g(x))\) with
    \begin{equation*} f(u) = \sin u \quad g(x) = 2x. \end{equation*}
    🔗
    Derivatives:
    \begin{equation*} f'(u) = \cos u \quad g'(x) = 2. \end{equation*}
    🔗
    Derivative of \(h(x)\) by the chain rule:
    \begin{equation*} h'(x) = (\cos(2x)) (2)=2\cos 2x. \end{equation*}
    🔗
    🔗

    Example 162.

    The function \(h(x) = \sin^2(2x)\) is decomposed as \(f(g(x))\) with
    \begin{equation*} f(u) = \sin^2 u \quad g(x) = 2x. \end{equation*}
    🔗
    Derivatives:
    \begin{equation*} f'(u) = 2\sin u\cos u \quad g'(x) = 2. \end{equation*}
    🔗
    Derivative of \(h(x)\) by the chain rule:
    \begin{equation*} h'(x) = (2\sin(2x)\cos(2x)) (2)= 4\sin(2x)\cos(2x). \end{equation*}
    🔗
    🔗
    The Chain Rule is a powerful tool that extends our ability to differentiate beyond simple functions, enabling us to handle a wide range of mathematical models and applications in physics, engineering, economics, and other fields.
    🔗

    Example 163.

    \(f(x)=e^{2x}\)
    🔗
    Solution.
    To find the derivative of \(f(x) = e^{2x}\text{,}\) we can use the Chain Rule. Let \(u = 2x\text{,}\) so that \(f(x) = e^u\text{.}\) Then, we have:
    \begin{align*} f'(x) \amp = \frac{d}{dx}(e^u) \cdot \frac{du}{dx}\\ \amp = e^u \cdot 2\\ \amp = 2e^{2x} \end{align*}
    🔗
    🔗
    🔗

    Example 164.

    For \(y=2+\sqrt{u}\) and \(u=x^3+1\text{,}\) find \(\dfrac{dy}{dx}\text{.}\)
    🔗
    Solution.
    First, we find the individual derivatives:
    \begin{equation*} \frac{dy}{du} = \frac{1}{2}u^{-1/2} = \frac{1}{2\sqrt{u}} \quad \text{and} \quad \frac{du}{dx} = 3x^2 \end{equation*}
    🔗
    Using the Chain Rule \(\dfrac{dy}{dx} = \dfrac{dy}{du} \cdot \dfrac{du}{dx}\text{:}\)
    \begin{equation*} \dfrac{dy}{dx} = \left( \dfrac{1}{2\sqrt{u}} \right) (3x^2) \end{equation*}
    🔗
    Substitute \(u = x^3+1\) back into the expression:
    \begin{equation*} \dfrac{dy}{dx} = \dfrac{3x^2}{2\sqrt{x^3+1}} \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 165.

    Find functions \(f(x)\) and \(g(x)\) such that \(h(x)=f\circ g(x)\text{,}\) then differentiate:
    \begin{equation*} h(x)=(4x^3-7)^6 \end{equation*}
    🔗
    Solution.
    First, we decompose the function:
    • The "inner" function is \(g(x) = 4x^3 - 7\text{.}\)
      🔗
      🔗
    • The "outer" function is \(f(u) = u^6\text{.}\)
      🔗
      🔗
    🔗
    Next, we find the derivative using the Chain Rule:
    \begin{equation*} h'(x) = f'(g(x)) \cdot g'(x) \end{equation*}
    \begin{equation*} h'(x) = 6(4x^3-7)^5 \cdot (12x^2) \end{equation*}
    \begin{equation*} h'(x) = 72x^2(4x^3-7)^5 \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 166.

    Find the points on the graph of
    \begin{equation*} y = \cos 2x + 2\cos x \quad \text{for} \quad 0 \leq x \leq 2\pi \end{equation*}
    at which the tangent line is horizontal.
    🔗
    Solution.
    A tangent line is horizontal when the derivative is zero. First, we find \(\dfrac{dy}{dx}\) using the Chain Rule:
    \begin{equation*} \dfrac{dy}{dx} = -2\sin 2x - 2\sin x \end{equation*}
    🔗
    Set the derivative equal to zero and use the double-angle identity \(\sin 2x = 2\sin x \cos x\text{:}\)
    \begin{equation*} -2(2\sin x \cos x) - 2\sin x = 0 \end{equation*}
    \begin{equation*} -2\sin x (2\cos x + 1) = 0 \end{equation*}
    🔗
    This gives two cases for \(0 \leq x \leq 2\pi\text{:}\)
    • \(\displaystyle \sin x = 0 \implies x = 0, \pi, 2\pi\)
      🔗
      🔗
    • \(\displaystyle \cos x = -1/2 \implies x = 2\pi/3, 4\pi/3\)
      🔗
      🔗
    🔗
    Finally, we find the \(y\)-coordinates for these points:
    \begin{equation*} (0, 3), (\pi, -1), (2\pi, 3), (2\pi/3, -1.5), (4\pi/3, -1.5) \end{equation*}
    🔗

    Differentiate the following functions.

    1.

    \(y=\sqrt[3]{5x^2-x+4}\)
    🔗
    Solution.
    Rewrite as \(y = (5x^2-x+4)^{1/3}\text{.}\) By the Chain Rule:
    \begin{equation*} y' = \frac{1}{3}(5x^2-x+4)^{-2/3} \cdot (10x-1) = \frac{10x-1}{3\sqrt[3]{(5x^2-x+4)^2}} \end{equation*}

    \(r(x) = \dfrac{1}{(4x^2+6x-7)^3}\)

    \begin{equation*} r'(x) = -3(4x^2+6x-7)^{-4} \cdot (8x+6) = \frac{-6(4x+3)}{(4x^2+6x-7)^4} \end{equation*}
    🔗
    🔗
    🔗

    3.

    \(y=(2z+5)^3(3z-1)^4\)
    🔗

    \begin{equation*} y' = 6(2z+5)^2(3z-1)^3 [ (3z-1) + 2(2z+5) ] = 6(2z+5)^2(3z-1)^3(7z+9) \end{equation*}
    🔗
    🔗
    🔗

    \(f(w)=\cot^3(3w-1)\)

    14.

    \(f(x)=\dfrac{\sec 2x}{1+\tan 2x}\)

    🔗
    🔗
    🔗

    \(y = \sin \sqrt{x}+\cos \sqrt{x}\)

    Subsection Higher Order Derivatives

    Definition 167. Higher-Order Derivatives.

    The second derivative of \(f\) is denoted by \(f''\) and is defined as
    \begin{equation*} f''(x) = \frac{d}{dx}f'(x). \end{equation*}
    🔗
    🔗

    Example 168.

    For \(y=1/x\text{,}\) find \(\dfrac{d^2y}{dx^2}\text{.}\)
    🔗
    Solution.
    First, rewrite the function as a power:
    \begin{equation*} y = x^{-1} \end{equation*}
    🔗
    Find the first derivative:
    \begin{equation*} \frac{dy}{dx} = -1x^{-2} = -\frac{1}{x^2} \end{equation*}
    🔗
    Differentiate again to find the second derivative:
    \begin{equation*} \frac{d^2y}{dx^2} = \frac{d}{dx}(-x^{-2}) = 2x^{-3} = \frac{2}{x^3} \end{equation*}
