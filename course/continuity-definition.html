    Section Continuity

    In this section, we will discuss the concept of continuity and how it relates to limits and derivatives.
    🔗

    Insight 35.

    The limit at a number \(a\) does not depend on the function value at \(a\text{,}\) even if that value, \(f(a)\text{,}\) exists. That is, whether or not a limit exists at \(a\) has nothing to do with the function value \(f(a)\text{.}\)
    🔗
    🔗

    Continuity at a point.

    When the limit of a function is the same as its function value, it satisfies a condition called continuity at a point. Continuous functions do not have “jumps” or “holes” in their graphs.
    🔗
    🔗

    Definition 36. Continuity at a Point.

    A function \(f\) is said to be continuous at a point \(x = a\) if the following three conditions are satisfied:
    1. The function \(f\) is defined at \(x = a\) (i.e., \(f(a)\) exists).
      🔗
      🔗
    2. The limit of \(f(x)\) as \(x\) approaches \(a\) exists (i.e., \(\lim_{x \to a} f(x)\) exists).
      🔗
      🔗
    3. The limit of the function equals the function value: \(\lim_{x \to a} f(x) = f(a)\text{.}\)
      🔗
      🔗
    🔗
    A function is continuous over an interval I if it is continuous at each point in I.
    🔗
    🔗
    If a function is continuous at every point in its domain, we say that the function is continuous on its domain.
    🔗
    There are three types of discontinuous functions which are removable, jump and infinite discontinuous. Roughly speaking, we say that a function \(f(x)\) is continuous at \(x = a\) if its graph has no breaks and passes through the point \((a,f(a))\text{.}\)
    🔗

    Example 37.

    Let \(f\) be defined as:
    \begin{equation*} f(x) = \begin{cases} 4x+1 \amp \text{for } 0 \lt x \lt 1 \\ x^2+4 \amp \text{for } 1 \lt x \lt 2 \end{cases} \end{equation*}
    🔗
    Solution.
    We evaluate the one-sided limits as \(x\) approaches \(1\text{:}\)
    \begin{equation*} \lim_{x \to 1^-} f(x) = 5 \quad \text{and} \quad \lim_{x \to 1^+} f(x) = 5 \end{equation*}
    Therefore, \(f\) would be continuous at \(x = 1\) if we define \(f(1) = 5\text{.}\)
    🔗
    🔗
    🔗

    Example 38.

    Let \(f\) be defined as:
    \begin{equation*} f(x) = \begin{cases} x^2 - \frac{1}{2} \amp \text{where } x \in [-2,-1] \\ x + 2 \amp \text{where } x \in (-1,1) \end{cases} \end{equation*}
    🔗
    This function is defined on the interval \([-2,1)\text{,}\) which is the union of the intervals \([-2,-1]\) and \((-1,1)\text{.}\)
    🔗
    Solution.
    The point \(-2\) is a point of continuity because the limit \(\lim_{x \to -2^+} f(x)\) exists (as a one-sided limit) and is equal to \(3.5\) (or \(7/2\)), which is also the value of the function:
    \begin{equation*} \lim_{x \to -2} f(x) = f(-2) \end{equation*}
    🔗
    The function is also continuous at any point in the open intervals \((-2,-1)\) and \((-1,1)\text{.}\) However, at the point \(x = -1\text{,}\) the function is not continuous because the two-sided limit does not exist. While the one-sided limits exist:
    \begin{equation*} \lim_{x \to -1^+} f(x) = 1 \quad \text{and} \quad \lim_{x \to -1^-} f(x) = \frac{1}{2} \end{equation*}
    they are different, so the limit \(\lim_{x \to -1} f(x)\) does not exist.
    🔗
    Since the function is not defined at \(x = 1\text{,}\) it does not make sense to discuss continuity there; \(\lim_{x \to 1^-} f(x)\) exists, but it cannot be compared to an undefined \(f(1)\text{.}\) Thus, the function has exactly one discontinuity at \(x = -1\) and is continuous elsewhere on its domain.
    🔗
    🔗
    🔗

    Example 39. Absolute Value function Continuity.

    Show that the function \(f(x) = |x|\) is continuous at every value \(c\) in its domain.
    🔗
    Solution.
    Recall that the absolute value function is defined piecewise as:
    \begin{equation*} f(x) = \begin{cases} x \amp \text{if } x \ge 0 \\ -x \amp \text{if } x \lt 0 \end{cases} \end{equation*}
    🔗
    We consider three cases for a real number \(c\text{:}\)
    🔗
    1. If \(c \gt 0\text{,}\) then for values of \(x\) sufficiently close to \(c\text{,}\) \(f(x) = x\text{.}\) Since \(\lim_{x \to c} x = c\text{,}\) we have \(\lim_{x \to c} f(x) = f(c)\text{.}\)
      🔗
      🔗
    2. If \(c \lt 0\text{,}\) then for values of \(x\) sufficiently close to \(c\text{,}\) \(f(x) = -x\text{.}\) Since \(\lim_{x \to c} (-x) = -c\text{,}\) we have \(\lim_{x \to c} f(x) = f(c)\text{.}\)
      🔗
      🔗
    3. If \(c = 0\text{,}\) we check the one-sided limits:
      • \(\displaystyle \lim_{x \to 0^+} f(x) = \lim_{x \to 0^+} x = 0\)
        🔗
        🔗
      • \(\displaystyle \lim_{x \to 0^-} f(x) = \lim_{x \to 0^-} (-x) = 0\)
        🔗
        🔗
      Since the left and right limits are equal, \(\lim_{x \to 0} f(x) = 0\text{.}\) Since \(f(0) = 0\text{,}\) the function is continuous at \(x = 0\text{.}\)
      🔗
      🔗
    🔗
    Therefore, \(f(x) = |x|\) is continuous for all \(x\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 42. Continuity at Specific Points.

    (a)

    \(f(x) = 2x + 3\) at \(x = 3\text{.}\)
    🔗
    Solution.
    Since \(f(x)\) is a polynomial, it is continuous everywhere. Specifically, \(\lim_{x \to 3} (2x+3) = 2(3)+3 = 9\text{.}\) Since \(f(3) = 9\text{,}\) the function is continuous at \(x=3\text{.}\)
    🔗
    🔗
    🔗

    (b)

    \(g(x) = \frac{x^2+x-2}{x-1}\) at \(x = 1\text{.}\)
    🔗
    Solution.
    The function \(g(x)\) is not defined at \(x = 1\) because the denominator becomes zero. Since \(g(1)\) does not exist, the function is not continuous at \(x = 1\text{.}\) (Note: There is a removable discontinuity at this point).
    🔗
    🔗
    🔗

    (c)

    The greatest integer function \(f(x) = \lfloor x \rfloor\) at integer points.
    🔗
    Solution.
    Let \(n\) be an integer. As \(x \to n^-\text{,}\) \(f(x) = n-1\text{,}\) so \(\lim_{x \to n^-} \lfloor x \rfloor = n-1\text{.}\) As \(x \to n^+\text{,}\) \(f(x) = n\text{,}\) so \(\lim_{x \to n^+} \lfloor x \rfloor = n\text{.}\) Since the one-sided limits are not equal, the limit does not exist, and the function is not continuous at any integer point.
    🔗
    🔗
    🔗
    🔗

    Theorem 43. Continuity Principles.

    The following principles describe the continuity of various functions:
    🔗
    1. Any constant function is continuous.
      🔗
      🔗
    2. Any polynomial function is continuous.
      🔗
      🔗
    3. Trigonometric functions and their inverse trigonometric functions (such as \(\sin\text{,}\) \(\cos\text{,}\) and \(\tan\)) are continuous on their domains.
      🔗
      🔗
    4. Exponential functions and logarithmic functions are continuous on their domains.
      🔗
      🔗
    5. For any positive integer \(n\) and any continuous function \(f\text{,}\) the functions \([f(x)]^n\) and \(\sqrt[n]{f(x)}\) are continuous. When \(n\) is even, the domain of \(\sqrt[n]{f(x)}\) is restricted to values of \(x\) for which \(f(x) \geq 0\text{.}\)
      🔗
      🔗
    6. If \(f(x)\) and \(g(x)\) are continuous, then their sum \(f(x) + g(x)\text{,}\) difference \(f(x) - g(x)\text{,}\) and product \(f(x) \cdot g(x)\) are also continuous.
      🔗
      🔗
    7. If \(f(x)\) and \(g(x)\) are continuous, then the quotient \(\frac{g(x)}{f(x)}\) is continuous for all \(x\) such that \(f(x) \neq 0\text{.}\)
      🔗
      🔗
    8. If \(g(x)\) is continuous at \(x=c\) with \(\lim_{x \to c} g(x) = b\text{,}\) and \(f(x)\) is continuous at \(x=b\text{,}\) then the composite function \((f \circ g)(x) = f(g(x))\) is continuous at \(x=c\text{.}\) That is:
      \begin{equation*} \lim_{x \to c} (f \circ g)(x) = f(b) = f\left( \lim_{x \to c} g(x) \right) \end{equation*}
      In fact, if \(g\) is continuous at \(c\) and \(f\) is continuous at \(g(c)\text{,}\) then the composite function \(f \circ g\) is continuous at \(x=c\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 44.

    Find the following limit:
    \begin{equation*} \lim_{x \to \pi} \cos\left(2x + \frac{3x}{2}\right) \end{equation*}
    🔗
    Solution.
    Since the cosine function and the linear terms inside the parentheses are continuous, we can evaluate the limit by direct substitution:
    \begin{align*} \lim_{x \to \pi} \cos\left(2x + \frac{3x}{2}\right) \amp = \cos\left(2\pi + \frac{3\pi}{2}\right)\\ \amp = \cos\left(\frac{7\pi}{2}\right)\\ \amp = 0 \end{align*}
    🔗
    🔗
    🔗

    Example 45.

    Provide an argument to show that \(f(x) = x^2 - 3x + 2\) is continuous.
    🔗
    Solution.
    The function \(f(x) = x^2 - 3x + 2\) is a polynomial. According to the Continuity Principles, any polynomial function is continuous for all real numbers.
    🔗
    Alternatively, we can observe that \(f(x)\) is formed by the sum and difference of the power functions \(x^2\text{,}\) \(3x\text{,}\) and the constant \(2\text{.}\) Since each of these individual terms is continuous, their sum \(f(x)\) must also be continuous at every value of \(x\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 46.

    (a)

    Show that the rational function
    \begin{equation*} r(x)=\frac{x^4-5x^3+x^2-7}{x-3} \end{equation*}
    is continuous for all values except \(x=3\text{.}\)
    🔗
    Solution.
    The function \(r(x)\) is a rational function, which is the quotient of two polynomials. According to the Theorem 43, a rational function is continuous at all points in its domain.
    🔗
    The domain of \(r(x)\) consists of all real numbers where the denominator is non-zero. Since \(x-3 = 0\) only when \(x=3\text{,}\) the function is continuous for all \(x \neq 3\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Show that \(f(x)=|x|\) is continuous everywhere (at every real number \(c\)).
    🔗
    Solution.
    Recall that \(f(x) = \sqrt{x^2}\text{.}\) Since the power function \(g(x) = x^2\) is a polynomial and therefore continuous, and the square root function \(h(x) = \sqrt{x}\) is continuous for all \(x \geq 0\text{,}\) their composition \(h(g(x))\) is continuous.
    🔗
    Alternatively, for any real number \(c\text{,}\) we can show that \(\lim_{x \to c} |x| = |c|\) by considering cases for\(c\gt 0 \text{,}\) \(c\lt 0\text{,}\) and \(c = 0\) using one-sided limits. Since the limit always equals the function value, \(f(x) = |x|\) is continuous at every real number \(c\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Checkpoint 47.

    Show that
    \begin{equation*} \lim_{x \to 1} \arcsin\left(\frac{1-\sqrt{x}}{1-x}\right) = \frac{\pi}{6} \end{equation*}
    🔗
    Solution.
    First, we simplify the rational expression inside the arcsine. Notice that the denominator can be factored as a difference of squares: \(1 - x = (1 - \sqrt{x})(1 + \sqrt{x})\text{.}\)
    🔗
    For \(x \neq 1\text{,}\) we have:
    \begin{equation*} \frac{1 - \sqrt{x}}{1 - x} = \frac{1 - \sqrt{x}}{(1 - \sqrt{x})(1 + \sqrt{x})} = \frac{1}{1 + \sqrt{x}} \end{equation*}
    🔗
    Now, we apply the limit inside the function, justified by the continuity of the \(\arcsin\) function:
    \begin{align*} \lim_{x \to 1} \arcsin\left(\frac{1 - \sqrt{x}}{1 - x}\right) \amp = \arcsin\left(\lim_{x \to 1} \frac{1}{1 + \sqrt{x}}\right)\\ \amp = \arcsin\left(\frac{1}{1 + \sqrt{1}}\right)\\ \amp = \arcsin\left(\frac{1}{2}\right)\\ \amp = \frac{\pi}{6} \end{align*}
    🔗
    🔗
    🔗

    Checkpoint 48.

    Show that \(f\) is continuous on \((-\infty, \infty)\) where
    \begin{equation*} f(x) = \begin{cases} \sin x \amp \text{if } x \lt \pi/4 \\ \cos x \amp \text{if } x \geq \pi/4 \end{cases} \end{equation*}
    🔗
    Solution.
    We check the continuity of \(f\) by examining the two pieces and the transition point:
    🔗
    • For \(x \lt \pi/4\text{,}\) \(f(x) = \sin x\text{.}\) Since the sine function is continuous everywhere, \(f\) is continuous on the interval \((-\infty, \pi/4)\text{.}\)
      🔗
      🔗
    • For \(x \gt \pi/4\text{,}\) \(f(x) = \cos x\text{.}\) Since the cosine function is continuous everywhere, \(f\) is continuous on the interval \((\pi/4, \infty)\text{.}\)
      🔗
      🔗
    • At \(x = \pi/4\text{,}\) we check the one-sided limits and the function value:
      • \(\displaystyle \lim_{x \to (\pi/4)^-} f(x) = \lim_{x \to (\pi/4)^-} \sin x = \sin(\pi/4) = \frac{\sqrt{2}}{2}\)
        🔗
        🔗
      • \(\displaystyle \lim_{x \to (\pi/4)^+} f(x) = \lim_{x \to (\pi/4)^+} \cos x = \cos(\pi/4) = \frac{\sqrt{2}}{2}\)
        🔗
        🔗
      • \(\displaystyle f(\pi/4) = \cos(\pi/4) = \frac{\sqrt{2}}{2}\)
        🔗
        🔗
      Since \(\lim_{x \to \pi/4} f(x) = f(\pi/4)\text{,}\) the function is continuous at \(x = \pi/4\text{.}\)
      🔗
      🔗
    Therefore, \(f\) is continuous on \((-\infty, \infty)\text{.}\)
    🔗
    🔗

    Checkpoint 49.

    (a)

    \(f(x) = \sin(x^2)\)
    🔗
    Solution.
    The function \(f(x)\) is the composition of the sine function and the polynomial function \(x^2\text{.}\) Since both \(\sin(x)\) and \(x^2\) are continuous on \((-\infty, \infty)\text{,}\) their composition is also continuous everywhere.
    🔗
    🔗
    🔗

    (b)

    \(F(x) = \ln(1 + \cos x)\)
    🔗
    Solution.
    The function \(F(x)\) is continuous wherever its component parts are continuous and the argument of the logarithm is positive. The functions \(\cos x\) and \(1 + \cos x\) are continuous for all real numbers. However, \(\ln(u)\) is only continuous for \(u \gt 0\text{.}\)
    🔗
    We must have \(1 + \cos x \gt 0\text{,}\) which means \(\cos x \neq -1\text{.}\) This occurs when \(x\) is not an odd multiple of \(\pi\text{.}\) Therefore, \(F(x)\) is continuous on its domain:
    \begin{equation*} \{x \in \mathbb{R} \mid x \neq (2n+1)\pi, n \in \mathbb{Z}\}\text{.} \end{equation*}
    🔗
    🔗
    🔗
    🔗

    Checkpoint 50.

    (a)

    If the product function \(f(x) = g(x) \cdot h(x)\) is continuous at \(x = 0\text{,}\) must \(g(x)\) and \(h(x)\) be continuous at \(x = 0\text{?}\) Give reasons for your answer.
    🔗
    Solution.
    No, \(g(x)\) and \(h(x)\) do not need to be continuous at \(x = 0\text{.}\)
    🔗
    For example, consider \(g(x) = \begin{cases} 1 \amp x \neq 0 \\ 0 \amp x = 0 \end{cases}\) and \(h(x) = x\text{.}\) Here, \(g(x)\) is discontinuous at \(x = 0\text{,}\) but the product \(f(x) = g(x) \cdot h(x)\) is:
    \begin{equation*} f(x) = \begin{cases} x \amp x \neq 0 \\ 0 \amp x = 0 \end{cases} \end{equation*}
    which simplifies to \(f(x) = x\) for all \(x\text{.}\) Since \(f(x) = x\) is a polynomial, it is continuous at \(x = 0\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Give an example of functions \(f\) and \(g\text{,}\) both continuous at \(x = 0\text{,}\) for which the composite \(f \circ g\) is discontinuous at \(x = 0\text{.}\) Does this contradict the Continuity Principles theorem? Give reasons for your answer.
    🔗
    Solution.
    This is actually impossible. If \(g\) is continuous at \(x = 0\) and \(f\) is continuous at \(g(0)\text{,}\) then the composition \(f \circ g\) must be continuous at \(x = 0\text{.}\)
    🔗
    The confusion often arises if \(f\) is continuous at \(x = 0\) but not continuous at the value \(g(0)\text{.}\) For example, let \(g(x) = 1\) (constant) and \(f(x) = \begin{cases} 0 \amp x \neq 1 \\ 5 \amp x = 1 \end{cases}\text{.}\) Both are continuous at \(x = 0\text{,}\) but \(f(g(x)) = f(1) = 5\) for all \(x\text{,}\) which is actually continuous.
    🔗
    It does not contradict Theorem 43 because the theorem specifically requires \(f\) to be continuous at the output of \(g\) (i.e., at \(b = g(c)\)), not just at the same point \(c\text{.}\)
    🔗
    🔗
    🔗
