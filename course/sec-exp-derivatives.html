    Section 2.3 Derivatives of Exponential Functions

    Definition 144. Exponential Function.

    The exponential function \(f\) with base \(a\) is defined by
    \begin{equation*} f(x)=a^x \quad \text{or} \quad y=a^x \end{equation*}
    where \(a\) is a positive constant other than 1 (\(a \gt 0\) and \(a \neq 1\)) and \(x\) is any real number.
    🔗
    🔗
    In this section, we explore the derivatives of both the natural exponential function and general exponential functions. The natural exponential function, \(e^x\text{,}\) is unique because it is its own derivative:
    \begin{equation*} \frac{d}{dx} e^x = e^x. \end{equation*}
    🔗
    For a general exponential function \(a^x\) (where \(a \gt 0\) and \(a \neq 1\)), the derivative involves a scaling factor of the natural logarithm of the base:
    \begin{equation*} \frac{d}{dx} a^x = a^x \ln(a). \end{equation*}
    🔗
    This formula shows that the growth rate of an exponential function is proportional to the function itself. The constant of proportionality, \(\ln(a)\text{,}\) arises from the relationship between general bases and the natural base \(e\text{.}\)
    🔗
    Understanding these derivatives is essential for modeling real-world phenomena such as population growth, radioactive decay, and compound interest, where the rate of change depends directly on the current quantity.
    🔗

    Definition 145. The Natural Exponential Function.

    The irrational number \(e\text{,}\) approximately \(2.71828\text{,}\) is called the natural base. The number \(e\) is defined as the value that \((1+1/n)^n\) approaches as \(n\) increases without bound:
    \begin{equation*} \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e^1 = e. \end{equation*}
    The function \(f(x)=e^x\) is called the natural exponential function.
    🔗
    🔗
    Since \(2 \lt e \lt 3\text{,}\) the graph of the natural exponential function lies between the graphs of \(2^x\) and \(3^x\text{.}\)
    🔗

    Example 146.

    Find the derivative of \(f(x)=a^x\text{.}\)
    🔗
    Solution.
    Using the limit definition of the derivative:
    \begin{equation*} \frac{d}{dx}(a^x) = \left(\lim_{h\to 0}\frac{a^h-1}{h}\right) \cdot a^x \end{equation*}
    🔗
    Assuming the limit exists, this means that the derivative of \(a^x\) is equal to some constant times \(a^x\text{.}\) This constant varies depending on the value of the base \(a\text{.}\)
    🔗
    Specifically, when \(a=e\text{,}\) the value of this limit is exactly \(1\text{.}\)
    🔗
    🔗
    🔗

    Derivative of the Natural Exponential Function.

    \begin{equation*} \frac{d}{dx}(e^x) = e^x \end{equation*}
    🔗
    🔗

    Example 147.

    Find the derivative of \(f(x)=e^{2x}\text{.}\)
    🔗
    Solution.
    Using the chain rule with the fact that \(\frac{d}{dx}(e^u) = e^u \frac{du}{dx}\text{,}\) where \(u = 2x\text{:}\)
    \begin{equation*} f'(x) = e^{2x} \cdot \frac{d}{dx}(2x) = 2e^{2x} \end{equation*}
    🔗
    🔗
    🔗

    Example 148.

    \(f(x)=e^{-x}\)
    🔗
    Solution.
    Similarly, using the chain rule where \(u = -x\text{:}\)
    \begin{equation*} f'(x) = e^{-x} \cdot \frac{d}{dx}(-x) = -e^{-x} \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 149.

    Find the derivatives of the following functions.
    🔗

    (a)

    \(f(x)=xe^{-x}\)
    🔗
    Solution.
    Using the Product Rule \((uv)' = u'v + uv'\) with \(u=x\) and \(v=e^{-x}\text{:}\)
    \begin{align*} f'(x) \amp = (1)(e^{-x}) + (x)(-e^{-x})\\ \amp = e^{-x} - xe^{-x}\\ \amp = e^{-x}(1-x) \end{align*}
    🔗
    🔗
    🔗

    (b)

    \(f(x)=x^{-3/5}+\pi^{3/2}\)
    🔗
    Solution.
    Note that \(\pi^{3/2}\) is a constant, so its derivative is zero. Applying the Power Rule to the first term:
    \begin{equation*} f'(x) = -\frac{3}{5}x^{-3/5 - 1} + 0 = -\frac{3}{5}x^{-8/5} \end{equation*}
    🔗
    🔗
    🔗

    (c)

    \(z=2t^{2/3}+3e^{2t}\)
    🔗
    Solution.
    Differentiating each term separately:
    \begin{align*} \frac{dz}{dt} \amp = 2\left(\frac{2}{3}t^{-1/3}\right) + 3(2e^{2t})\\ \amp = \frac{4}{3}t^{-1/3} + 6e^{2t} \end{align*}
    🔗
    🔗
    🔗
    🔗

    Checkpoint 150.

    Find the limits:
    🔗

    (a)

    \(\displaystyle\lim_{x\to\infty} e^{-x}\sin x\)
    🔗
    Solution.
    Note that \(e^{-x} \to 0\) as \(x \to \infty\) and \(\sin x\) is bounded between \(-1\) and \(1\text{.}\) By the Squeeze Theorem, since \(-e^{-x} \le e^{-x}\sin x \le e^{-x}\text{,}\) the limit is \(0\text{.}\)
    🔗
    🔗
    🔗

    (b)

    \(\displaystyle\lim_{x\to\infty} \frac{e^{x}-e^{-x}}{e^x+e^{-x}}\)
    🔗
    Solution.
    Multiply the numerator and denominator by \(e^{-x}\text{:}\)
    \begin{equation*} \lim_{x\to\infty} \frac{1 - e^{-2x}}{1 + e^{-2x}} = \frac{1 - 0}{1 + 0} = 1 \end{equation*}
    🔗
    🔗
    🔗
    🔗

    Checkpoint 151.

    Find an equation for a line that is tangent to the curve \(y=e^x\) and goes through \(x=0\text{.}\)
    🔗
    Solution.
    To find the equation of the tangent line, we need a point and a slope:
    1. Point: When \(x=0\text{,}\) \(y=e^0=1\text{.}\) So the point is \((0,1)\text{.}\)
      🔗
      🔗
    2. Slope: The derivative is \(y' = e^x\text{.}\) Evaluating at \(x=0\text{,}\) the slope is \(m = e^0 = 1\text{.}\)
      🔗
      🔗
    Using the point-slope form \(y - y_1 = m(x - x_1)\text{:}\)
    \begin{equation*} y - 1 = 1(x - 0) \implies y = x + 1 \end{equation*}
    🔗
    🔗
    🔗
