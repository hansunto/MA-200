    Section 2.1 Differentiation Rules

    In this section, we will learn some rules for computing derivatives of functions.
    🔗
    We will start with the constant rule, which states that the derivative of a constant function is zero. Then we will learn the power rule, which allows us to compute the derivative of a function of the form \(f(x) = x^n\) for any real number \(n.\) Finally, we will learn the sum rule, which states that the derivative of a sum of functions is the sum of their derivatives.
    🔗
    These rules will allow us to compute derivatives of many different types of functions, and they will be essential tools for solving problems in calculus.
    🔗

    Theorem 106. The Power Rule.

    For any real number \(n\text{,}\)
    \begin{equation*} \frac{d}{dx}x^n = n \cdot x^{n-1}. \end{equation*}
    🔗
    🔗

    Example 107.

    Find \(\dfrac{dy}{dx}\) if
    1. \(\displaystyle y=x^5\)
      🔗
      🔗
    2. \(\displaystyle y=x\)
      🔗
      🔗
    3. \(\displaystyle y=\frac{1}{x}\)
      🔗
      🔗
    4. \(\displaystyle \sqrt{x}\)
      🔗
      🔗
    5. \(\displaystyle x^{-2/3}\)
      🔗
      🔗
    6. \(\displaystyle y=2.349\)
      🔗
      🔗
    7. \(\displaystyle y=\pi^2\)
      🔗
      🔗
    🔗
    Solution.
    Applying the Power Rule:
    1. \(\displaystyle \dfrac{dy}{dx} = 5x^4\)
      🔗
      🔗
    2. \(\displaystyle \dfrac{dy}{dx} = 1\)
      🔗
      🔗
    3. \(\displaystyle \dfrac{dy}{dx} = -x^{-2} = -\dfrac{1}{x^2}\)
      🔗
      🔗
    4. \(\displaystyle \dfrac{d}{dx}[x^{1/2}] = \dfrac{1}{2}x^{-1/2} = \dfrac{1}{2\sqrt{x}}\)
      🔗
      🔗
    5. \(\displaystyle \dfrac{d}{dx}[x^{-2/3}] = -\dfrac{2}{3}x^{-5/3}\)
      🔗
      🔗
    6. \(\dfrac{dy}{dx} = 0\) (constant rule)
      🔗
      🔗
    7. \(\dfrac{dy}{dx} = 0\) (constant rule)
      🔗
      🔗
    🔗
    🔗
    🔗

    Theorem 108.

    The derivative of a constant function is 0. That is,
    \begin{equation*} \frac{d}{dx}c=0. \end{equation*}
    🔗
    🔗

    Theorem 109.

    The derivative of a linear function is \(m\text{.}\)
    \begin{equation*} \frac{d}{dx}(mx+b)=m. \end{equation*}
    🔗
    🔗

    Subsection Techniques of Differentiation

    In the previous section, we learned some basic rules for computing derivatives of functions. In this section, we will learn some techniques for computing derivatives of more complicated functions.
    🔗

    Theorem 110.

    The derivative of a constant times a function is the constant times the derivative of the function. Using derivative notation, we can write this as
    \begin{equation*} \frac{d}{dx}[c \cdot f(x)] = c \cdot \frac{d}{dx}f(x). \end{equation*}
    🔗
    🔗
    Here are some examples with integer exponents:
    🔗
    1. Let \(f(x) = -7x^4.\) Then \(f'(x) = -7 \cdot 4x^{(4-1)} = -28x^3\)
      🔗
      🔗
    2. Let \(g(t) = 3t^{-2}.\) Then \(g'(t) = 3 \cdot (-2)t^{(-2-1)} = -6t^{-3}\)
      🔗
      🔗
    🔗

    Example 111.

    Find \(\dfrac{dy}{dx}\) if
    1. \(\displaystyle y=5x^4\)
      🔗
      🔗
    2. \(\displaystyle y=\dfrac{-4}{x^2}\)
      🔗
      🔗
    3. \(\displaystyle y=-x^{0.7}\)
      🔗
      🔗
    🔗
    Solution.
    1. \(\displaystyle \dfrac{dy}{dx} = 5(4x^3) = 20x^3\)
      🔗
      🔗
    2. Rewrite as \(y = -4x^{-2}\text{.}\) Then \(\dfrac{dy}{dx} = -4(-2x^{-3}) = 8x^{-3} = \dfrac{8}{x^3}\)
      🔗
      🔗
    3. \(\displaystyle \dfrac{dy}{dx} = -0.7x^{-0.3} = -\dfrac{0.7}{x^{0.3}}\)
      🔗
      🔗
    🔗
    🔗
    🔗

    Theorem 112. The Sum-Difference Rule.

    The derivative of a sum is the sum of the derivatives;
    \begin{equation*} \frac{d}{dx}[f(x)+g(x)] = \frac{d}{dx}f(x) + \frac{d}{dx}g(x). \end{equation*}
    The derivative of a difference is the difference of the derivatives;
    \begin{equation*} \frac{d}{dx}[f(x)-g(x)] = \frac{d}{dx}f(x) - \frac{d}{dx}g(x). \end{equation*}
    🔗
    🔗
    Let \(y\) be the polynomial
    \begin{equation*} y = 2x^5 + (1/3)x^2 - 1.7x - 3 \end{equation*}
    Then
    \begin{equation*} \frac{dy}{dx} = 2(5x^4) + (1/3)(2x) - 1.7 = 10x^4 + \frac{2}{3}x - 1.7 \end{equation*}
    Notice that the derivative of the constant term \(-3\) is \(0\text{,}\) because \(3\) really means \(3x^0\text{.}\) The derivative of any real constant is zero.
    🔗

    Example 113.

    Let \(y\) be the Laurent polynomial (with negative exponents, in this case)
    \begin{equation*} y = \frac{5}{x^4} + \frac{1}{3x} - 2x = 5 x^{-4} + \frac{1}{3}x^{-1} - 2x \end{equation*}
    \begin{equation*} \frac{dy}{dx} = -4(5x^{-5}) + (-1)\left(\frac{1}{3}\right) x^{-2} - 2 = -20x^{-5} - \frac{1}{3}x^{-2} - 2 \end{equation*}
    🔗
    🔗

    Remark 114.

    In this section, you can write negative powers as fractions, if you like:
    \begin{equation*} x^{-n} = \frac{1}{x^n} \end{equation*}
    (e.g., \(3x^{-6} = \dfrac{3}{x^6}\))
    🔗
    🔗

    Checkpoint 115.

    Find \(\dfrac{d}{dx}\) if
    1. \(\displaystyle 5x^3-3x^2\)
      🔗
      🔗
    2. \(\displaystyle 24x-\sqrt{x}+\dfrac{2}{x}\)
      🔗
      🔗
    3. \(\displaystyle 6\sqrt[3]{x^2}-\dfrac{4}{\sqrt{x}}\)
      🔗
      🔗
    🔗
    Solution.
    1. \(\displaystyle 15x^2 - 6x\)
      🔗
      🔗
    2. Rewrite as \(24x - x^{1/2} + 2x^{-1}\text{.}\) Then the derivative is \(24 - \dfrac{1}{2}x^{-1/2} - 2x^{-2}\text{,}\) or \(24 - \dfrac{1}{2\sqrt{x}} - \dfrac{2}{x^2}\text{.}\)
      🔗
      🔗
    3. Rewrite as \(6x^{2/3} - 4x^{-1/2}\text{.}\) Then the derivative is \(6(\frac{2}{3})x^{-1/3} - 4(-\frac{1}{2})x^{-3/2} = 4x^{-1/3} + 2x^{-3/2}\text{,}\) or \(\dfrac{4}{\sqrt[3]{x}} + \dfrac{2}{\sqrt{x^3}}\text{.}\)
      🔗
      🔗
    🔗
    🔗
    🔗

    Checkpoint 116.

    Find the equation of the tangent line to the graph of \(y = 6\sqrt[3]{x^2} - \dfrac{4}{\sqrt{x}}\) at \((1,2)\text{.}\)
    🔗
    Solution.
    First, we rewrite the function using fractional exponents:
    \begin{equation*} y = 6x^{2/3} - 4x^{-1/2} \end{equation*}
    Next, we find the derivative to determine the slope \(m\text{:}\)
    \begin{equation*} \frac{dy}{dx} = 6\left(\frac{2}{3}\right)x^{-1/3} - 4\left(-\frac{1}{2}\right)x^{-3/2} = 4x^{-1/3} + 2x^{-3/2} \end{equation*}
    To find the slope at the point \((1,2)\text{,}\) we evaluate the derivative at \(x=1\text{:}\)
    \begin{equation*} m = 4(1)^{-1/3} + 2(1)^{-3/2} = 4 + 2 = 6 \end{equation*}
    Using the point-slope form \(y - y_1 = m(x - x_1)\) with the point \((1,2)\text{:}\)
    \begin{equation*} y - 2 = 6(x - 1) \end{equation*}
    Simplifying to slope-intercept form:
    \begin{equation*} y = 6x - 4 \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 117.

    Find the points on the graph of \(y=-x^3+6x^2\) at which the tangent line is horizontal.
    🔗
    Solution.
    A tangent line is horizontal when the derivative (slope) is equal to zero. First, we find the derivative:
    \begin{equation*} \frac{dy}{dx} = -3x^2 + 12x \end{equation*}
    Setting the derivative equal to zero and solving for \(x\text{:}\)
    \begin{align*} -3x^2 + 12x \amp = 0\\ -3x(x - 4) \amp = 0 \end{align*}
    This gives critical values of \(x = 0\) and \(x = 4\text{.}\)
    🔗
    Now, we find the corresponding \(y\)-coordinates by plugging these values back into the original function:
    • At \(x = 0\text{:}\) \(y = -(0)^3 + 6(0)^2 = 0\text{.}\) So, the point is \((0, 0)\text{.}\)
      🔗
      🔗
    • At \(x = 4\text{:}\) \(y = -(4)^3 + 6(4)^2 = -64 + 96 = 32\text{.}\) So, the point is \((4, 32)\text{.}\)
      🔗
      🔗
    The points where the tangent line is horizontal are \((0, 0)\) and \((4, 32)\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 118.

    Find the points on the graph of \(y=-x^3+6x^2\) at which the tangent line has slope \(9\text{.}\)
    🔗
    Solution.
    The slope of the tangent line is given by the derivative. First, we find \(\frac{dy}{dx}\text{:}\)
    \begin{equation*} \frac{dy}{dx} = -3x^2 + 12x \end{equation*}
    We set the derivative equal to the desired slope, \(9\text{,}\) and solve for \(x\text{:}\)
    \begin{align*} -3x^2 + 12x \amp = 9\\ -3x^2 + 12x - 9 \amp = 0\\ -3(x^2 - 4x + 3) \amp = 0\\ -3(x - 1)(x - 3) \amp = 0 \end{align*}
    This gives us \(x = 1\) and \(x = 3\text{.}\)
    🔗
    Now, find the corresponding \(y\)-coordinates from the original function:
    • If \(x = 1\text{:}\) \(y = -(1)^3 + 6(1)^2 = -1 + 6 = 5\text{.}\) Point: \((1, 5)\text{.}\)
      🔗
      🔗
    • If \(x = 3\text{:}\) \(y = -(3)^3 + 6(3)^2 = -27 + 54 = 27\text{.}\) Point: \((3, 27)\text{.}\)
      🔗
      🔗
    The points where the tangent line has slope \(9\) are \((1, 5)\) and \((3, 27)\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection Product and Quotient Rules

    In the previous section, we learned some techniques for computing derivatives of functions. In this section, we will learn two more techniques for computing derivatives of more complicated functions: the product rule and the quotient rule.
    🔗

    Theorem 119. The Product Rule.

    Suppose that \(F(x)=f(x)\cdot g(x)\text{,}\) where \(f(x)\) is the “first” factor and \(g(x)\) is the “second” factor. Then
    \begin{equation*} F'(x) = \frac{d}{dx}[f(x)\cdot g(x)] = \left[\frac{d}{dx}f(x)\right]\cdot g(x) + f(x)\cdot\left[\frac{d}{dx}g(x)\right]. \end{equation*}
    The derivative of a product is the first factor times the derivative of the second factor, plus the derivative of the first factor times the second factor.
    🔗
    🔗
    In this section, we learn how to differentiate a “product” function which is built from two basic parts which are multiplied together: a product
    \begin{equation*} f(x) = u(x) v(x) \end{equation*}
    of two simpler parts \(u\) and \(v\text{.}\)
    \begin{equation*} \frac{df}{dx} = u(x) \frac{dv}{dx} + v(x) \frac{du}{dx} \end{equation*}
    This is often written
    \begin{equation*} (uv)' = u v' + v u' \end{equation*}
    🔗

    Example 120.

    Given \(f(x) = (3x^2 + x) (7x^3 + 1)\text{,}\) find \(\dfrac{df}{dx}\text{.}\)
    🔗
    1. Identify \(u\) and \(v\text{:}\) \(f = u v\text{,}\) where \(u = 3x^2 + x\) and \(v = 7x^3 + 1\)
      🔗
      🔗
    2. Find the derivatives \(\dfrac{du}{dx}\) and \(\dfrac{dv}{dx}\) of the factors:
      \begin{equation*} u = 3x^2 + x, \dfrac{du}{dx} = 6x + 1 \quad \text{and} \quad v = 7x^3 + 1, \dfrac{dv}{dx} = 21x^2 \end{equation*}
      🔗
      🔗
    3. Apply the product formula: \(\dfrac{df}{dx} = u \dfrac{dv}{dx} + v \dfrac{du}{dx}\)
      \begin{equation*} \dfrac{df}{dx} = (3x^2 + x)(21x^2) + (7x^3 + 1)(6x + 1). \end{equation*}
      🔗
      🔗
    🔗
    Of course, this can be expanded and simplified to obtain a polynomial representation:
    \begin{equation*} \dfrac{df}{dx} = 105 x^4 + 28 x^3 + 6 x + 1 \end{equation*}
    🔗
    🔗

    Note 121. Note on the derivative of sine.

    Now for an example involving trigonometric functions. All we need is one fact: the derivative of \(\sin x\) is \(\cos x\) (that is, \(\dfrac{d}{dx} \sin x = \cos x\)).
    🔗
    🔗

    Example 122.

    Given \(f(x) = 3x^5 \sin x\text{,}\) find \(f'(x)\text{.}\)
    🔗
    1. Identify \(u\) and \(v\text{:}\) \(f = u v\text{,}\) where \(u = 3x^5\) and \(v = \sin x\)
      🔗
      🔗
    2. Find the derivatives \(u'\) and \(v'\) of the factors:
      \begin{equation*} u = 3x^5, u' = 15 x^4 \quad \text{and} \quad v = \sin x, v' = \cos x \end{equation*}
      🔗
      🔗
    3. Apply the product formula: \(f' = u v' + u' v\)
      \begin{equation*} f'(x) = 3x^5 \cos x + 15 x^4 \sin x \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Checkpoint 123.

    (a)

    🔗

    \((x^4-2x^3-7)(6x-5) + (3x^2-5x)(4x^3-6x^2)\)

    (b)

    🔗
    🔗
    🔗
    (c)
    \(x^{1/3}(x^2-3x+2)\)
    🔗
    Solution.
    \(x^{1/3}(2x-3) + (x^2-3x+2)(\frac{1}{3}x^{-2/3})\)
    🔗
    🔗
    🔗
    (d)
    \((x^2-3x+2)\sin x\)
    🔗

    \((x^2-3x+2)\cos x + \sin x(2x-3)\)
    🔗

    Theorem 124. The Quotient Rule.

    Suppose that \(F(x)=\dfrac{f(x)}{g(x)}\text{,}\) where \(f(x)\) is the “numerator” and \(g(x)\) is the “denominator”. Then
    \begin{equation*} F'(x) = \frac{d}{dx}\left[\frac{f(x)}{g(x)}\right] = \frac{\left[\frac{d}{dx}f(x)\right]\cdot g(x) - f(x)\cdot\left[\frac{d}{dx}g(x)\right]}{(g(x))^2}. \end{equation*}
    The derivative of a quotient is the denominator times the derivative of the numerator, minus the numerator times the derivative of the denominator, all divided by the denominator squared.
    🔗
    🔗
    In this section, we learn how to differentiate a function which is constructed as a ratio of two basic parts: a quotient
    \begin{equation*} f(x) = \frac{u(x)}{v(x)} \end{equation*}
    of two simpler functions \(u\) and \(v\text{.}\) To calculate the derivative of a function of the form \(u/v\text{,}\) we have the “Quotient Rule”. The quotient rule says explicitly how to combine the functions \(u\) and \(v\) with their derivatives \(\frac{du}{dx}\) and \(\frac{dv}{dx}\) to form the derivative of \(f=u/v\text{.}\) It works like this:
    \begin{equation*} \frac{df}{dx} = \frac{\frac{du}{dx} v(x) - \frac{dv}{dx} u(x)}{v(x)^2} \end{equation*}
    This can also be written
    \begin{equation*} \left(\frac{u}{v}\right)' = \frac{v u' - u v'}{v^2} \end{equation*}
    🔗

    Example 125.

    Given \(f(x) = \dfrac{3x^2 + x}{7x^3 + 1}\text{,}\) find \(\dfrac{df}{dx}\text{.}\)
    🔗
    1. Identify \(u\) and \(v\text{:}\) \(f = u / v\text{,}\) where \(u = 3x^2 + x\) and \(v = 7x^3 + 1\)
      🔗
      🔗
    2. Find the derivatives \(\dfrac{du}{dx}\) and \(\dfrac{dv}{dx}\) of the numerator and denominator:
      \begin{equation*} u = 3x^2 + x, \dfrac{du}{dx} = 6x + 1 \quad \text{and} \quad v = 7x^3 + 1, \dfrac{dv}{dx} = 21x^2 \end{equation*}
      🔗
      🔗
    3. Apply the quotient formula: \(\dfrac{df}{dx} = \dfrac{v \dfrac{du}{dx} - u \dfrac{dv}{dx}}{v^2}\)
      \begin{equation*} \dfrac{df}{dx} = \dfrac{(7x^3 + 1)(6x + 1) - (3x^2 + x)(21x^2)}{(7x^3 + 1)^2} \end{equation*}
      🔗
      🔗
    🔗
    Of course, this can be expanded and terms collected to obtain a rational representation:
    \begin{equation*} \dfrac{df}{dx} = \dfrac{-21x^4 - 14x^3 + 6x - 1}{(7x^3 + 1)^2} \end{equation*}
    🔗
    🔗

    Example 126.

    Given \(f(x) = \dfrac{\sin x}{x}\text{,}\) find \(f'(x)\text{.}\)
    🔗
    Solution.
    Using the Quotient Rule with \(u = \sin x\) and \(v = x\text{,}\) and recalling the fact (Note 121) that
    \begin{equation*} \frac{d}{dx}(\sin x) = \cos x \end{equation*}
    we have \(u' = \cos x\) and \(v' = 1\text{.}\) Thus,
    \begin{equation*} f'(x) = \frac{x(\cos x) - (\sin x)(1)}{x^2} = \frac{x\cos x - \sin x}{x^2} \end{equation*}
    🔗
    🔗
    🔗

    Remark 127.

    To avoid ambiguity when multiplying a trigonometric function by a power function, always write the power function first. For example, write \(x \sin x\) instead of \(\sin x \cdot x\text{.}\) This prevents the common mistake of misinterpreting the expression as \(\sin(x^2)\text{.}\)
    🔗
    🔗
