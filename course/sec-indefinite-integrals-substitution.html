    Section 4.4 Indefinite Integrals and Substitution Rule

    The variable \(x\) can be replaced by a new variable \(u\) to find indefinite integrals. This technique is referred to as a change of variable, or the method of substitution.
    🔗

    Method of Substitution.

    If \(F\) is an antiderivative of \(f\text{,}\) then:
    \begin{equation*} \int f(g(x))g'(x) \, dx = F(g(x))+C \end{equation*}
    If \(u=g(x)\) and \(du=g'(x) \, dx,\) then:
    \begin{equation*} \int f(u) \, du=F(u)+C \end{equation*}
    🔗
    🔗

    Fact 350. Integral of the Tangent Function.

    The general indefinite integral of the tangent function is given by:
    \begin{equation*} \int \tan x \, dx = \ln|\sec x| + C \quad \text{or} \quad \int \tan x \, dx = -\ln|\cos x| + C \end{equation*}
    🔗
    🔗

    Proof.

    We begin by rewriting the tangent function in terms of sine and cosine:
    \begin{equation*} \int \tan x \, dx = \int \frac{\sin x}{\cos x} \, dx \end{equation*}
    🔗
    We use the method of substitution by letting the denominator be our new variable:
    \begin{equation*} u = \cos x \end{equation*}
    Taking the differential of both sides gives:
    \begin{equation*} du = -\sin x \, dx \implies \sin x \, dx = -du \end{equation*}
    🔗
    Substituting \(u\) and \(-du\) back into the integral equation yields:
    \begin{align*} \int \frac{\sin x}{\cos x} \, dx \amp = \int \frac{-1}{u} \, du\\ \amp = -\ln|u| + C \end{align*}
    🔗
    Replacing \(u\) with the original expression \(\cos x\) results in our first general form:
    \begin{equation*} = -\ln|\cos x| + C \end{equation*}
    🔗
    Using the logarithmic power property (\(-1 \cdot \ln|A| = \ln|A^{-1}|\)), we can rewrite the expression to eliminate the negative sign:
    \begin{align*} -\ln|\cos x| + C \amp = \ln\left| (\cos x)^{-1} \right| + C\\ \amp = \ln\left| \frac{1}{\cos x} \right| + C\\ \amp = \ln|\sec x| + C \end{align*}
    🔗
    🔗

    Fact 351. Integral of the Secant Function.

    The indefinite integral of the secant function is:
    \begin{equation*} \int \sec x \, dx = \ln|\sec x + \tan x| + C \end{equation*}
    🔗
    🔗

    Example 352. Deriving the Integral of Secant.

    Evaluate the indefinite integral \(\int \sec x \, dx\) to find its general formula.
    🔗
    Solution.
    We use a classic integration trick by multiplying the numerator and denominator by \((\sec x + \tan x)\text{:}\)
    \begin{equation*} \int \sec x \, dx = \int \sec x \cdot \frac{\sec x + \tan x}{\sec x + \tan x} \, dx = \int \frac{\sec^2 x + \sec x \tan x}{\sec x + \tan x} \, dx \end{equation*}
    🔗
    Now, we apply the method of substitution by letting the denominator be our new variable:
    \begin{equation*} u = \sec x + \tan x \end{equation*}
    Taking the differential of both sides yields:
    \begin{equation*} du = (\sec x \tan x + \sec^2 x) \, dx \end{equation*}
    🔗
    Notice that the numerator is an exact match for \(du\text{.}\) Substituting \(u\) and \(du\) back into our expression transforms it into a standard logarithmic integration form:
    \begin{align*} \int \frac{\sec^2 x + \sec x \tan x}{\sec x + \tan x} \, dx \amp = \int \frac{1}{u} \, du\\ \amp = \ln|u| + C\\ \amp = \ln|\sec x + \tan x| + C \end{align*}
    🔗
    🔗
    🔗

    Example 353. Evaluating Indefinite Integrals via Substitution.

    Evaluate each of the following indefinite integrals:
    🔗

    (a)

    \(\displaystyle \int x^2\sqrt{x^3+1} \, dx\)
    🔗
    Solution.
    Let \(u = x^3 + 1\text{.}\) Then \(du = 3x^2 \, dx\text{,}\) which means \(x^2 \, dx = \frac{1}{3} \, du\text{.}\) Substituting these into the integral gives:
    \begin{align*} \int x^2\sqrt{x^3+1} \, dx \amp = \int \sqrt{u} \cdot \frac{1}{3} \, du = \frac{1}{3} \int u^{1/2} \, du\\ \amp = \frac{1}{3} \left( \frac{2}{3}u^{3/2} \right) + C = \frac{2}{9}u^{3/2} + C \end{align*}
    Substituting back \(u = x^3 + 1\text{:}\)
    \begin{equation*} = \frac{2}{9}(x^3+1)^{3/2} + C \end{equation*}
    🔗
    🔗
    🔗

    (b)

    \(\displaystyle \int 4x e^{2x^2+1} \, dx\)
    🔗
    Solution.
    Let \(u = 2x^2 + 1\text{.}\) Then \(du = 4x \, dx\text{.}\) The substitution is a direct match:
    \begin{align*} \int 4x e^{2x^2+1} \, dx \amp = \int e^u \, du\\ \amp = e^u + C \end{align*}
    Substituting back \(u = 2x^2 + 1\text{:}\)
    \begin{equation*} = e^{2x^2+1} + C \end{equation*}
    🔗
    🔗
    🔗

    (c)

    \(\displaystyle \int \frac{3x^2+2}{x^3+2x} \, dx\)
    🔗
    Solution.
    Let \(u = x^3 + 2x\text{.}\) Then \(du = (3x^2 + 2) \, dx\text{.}\) This yields the standard natural log integration form:
    \begin{align*} \int \frac{3x^2+2}{x^3+2x} \, dx \amp = \int \frac{1}{u} \, du\\ \amp = \ln|u| + C \end{align*}
    Substituting back \(u = x^3 + 2x\text{:}\)
    \begin{equation*} = \ln|x^3+2x| + C \end{equation*}
    🔗
    🔗
    🔗

    (d)

    \(\displaystyle \int \sqrt{5x+7} \, dx\)
    🔗
    Solution.
    Let \(u = 5x + 7\text{.}\) Then \(du = 5 \, dx\text{,}\) which means \(dx = \frac{1}{5} \, du\text{:}\)
    \begin{align*} \int \sqrt{5x+7} \, dx \amp = \int \sqrt{u} \cdot \frac{1}{5} \, du = \frac{1}{5} \int u^{1/2} \, du\\ \amp = \frac{1}{5} \left( \frac{2}{3}u^{3/2} \right) + C = \frac{2}{15}u^{3/2} + C \end{align*}
    Substituting back \(u = 5x + 7\text{:}\)
    \begin{equation*} = \frac{2}{15}(5x+7)^{3/2} + C \end{equation*}
    🔗
    🔗
    🔗

    (e)

    \(\displaystyle \int \cos 4x \, dx\)
    🔗
    Solution.
    Let \(u = 4x\text{.}\) Then \(du = 4 \, dx\text{,}\) which means \(dx = \frac{1}{4} \, du\text{:}\)
    \begin{align*} \int \cos 4x \, dx \amp = \int \cos u \cdot \frac{1}{4} \, du = \frac{1}{4} \sin u + C \end{align*}
    Substituting back \(u = 4x\text{:}\)
    \begin{equation*} = \frac{1}{4}\sin 4x + C \end{equation*}
    🔗
    🔗
    🔗

    (f)

    \(\displaystyle \int (2x^3+1)^7x^2 \, dx\)
    🔗
    Solution.
    Let \(u = 2x^3 + 1\text{.}\) Then \(du = 6x^2 \, dx\text{,}\) which means \(x^2 \, dx = \frac{1}{6} \, du\text{:}\)
    \begin{align*} \int (2x^3+1)^7x^2 \, dx \amp = \int u^7 \cdot \frac{1}{6} \, du = \frac{1}{6} \left( \frac{u^8}{8} \right) + C\\ \amp = \frac{1}{48}u^8 + C \end{align*}
    Substituting back \(u = 2x^3 + 1\text{:}\)
    \begin{equation*} = \frac{1}{48}(2x^3+1)^8 + C \end{equation*}
    🔗
    🔗
    🔗

    (g)

    \(\displaystyle \int \frac{(x^2-1)}{(x^3-3x+1)^6} \, dx\)
    🔗
    Solution.
    Let \(u = x^3 - 3x + 1\text{.}\) Then \(du = (3x^2 - 3) \, dx = 3(x^2 - 1) \, dx\text{,}\) which means \((x^2 - 1) \, dx = \frac{1}{3} \, du\text{:}\)
    \begin{align*} \int \frac{(x^2-1)}{(x^3-3x+1)^6} \, dx \amp = \int \frac{1}{u^6} \cdot \frac{1}{3} \, du = \frac{1}{3} \int u^{-6} \, du\\ \amp = \frac{1}{3} \left( \frac{u^{-5}}{-5} \right) + C = -\frac{1}{15u^5} + C \end{align*}
    Substituting back \(u = x^3 - 3x + 1\text{:}\)
    \begin{equation*} = -\frac{1}{15(x^3-3x+1)^5} + C \end{equation*}
    🔗
    🔗
    🔗

    (h)

    \(\displaystyle \int \cos^3 5x \sin 5x \, dx\)
    🔗
    Solution.
    Let \(u = \cos 5x\text{.}\) Then \(du = -5\sin 5x \, dx\text{,}\) which implies \(\sin 5x \, dx = -\frac{1}{5} \, du\text{:}\)
    \begin{align*} \int \cos^3 5x \sin 5x \, dx \amp = \int u^3 \cdot \left( -\frac{1}{5} \, du \right) = -\frac{1}{5} \left( \frac{u^4}{4} \right) + C\\ \amp = -\frac{1}{20}u^4 + C \end{align*}
    Substituting back \(u = \cos 5x\text{:}\)
    \begin{equation*} = -\frac{1}{20}\cos^4 5x + C \end{equation*}
    🔗
    🔗
    🔗

    (i)

    \(\displaystyle \int \tan x \sec^2 x \, dx\)
    🔗
    Solution.
    Let \(u = \tan x\text{.}\) Then \(du = \sec^2 x \, dx\text{.}\) This aligns perfectly with the standard power rule profile:
    \begin{align*} \int \tan x \sec^2 x \, dx \amp = \int u \, du\\ \amp = \frac{1}{2}u^2 + C \end{align*}
    Substituting back \(u = \tan x\text{:}\)
    \begin{equation*} = \frac{1}{2}\tan^2 x + C \end{equation*}
    Note 354.
    An alternative choice of substitution \(u = \sec x\) (where \(du = \sec x \tan x \, dx\)) yields \(\frac{1}{2}\sec^2 x + C_2\text{.}\) Both answers are correct as they differ only by a trigonometric constant identity threshold (\(\frac{1}{2}\sec^2 x = \frac{1}{2}\tan^2 x + \frac{1}{2}\)).
    🔗
    🔗
    🔗
    🔗
    🔗
    🔗

    Checkpoint 355. Further Indefinite Integrals via Substitution.

    Evaluate each of the following indefinite integrals:
    🔗

    (a)

    \(\displaystyle \int x \sqrt[3]{7-6x^2} \, dx\)
    🔗
    Solution.
    Let \(u = 7 - 6x^2\text{.}\) Then \(du = -12x \, dx\text{,}\) which means \(x \, dx = -\frac{1}{12} \, du\text{.}\) Substituting these into the integral gives:
    \begin{align*} \int x \sqrt[3]{7-6x^2} \, dx \amp = \int \sqrt[3]{u} \cdot \left(-\frac{1}{12} \, du\right) = -\frac{1}{12} \int u^{1/3} \, du\\ \amp = -\frac{1}{12} \left( \frac{3}{4} u^{4/3} \right) + C\\ \amp = -\frac{1}{16} u^{4/3} + C \end{align*}
    Substituting back \(u = 7 - 6x^2\) yields:
    \begin{equation*} = -\frac{1}{16}(7 - 6x^2)^{4/3} + C \end{equation*}
    🔗
    🔗
    🔗

    (b)

    \(\displaystyle \int \frac{\cos \sqrt{x}}{\sqrt{x}} \, dx\)
    🔗
    Solution.
    Let \(u = \sqrt{x} = x^{1/2}\text{.}\) Then \(du = \frac{1}{2}x^{-1/2} \, dx = \frac{1}{2\sqrt{x}} \, dx\text{,}\) which implies \(\frac{1}{\sqrt{x}} \, dx = 2 \, du\text{.}\) Substituting these gives:
    \begin{align*} \int \frac{\cos \sqrt{x}}{\sqrt{x}} \, dx \amp = \int \cos(u) \cdot 2 \, du = 2 \int \cos(u) \, du\\ \amp = 2\sin(u) + C \end{align*}
    Substituting back \(u = \sqrt{x}\) yields:
    \begin{equation*} = 2\sin\sqrt{x} + C \end{equation*}
    🔗
    🔗
    🔗

    (c)

    \(\displaystyle \int \frac{\sin 2x}{\sqrt{1-\cos 2x}} \, dx\)
    🔗
    Solution.
    Let \(u = 1 - \cos 2x\text{.}\) Using the chain rule, \(du = -(-\sin 2x \cdot 2) \, dx = 2\sin 2x \, dx\text{,}\) which means \(\sin 2x \, dx = \frac{1}{2} \, du\text{.}\) Substituting these gives:
    \begin{align*} \int \frac{\sin 2x}{\sqrt{1-\cos 2x}} \, dx \amp = \int \frac{1}{\sqrt{u}} \cdot \frac{1}{2} \, du = \frac{1}{2} \int u^{-1/2} \, du\\ \amp = \frac{1}{2} \left( 2u^{1/2} \right) + C = \sqrt{u} + C \end{align*}
    Substituting back \(u = 1 - \cos 2x\) yields:
    \begin{equation*} = \sqrt{1 - \cos 2x} + C \end{equation*}
    🔗
    🔗
    🔗

    (d)

    \(\displaystyle \int (\cos x + \sin x)^2 \, dx\)
    🔗
    Solution.
    First, expand the integrand algebraically before evaluating:
    \begin{equation*} (\cos x + \sin x)^2 = \cos^2 x + 2\sin x \cos x + \sin^2 x \end{equation*}
    🔗
    Using the Pythagorean identity \(\cos^2 x + \sin^2 x = 1\) and the double-angle identity \(2\sin x \cos x = \sin 2x\text{,}\) we rewrite the integral without needing a raw \(u\)-substitution:
    \begin{align*} \int (\cos x + \sin x)^2 \, dx \amp = \int (1 + \sin 2x) \, dx\\ \amp = x - \frac{1}{2}\cos 2x + C \end{align*}
    🔗
    🔗
    🔗

    (e)

    \(\displaystyle \int \frac{x}{\cos^2(x^2)} \, dx\)
    🔗
    Solution.
    First, rewrite the integrand using the identity \(\frac{1}{\cos^2 \theta} = \sec^2 \theta\text{:}\)
    \begin{equation*} \int x \sec^2(x^2) \, dx \end{equation*}
    Let \(u = x^2\text{.}\) Then \(du = 2x \, dx\text{,}\) which means \(x \, dx = \frac{1}{2} \, du\text{.}\) Substituting these into the formula gives:
    \begin{align*} \int x \sec^2(x^2) \, dx \amp = \int \sec^2(u) \cdot \frac{1}{2} \, du = \frac{1}{2} \int \sec^2(u) \, du\\ \amp = \frac{1}{2}\tan(u) + C \end{align*}
    Substituting back \(u = x^2\) yields:
    \begin{equation*} = \frac{1}{2}\tan(x^2) + C \end{equation*}
    🔗
    🔗
    🔗

    (f)

    \(\displaystyle \int \frac{1}{\sin^2(5x)} \, dx\)
    🔗
    Solution.
    Rewrite the integrand using the identity \(\frac{1}{\sin^2 \theta} = \csc^2 \theta\text{:}\)
    \begin{equation*} \int \csc^2(5x) \, dx \end{equation*}
    Let \(u = 5x\text{.}\) Then \(du = 5 \, dx\text{,}\) which means \(dx = \frac{1}{5} \, du\text{.}\) Knowing that the antiderivative of \(\csc^2 u\) is \(-\cot u\text{:}\)
    \begin{align*} \int \csc^2(5x) \, dx \amp = \int \csc^2(u) \cdot \frac{1}{5} \, du = \frac{1}{5} ( -\cot u ) + C\\ \amp = -\frac{1}{5}\cot(u) + C \end{align*}
    Substituting back \(u = 5x\) yields:
    \begin{equation*} = -\frac{1}{5}\cot(5x) + C \end{equation*}
    🔗
