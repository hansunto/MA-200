    Section 3.10 Antiderivatives and Indefinite Integrals

    In this section, we reverse the process of differentiation. Instead of finding the derivative of a given function, we will find a function whose derivative is already known. This process is fundamental to the Fundamental Theorem of Calculus.
    🔗

    Definition 296.

    A function, \(F\text{,}\) is an antiderivative of a function, \(f\text{,}\) on an interval \(I\) if
    \begin{equation*} F'(x) = f(x) \text{ for all } x \end{equation*}
    🔗
    🔗

    Example 297.

    If \(f(x) = 5x^2\) then \(F(x) = \)
    🔗
    Solution.
    To find \(F(x)\text{,}\) we apply the power rule for antiderivatives, which states that \(\int x^n \, dx = \dfrac{x^{n+1}}{n+1}\text{.}\)
    \begin{equation*} F(x) = \dfrac{5x^{2+1}}{2+1} + C = \dfrac{5}{3}x^3 + C \end{equation*}
    🔗
    🔗
    🔗

    Definition 298.

    The notation
    \begin{equation*} \int f(x)dx=F(x)+C, \end{equation*}
    where \(F'(x)=f(x)\) and \(C\) is an arbitrary constant, denotes the family of all antiderivatives of \(f(x)\) on an interval \(I\text{.}\)
    🔗
    🔗
    So, if we know one antiderivative of \(f(x)\) on \(I\text{,}\) say \(F(x)\text{,}\) then we know them all. The family of antiderivatives is denoted using the notation:
    \begin{equation*} \int f(x)\,dx = F(x) + C \quad \text{where } C \text{ is an arbitrary constant} \end{equation*}
    🔗

    Example 299.

    Evaluate:
    \begin{equation*} \int 5x^4\,dx = \end{equation*}
    🔗
    Solution.
    We apply the power rule for integration, which states that \(\int x^n \, dx = \dfrac{x^{n+1}}{n+1}\) for \(n \neq -1\text{.}\)
    \begin{equation*} \int 5x^4\,dx = 5 \cdot \frac{x^{4+1}}{4+1} + C = 5 \cdot \dfrac{x^5}{5} + C = x^5 + C \end{equation*}
    🔗
    🔗
    🔗

    Example 300.

    Evaluate \(\displaystyle \int 3x^2\,dx\) that satisfies \(F(1)=1\text{.}\)
    🔗
    Solution.
    First, find the general antiderivative by integrating term-by-term:
    \begin{equation*} F(x) = \int 3x^2\,dx = 3 \cdot \frac{x^3}{3} + C = x^3 + C \end{equation*}
    🔗
    Next, use the initial condition \(F(1) = 1\) to solve for the specific constant of integration \(C\text{:}\)
    \begin{equation*} F(1) = (1)^3 + C = 1 \end{equation*}
    \begin{equation*} 1 + C = 1 \implies C = 0 \end{equation*}
    🔗
    Therefore, the particular solution that satisfies the initial value condition is:
    \begin{equation*} F(x) = x^3 \end{equation*}
    🔗
    🔗
    🔗

      🔗
      🔗
    3. \(C\text{:}\) constant of integration
      🔗
      🔗
    4. \(dx\text{:}\) tells us the variable of integration is \(x\)

    Subsection Differential Equation: An equation that includes derivatives

    Definition 303.

    Finding an antiderivative for a function \(f(x)\) is the same problem as finding a function \(y(x)\) that satisfies the equation
    \begin{equation*} \frac{dy}{dx}=f'(x) \end{equation*}
    This is called a differential equation.
    🔗
    Suppose we fix the arbitrary constant arising in the antidifferentiation process by specifying an initial condition
    \begin{equation*} y(x_0)=y_0 \end{equation*}
    The combination of a differential equation and an initial condition is called an initial value problem.
    🔗
    🔗

    Example 304.

    Suppose \(f'(x) = 3x^2 - 8x\) and \(f(1) = 2\text{,}\) find the particular solution of \(f(x)\text{.}\)
    🔗
    Solution.
    To find the general solution \(f(x)\text{,}\) we integrate the derivative function \(f'(x)\) with respect to \(x\text{:}\)
    \begin{equation*} f(x) = \int (3x^2 - 8x) \, dx \end{equation*}
    Applying the power rule term by term gives:
    \begin{equation*} f(x) = 3\left(\frac{x^3}{3}\right) - 8\left(\frac{x^2}{2}\right) + C = x^3 - 4x^2 + C \end{equation*}
    🔗
    Now, we use the initial condition \(f(1) = 2\) to solve for the specific constant \(C\text{:}\)
    \begin{equation*} f(1) = (1)^3 - 4(1)^2 + C = 2 \end{equation*}
    \begin{equation*} 1 - 4 + C = 2 \end{equation*}
    \begin{equation*} -3 + C = 2 \implies C = 5 \end{equation*}
    🔗
    Substituting \(C = 5\) back into our general equation gives the particular solution:
    \begin{equation*} f(x) = x^3 - 4x^2 + 5 \end{equation*}
    🔗
    🔗
    🔗

    Example 305.

    An object is dropped from a height of \(100\) feet. Disregarding air resistance, find:
    1. the distance it falls after \(t\) seconds
      🔗
      🔗
    2. its velocity after 2 seconds
      🔗
      🔗
    3. when it hits the ground
      🔗
      🔗
    🔗
    Solution.
    1. Begin with acceleration due to gravity \(a(t) = -32\text{.}\) Since \(v'(t) = a(t) = -32\text{,}\) we integrate to find velocity:
      \begin{equation*} v(t) = -32t + C_1 \end{equation*}
      Since the object is dropped, its initial velocity is zero, \(v(0) = 0\text{,}\) which yields \(0 = -32(0) + C_1 \implies C_1 = 0\text{.}\) Thus:
      \begin{equation*} v(t) = -32t \end{equation*}
      🔗
      Since position \(s'(t) = v(t)\text{,}\) we integrate velocity to find the height function:
      \begin{equation*} s(t) = \int -32t \, dt = -16t^2 + C_2 \end{equation*}
      Since the initial height is 100 feet, \(s(0) = 100\text{,}\) which gives \(100 = -16(0)^2 + C_2 \implies C_2 = 100\text{.}\) Therefore, the height equation is:
      \begin{equation*} s(t) = -16t^2 + 100 \end{equation*}
      The downward distance fallen after \(t\) seconds is represented by \(100 - s(t) = 16t^2\) feet.
      🔗
      🔗
    2. Substitute \(t = 2\) into the velocity equation:
      \begin{equation*} v(2) = -32(2) = -64 \text{ ft/sec} \end{equation*}
      🔗
      🔗
    3. The object hits the ground when its height is zero, \(s(t) = 0\text{:}\)
      \begin{equation*} -16t^2 + 100 = 0 \implies 16t^2 = 100 \end{equation*}
      \begin{equation*} t^2 = \frac{100}{16} = \frac{25}{4} \implies t = \frac{5}{2} = 2.5 \text{ seconds} \end{equation*}
      🔗
      🔗
    🔗
    🔗
    🔗

    Checkpoint 306.

    Find the general antiderivative of
    \begin{equation*} f(x)=\frac{3}{\sqrt{x}}+\frac{\sqrt{x}}{3}+\sin 2x \end{equation*}
    🔗
    Solution.
    First rewrite the radical terms as fractional exponents: \(f(x) = 3x^{-1/2} + \frac{1}{3}x^{1/2} + \sin 2x\text{.}\) Now integrate term by term:
    \begin{equation*} \int f(x)\,dx = 3\left(\frac{x^{1/2}}{1/2}\right) + \frac{1}{3}\left(\frac{x^{3/2}}{3/2}\right) - \frac{1}{2}\cos 2x + C \end{equation*}
    \begin{equation*} = 6\sqrt{x} + \frac{2}{9}x^{3/2} - \frac{1}{2}\cos 2x + C \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 307.

    A balloon is ascending at the rate of 12 ft/sec and is at a height of 80 ft above the ground when a package is dropped. How long does it take the package to reach the ground?
    🔗
    Solution.
    The acceleration due to gravity is \(a(t) = -32 \text{ ft/sec}^2\text{.}\) Integrating acceleration gives velocity: \(v(t) = -32t + C_1\text{.}\) Because the package is dropped from an ascending balloon, it inherits the balloon’s upward velocity as its initial velocity: \(v(0) = 12 \implies C_1 = 12\text{.}\)
    \begin{equation*} v(t) = -32t + 12 \end{equation*}
    🔗
    Integrating velocity gives the position equation for height: \(s(t) = -16t^2 + 12t + C_2\text{.}\) The initial height is 80 feet, so \(s(0) = 80 \implies C_2 = 80\text{.}\)
    \begin{equation*} s(t) = -16t^2 + 12t + 80 \end{equation*}
    🔗
    Set \(s(t) = 0\) to find when it hits the ground:
    \begin{equation*} -16t^2 + 12t + 80 = 0 \implies -4(4t^2 - 3t - 20) = 0 \end{equation*}
    Apply the quadratic formula to \(4t^2 - 3t - 20 = 0\text{:}\)
    \begin{equation*} t = \frac{-(-3) \pm \sqrt{(-3)^2 - 4(4)(-20)}}{2(4)} = \frac{3 \pm \sqrt{9 + 320}}{8} = \frac{3 \pm \sqrt{329}}{8} \end{equation*}
    Since time must be positive, we evaluate the positive root:
    \begin{equation*} t = \frac{3 + \sqrt{329}}{8} \approx \frac{3 + 18.138}{8} \approx 2.64 \text{ seconds} \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 308.

    Evaluate each of the following integrals using basic antiderivatives and algebraic manipulation:
    🔗
    (a)
    \(\displaystyle \int \frac{1+\cos 2x}{2} \,dx\)
    🔗
    Solution.
    Separate the fraction into two terms and integrate each term individually:
    \begin{equation*} \int \left(\frac{1}{2} + \frac{1}{2}\cos 2x\right)dx = \frac{1}{2}x + \frac{1}{4}\sin 2x + C \end{equation*}
    🔗
    🔗
    🔗
    (b)
    \(\displaystyle \int (e^{3x}+5e^{-x})\,dx\)
    🔗
    Solution.
    Integrate term by term using the exponential rule \(\int e^{kx}dx = \frac{1}{k}e^{kx}\text{:}\)
    \begin{equation*} \int e^{3x}\,dx + \int 5e^{-x}\,dx = \frac{1}{3}e^{3x} - 5e^{-x} + C \end{equation*}
    🔗
    🔗
    🔗
    (c)
    \(\displaystyle \int \cot^2 x\,dx\)
    🔗
    Solution.
    Rewrite the integrand using the Pythagorean identity \(\cot^2 x = \csc^2 x - 1\text{,}\) then apply known basic antiderivatives:
    \begin{equation*} \int (\csc^2 x - 1)\,dx = -\cot x - x + C \end{equation*}
    🔗
    🔗
    🔗
    (d)
    \(\displaystyle \int \frac{t\sqrt{t}+\sqrt{t}}{t^2}\,dt\)
    🔗
    Solution.
    Simplify the integrand first by dividing each term in the numerator by the denominator using exponent rules, yielding \(\dfrac{t^{3/2} + t^{1/2}}{t^2} = t^{-1/2} + t^{-3/2}\text{.}\) Then apply the Power Rule:
    \begin{equation*} \int (t^{-1/2} + t^{-3/2})\,dt = \dfrac{t^{1/2}}{1/2} + \dfrac{t^{-1/2}}{-1/2} + C = 2\sqrt{t} - \dfrac{2}{\sqrt{t}} + C \end{equation*}
    🔗
    🔗
    🔗
    (e)
    \(\displaystyle \int (7x-2)^3\,dx\)
    🔗
    Solution.
    To avoid \(u\)-substitution, fully expand the cubic binomial first using the binomial theorem or expansion rules:
    \begin{equation*} (7x - 2)^3 = (7x)^3 - 3(7x)^2(2) + 3(7x)(2)^2 - (2)^3 \end{equation*}
    \begin{equation*} = 343x^3 - 294x^2 + 84x - 8 \end{equation*}
    🔗
    Now compute the general antiderivative term-by-term using the basic Power Rule:
    \begin{align*} \amp \int (343x^3 - 294x^2 + 84x - 8)\,dx \\ \amp = 343\left(\frac{x^4}{4}\right) - 294\left(\frac{x^3}{3}\right) + 84\left(\frac{x^2}{2}\right) - 8x + C\\ \amp = \frac{343}{4}x^4 - 98x^3 + 42x^2 - 8x + C \end{align*}
