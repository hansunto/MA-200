    Section 4.3 The Fundamental Theorem of Calculus

    Theorem 337. The Fundamental Theorem of Calculus.

    Suppose \(f\) is continuous on a closed interval \([a,b]\text{.}\)
    1. If the function \(G\) is defined by \(G(x)=\displaystyle\int^{x}_{a}f(t) \, dt\) for every \(x\) in \([a,b]\text{,}\) then \(G\) is an antiderivative of \(f\) on \([a,b]\text{.}\) That is, \(G'(x) = f(x)\text{.}\)
      🔗
      🔗
    2. If \(F\) is any antiderivative of \(f\) on \([a,b]\text{,}\) then \(\displaystyle\int^{b}_{a} f(x) \, dx=F(b)-F(a).\)
      🔗
      🔗
    🔗
    🔗

    Corollary 338.

    If \(f\) is continuous on \([a,b]\) and \(F\) is any antiderivative of \(f\text{,}\) then:
    \begin{equation*} \int^{b}_{a} f(x) \, dx = \left. F(x) \right|^{b}_{a} = F(b)-F(a). \end{equation*}
    🔗
    🔗

    Theorem 339. Substitution Rule for Definite Integrals.

    If \(u=g(x)\text{,}\) then \(\displaystyle \int^{b}_{a} f(g(x)) \, dx = \int^{g(b)}_{g(a)}f(u) \, du.\)
    🔗
    🔗

    Definite Integrals of Symmetric Functions.

    Let \(f\) be continuous on \([-a,a]\text{.}\)
    1. If \(f\) is an even function, then \(\displaystyle\int^{a}_{-a}f(x) \, dx = 2\int^{a}_{0}f(x) \, dx\text{.}\)
      🔗
      🔗
    2. If \(f\) is an odd function, then \(\displaystyle\int^{a}_{-a}f(x) \, dx = 0\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Theorem 340. Derivative of an Integral.

    Let \(f\) be continuous on \([a,b]\text{.}\) If \(a \leq c \leq b\text{,}\) then for every \(x\) in \([a,b]\text{:}\)
    \begin{equation*} \frac{d}{dx}\int^{x}_{c}f(t) \, dt = f(x). \end{equation*}
    🔗
    🔗

    Example 341. Derivative of an Integral Function.

    If \(G(x)=\displaystyle \int^{x}_{1} \frac{1}{t}\,dt\) and \(x \gt 0\text{,}\) find \(G'(x)\text{.}\)
    🔗
    Solution.
    We use the Fundamental Theorem of Calculus, Part 1 (or the Leibniz Rule), which states that if \(f\) is continuous on an interval containing a constant \(c\text{,}\) then:
    \begin{equation*} \frac{d}{dx} \int^{x}_{c} f(t) \, dt = f(x) \end{equation*}
    🔗
    For the function \(G(x)\text{,}\) the integrand is \(f(t) = \frac{1}{t}\text{,}\) which is continuous for all \(t \gt 0\text{.}\) The lower limit of integration is the constant \(c = 1\text{,}\) and the upper limit is the single variable \(x\text{.}\)
    🔗
    Applying the theorem directly, we replace the dummy variable \(t\) with the upper limit variable \(x\text{:}\)
    \begin{equation*} G'(x) = \frac{d}{dx} \int^{x}_{1} \frac{1}{t} \, dt = \frac{1}{x} \end{equation*}
    🔗
    Therefore, for \(x \gt 0\text{,}\) the derivative is \(G'(x) = \dfrac{1}{x}\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 342. Derivatives of Integrals with Variable Bounds.

    Find \(\dfrac{dy}{dx}\) for each of the following functions:
    1. \(\displaystyle y=\displaystyle \int^{x}_{0} \sqrt{1+t^{2}}\,dt\)
      🔗
      🔗
    2. \(\displaystyle y=\displaystyle \int^{x^2}_{0} \cos\sqrt{t}\,dt\)
      🔗
      🔗
    🔗
    Solution.
    We find each derivative using the Fundamental Theorem of Calculus (FTC), Part 1.
    🔗
    1. The upper limit of integration is a simple variable \(x\text{,}\) and the lower limit is a constant. By the direct application of FTC Part 1, we replace the dummy variable \(t\) with the upper bound variable \(x\text{:}\)
      \begin{equation*} \frac{dy}{dx} = \frac{d}{dx} \int^{x}_{0} \sqrt{1+t^{2}}\,dt = \sqrt{1+x^{2}} \end{equation*}
      🔗
      🔗
    2. The upper limit of integration is a function of \(x\text{,}\) namely \(u = x^2\text{.}\) Therefore, we must apply the Chain Rule along with FTC Part 1:
      \begin{equation*} \frac{dy}{dx} = \frac{d}{du}\left[ \int^{u}_{0} \cos\sqrt{t}\,dt \right] \cdot \frac{du}{dx} \end{equation*}
      🔗
      Differentiating with respect to \(u\) gives the evaluated integrand \(\cos\sqrt{u}\text{,}\) and the derivative of the upper bound is \(\frac{du}{dx} = 2x\text{.}\) Substituting these back in gives:
      \begin{align*} \frac{dy}{dx} \amp = \cos\sqrt{x^2} \cdot \frac{d}{dx}(x^2)\\ \amp = \cos(|x|) \cdot 2x \end{align*}
      Assuming \(x \geq 0\text{,}\) this simplifies beautifully to:
      \begin{equation*} \frac{dy}{dx} = 2x\cos(x) \end{equation*}
      🔗
      🔗
    🔗
    🔗
    🔗

    Checkpoint 343. Solving an Initial Value Problem.

    Solve the initial value problem:
    \begin{equation*} \frac{dy}{dx}=\sec^{2} x, \quad y(2)=3 \end{equation*}
    🔗
    Solution.
    To find the general solution, we integrate both sides of the differential equation with respect to \(x\text{:}\)
    \begin{equation*} y(x) = \int \sec^2 x \, dx \end{equation*}
    🔗
    Since the derivative of \(\tan x\) is \(\sec^2 x\text{,}\) the general antiderivative introduces an arbitrary constant \(C\text{:}\)
    \begin{equation*} y(x) = \tan x + C \end{equation*}
    🔗
    Next, we use the given initial condition \(y(2) = 3\) to solve for the specific constant \(C\text{.}\) Substituting \(x = 2\) and \(y = 3\) (using radian measure for the trigonometric function):
    \begin{align*} 3 \amp = \tan(2) + C\\ C \amp = 3 - \tan(2) \end{align*}
    🔗
    Substituting the value of \(C\) back into our general equation yields the particular solution:
    \begin{equation*} y(x) = \tan x + 3 - \tan(2) \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 344. Solving a Second-Order Initial Value Problem.

    Find the function \(f\) that satisfies the following conditions:
    \begin{equation*} f''(x)=1-6x+48x^{2}, \quad f(0)=1, \quad f'(0)=2 \end{equation*}
    🔗
    Solution.
    We solve for \(f(x)\) by integrating the second derivative successively. First, we find the first derivative, \(f'(x)\text{,}\) by integrating \(f''(x)\) with respect to \(x\text{:}\)
    \begin{align*} f'(x) \amp = \int (1 - 6x + 48x^2) \, dx\\ \amp = x - 6\left(\frac{x^2}{2}\right) + 48\left(\frac{x^3}{3}\right) + C_1\\ \amp = x - 3x^2 + 16x^3 + C_1 \end{align*}
    🔗
    We apply the first initial condition, \(f'(0) = 2\text{,}\) to determine the value of the integration constant \(C_1\text{:}\)
    \begin{align*} 2 \amp = (0) - 3(0)^2 + 16(0)^3 + C_1\\ C_1 \amp = 2 \end{align*}
    Thus, the specific expression for the first derivative is:
    \begin{equation*} f'(x) = 16x^3 - 3x^2 + x + 2 \end{equation*}
    🔗
    Next, we integrate \(f'(x)\) with respect to \(x\) to find the original function \(f(x)\text{:}\)
    \begin{align*} f(x) \amp = \int (16x^3 - 3x^2 + x + 2) \, dx\\ \amp = 16\left(\frac{x^4}{4}\right) - 3\left(\frac{x^3}{3}\right) + \frac{x^2}{2} + 2x + C_2\\ \amp = 4x^4 - x^3 + \frac{1}{2}x^2 + 2x + C_2 \end{align*}
    🔗
    We apply the second initial condition, \(f(0) = 1\text{,}\) to determine the final integration constant \(C_2\text{:}\)
    \begin{align*} 1 \amp = 4(0)^4 - (0)^3 + \frac{1}{2}(0)^2 + 2(0) + C_2\\ C_2 \amp = 1 \end{align*}
    🔗
    Therefore, the unique function satisfying the given initial value problem is:
    \begin{equation*} f(x) = 4x^4 - x^3 + \frac{1}{2}x^2 + 2x + 1 \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 345. Evaluating Definite Integrals.

    Evaluate each of the following definite integrals using the Fundamental Theorem of Calculus:
    🔗

    (a)

    \(\displaystyle \int^{\pi}_{0} \sin x \, dx\)
    🔗
    Solution.
    The general antiderivative of \(\sin x\) is \(-\cos x\text{.}\) Applying the Fundamental Theorem of Calculus, Part 2:
    \begin{align*} \int^{\pi}_{0} \sin x \, dx \amp = \left[ -\cos x \right]^{\pi}_{0}\\ \amp = (-\cos\pi) - (-\cos 0)\\ \amp = (-(-1)) - (-1)\\ \amp = 1 + 1 = 2 \end{align*}
    🔗
    🔗
    🔗

    (b)

    \(\displaystyle \int^{\pi}_{0} \cos x \, dx\)
    🔗
    Solution.
    The general antiderivative of \(\cos x\) is \(\sin x\text{.}\) Evaluating across the bounds:
    \begin{align*} \int^{\pi}_{0} \cos x \, dx \amp = \left[ \sin x \right]^{\pi}_{0}\\ \amp = \sin\pi - \sin 0\\ \amp = 0 - 0 = 0 \end{align*}
    🔗
    🔗
    🔗

    (c)

    \(\displaystyle \int^{1}_{-1}(x^{4}+3x^{2}+1)\,dx\)
    🔗
    Solution.
    The integrand \(f(x) = x^4 + 3x^2 + 1\) consists entirely of even powers, making it an even function (\(f(-x) = f(x)\)). Since the integration interval is symmetric across the origin (\([-1, 1]\)), we can simplify using the even function property:
    \begin{equation*} \int^{1}_{-1}(x^{4}+3x^{2}+1)\,dx = 2\int^{1}_{0}(x^{4}+3x^{2}+1)\,dx \end{equation*}
    🔗
    Integrating term-by-term using the power rule:
    \begin{align*} \amp = 2 \left[ \frac{x^5}{5} + \frac{3x^3}{3} + x \right]^{1}_{0}\\ \amp = 2 \left[ \frac{x^5}{5} + x^3 + x \right]^{1}_{0}\\ \amp = 2 \left( \left(\frac{1}{5} + 1 + 1\right) - 0 \right)\\ \amp = 2 \left( \frac{1}{5} + \frac{10}{5} \right) = 2 \left(\frac{11}{5}\right) = \frac{22}{5} \end{align*}
    🔗
    🔗
    🔗

    (d)

    \(\displaystyle \int^{5}_{-5}(2x^{3}+3x^{2}+7x)\,dx\)
    🔗
    Solution.
    We can split the integrand into an odd component and an even component using the linearity properties of integration:
    \begin{equation*} \int^{5}_{-5}(2x^{3}+3x^{2}+7x)\,dx = \int^{5}_{-5}(2x^{3}+7x)\,dx + \int^{5}_{-5}3x^{2}\,dx \end{equation*}
    🔗
    The function \(g(x) = 2x^3 + 7x\) contains only odd exponents, meaning it is an odd function (\(g(-x) = -g(x)\)). Over a symmetric interval \([-5, 5]\text{,}\) its integral evaluates directly to \(0\text{.}\)
    🔗
    The remaining part, \(h(x) = 3x^2\text{,}\) is an even function. We can rewrite the problem as:
    \begin{align*} \amp = 0 + 2\int^{5}_{0}3x^{2}\,dx\\ \amp = 6 \int^{5}_{0}x^{2}\,dx\\ \amp = 6 \left[ \frac{x^3}{3} \right]^{5}_{0} = 2 \left[ x^3 \right]^{5}_{0}\\ \amp = 2(5^3 - 0) = 2(125) = 250 \end{align*}
    🔗
    🔗
    🔗
    🔗

    Example 346. Area Under a Sine Curve.

    Find the area of the region between the graph of \(y=\sin x\) and the \(x\)-axis from \(x=0\) to \(x=\pi\text{.}\)
    🔗
    Solution.
    Since \(\sin x \geq 0\) on the entire interval \([0, \pi]\text{,}\) the area \(A\) of the region is given directly by the definite integral of the function over this interval:
    \begin{equation*} A = \int_{0}^{\pi} \sin x \, dx \end{equation*}
    🔗
    The general antiderivative of \(\sin x\) is \(-\cos x\text{.}\) Applying the Fundamental Theorem of Calculus, Part 2:
    \begin{align*} A \amp = \left[ -\cos x \right]_{0}^{\pi}\\ \amp = (-\cos\pi) - (-\cos 0)\\ \amp = (-(-1)) - (-1)\\ \amp = 1 + 1 = 2 \end{align*}
    🔗
    Therefore, the area of the region under the sine curve on this interval is exactly \(2\) square units.
    🔗
    🔗
    🔗

    Checkpoint 348. Area of a Region Crossing the \(x\)-Axis.

    Find the area of the region between the graph of
    \begin{equation*} f(x)=x^{3}-3x^{2}+2x \end{equation*}
    and the \(x\)-axis from \(x=0\) to \(x=2\text{.}\)
    🔗
    Solution.
    To find the total area rather than the net displacement, we must first locate where the function crosses the \(x\)-axis by finding its roots on the interval \([0,2]\text{.}\) We factor the polynomial:
    \begin{equation*} f(x) = x(x^2 - 3x + 2) = x(x-1)(x-2) \end{equation*}
    Setting \(f(x) = 0\) gives roots at \(x = 0\text{,}\) \(x = 1\text{,}\) and \(x = 2\text{.}\)
    🔗
    We analyze the sign of the function on the resulting subintervals:
    • On \([0,1]\text{,}\) \(f(x) \geq 0\) (the curve lies above the \(x\)-axis).
      🔗
      🔗
    • On \([1,2]\text{,}\) \(f(x) \leq 0\) (the curve lies below the \(x\)-axis).
      🔗
      🔗
    Therefore, the total area \(A\) must be split into two separate definite integrals, negating the integral over the negative region:
    \begin{equation*} A = \int_{0}^{1} (x^3 - 3x^2 + 2x) \, dx - \int_{1}^{2} (x^3 - 3x^2 + 2x) \, dx \end{equation*}
    🔗
    First, we compute the general antiderivative, \(F(x)\text{:}\)
    \begin{equation*} F(x) = \int (x^3 - 3x^2 + 2x) \, dx = \frac{x^4}{4} - x^3 + x^2 \end{equation*}
    🔗
    Now, we evaluate the first integral over \([0,1]\text{:}\)
    \begin{align*} \int_{0}^{1} (x^3 - 3x^2 + 2x) \, dx \amp = \left[ \frac{x^4}{4} - x^3 + x^2 \right]_{0}^{1}\\ \amp = \left( \frac{1}{4} - 1 + 1 \right) - 0 = \frac{1}{4} \end{align*}
    🔗
    Next, we evaluate the second integral over \([1,2]\text{:}\)
    \begin{align*} \int_{1}^{2} (x^3 - 3x^2 + 2x) \, dx \amp = \left[ \frac{x^4}{4} - x^3 + x^2 \right]_{1}^{2}\\ \amp = \left( \frac{2^4}{4} - 2^3 + 2^2 \right) - \left( \frac{1}{4} - 1 + 1 \right)\\ \amp = (4 - 8 + 4) - \frac{1}{4} = 0 - \frac{1}{4} = -\frac{1}{4} \end{align*}
    🔗
    Finally, we add the absolute values of the two component areas to determine the total bounded space:
    \begin{equation*} A = \frac{1}{4} - \left(-\frac{1}{4}\right) = \frac{1}{4} + \frac{1}{4} = \frac{1}{2} \end{equation*}
    🔗
    Therefore, the total area of the region bounded between the curve and the \(x\)-axis is exactly \(\dfrac{1}{2}\) square units.
