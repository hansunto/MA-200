    Section 1.8 The Derivative as a Rate of Change

    In the previous section, we defined the derivative of a function at a point as the limit of the difference quotient. In this section, we will explore how the derivative can be interpreted as a rate of change.
    🔗
    The derivative of a function at a point gives us the instantaneous rate of change of the function at that point. This means that it tells us how fast the function is changing at that specific point. For example, if we have a function that represents the position of an object over time, the derivative of that function will give us the velocity of the object at any given time.
    🔗

    Definition 94. Tangent Line.

    The tangent line to \(y=f(x)\) at \((a,f(a))\) is the line through \((a,f(a))\) whose slope is \(f'(a)\text{,}\) the derivative of \(f\) at \(a\text{.}\)
    🔗
    🔗
    A tangent line at a point of a curve may be viewed as a geometric approximation to the curve itself. If the curve is the graph of a function \(y=f(x)\text{,}\) then we can think of the linear function defining the tangent line as an approximating function for \(f\text{.}\) If we call this linear function \(L(x)\text{,}\) then the tangent line is \(y=L(x)\text{.}\)
    🔗
    Suppose the point \(P\) lies on the graph of \(y=f(x)\text{,}\) where \(f\) is a smooth function (a function with a nice continuous derivative). We would like to find the equation of the tangent line \(y=L(x)\) at the point \(P\text{.}\) Suppose the coordinates of \(P\) are
    \begin{equation*} P = (x_0, y_0) \end{equation*}
    Since \(P\) lies on the graph of \(y = f(x)\text{,}\) we know that
    \begin{equation*} y_0 = f(x_0) \quad \text{and} \quad P = (x_0, f(x_0)) \end{equation*}
    The characteristic property of the tangent line at \(P\) is that the slope of the line is equal to the slope of the curve \(y=f(x)\) at \(P\text{,}\) which is the derivative of \(f(x)\) at \(x=x_0\text{.}\)
    🔗
    In other words, if the slope of the tangent line is \(m\text{,}\) and the equation is \(y=mx+b\text{,}\) then \(m = f'(x_0)\text{.}\) Also, \(P = (x_0, f(x_0))\) lies on the line. These two pieces of information allow us to use the “point-slope” formula to find the equation of the tangent. Equivalently, we could simply plug the coordinates of \(P\) into the equation \(y=mx+b\) and solve for \(b\text{.}\) Formally, we can say the tangent line equation is
    \begin{equation*} y = f(x_0) + f'(x_0)(x - x_0)\text{.} \end{equation*}
    🔗

    Example 95.

    Find the equation for the line tangent to \(f(x) = x^2\) at the point \((1,1)\text{.}\)
    🔗
    Solution.
    First we need to calculate \(f'(1)\text{:}\)
    \begin{equation*} f'(1) = \lim_{h\to 0}\frac{ f(1+h) - f(1)}{h} = \lim_{h\to 0}\frac{(1+h)^2 - 1^2}{h} = \lim_{h\to 0} (h + 2) \end{equation*}
    Thus, \(f'(1) = 2\text{.}\) Hence, the slope of the tangent line is \(2\text{.}\)
    🔗
    Now we will use this to find the equation of the tangent. Since the line goes through the point \((1,1)\text{,}\) \(y = mx + b\) becomes \(1 = 2(1) + b\text{,}\) so \(b = -1\text{,}\) and the equation of the tangent line is \(y=2x-1\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 96.

    Find an equation of the tangent line to the parabola \(y=x^2-5x+6\) at \(x=2\text{.}\)
    🔗
    Solution.
    First, find the \(y\)-coordinate of the point. When \(x=2\text{:}\)
    \begin{equation*} y = (2)^2 - 5(2) + 6 = 4 - 10 + 6 = 0 \end{equation*}
    So the point is \((2, 0)\text{.}\)
    🔗
    Next, find the derivative to get the slope \(m\text{:}\)
    \begin{equation*} f'(x) = 2x - 5 \end{equation*}
    At \(x=2\text{,}\) the slope is \(m = f'(2) = 2(2) - 5 = -1\text{.}\)
    🔗
    Using the point-slope formula \(y - y_0 = m(x - x_0)\text{:}\)
    \begin{equation*} y - 0 = -1(x - 2) \end{equation*}
    The equation of the tangent line is \(y = -x + 2\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 97.

    For \(f(x)=\dfrac{3}{x}\text{:}\)
    🔗
    1. Find \(f'(x)\text{.}\)
      🔗
      🔗
    2. Find an equation of the tangent line to the curve at the point \((1,3)\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    1. Using the definition of the derivative:
      \begin{equation*} f'(x) = \lim_{h \to 0} \frac{\frac{3}{x+h} - \frac{3}{x}}{h} \end{equation*}
      Finding a common denominator in the numerator:
      \begin{equation*} f'(x) = \lim_{h \to 0} \frac{3x - 3(x+h)}{x(x+h)h} = \lim_{h \to 0} \frac{-3h}{x(x+h)h} \end{equation*}
      Simplifying the \(h\text{:}\)
      \begin{equation*} f'(x) = \lim_{h \to 0} \frac{-3}{x(x+h)} = -\frac{3}{x^2} \end{equation*}
      🔗
      🔗
    2. First, find the slope at \(x=1\) using the result from part (a):
      \begin{equation*} m = f'(1) = -\frac{3}{(1)^2} = -3 \end{equation*}
      Using the point \((1,3)\) in the point-slope form \(y - y_0 = m(x - x_0)\text{:}\)
      \begin{equation*} y - 3 = -3(x - 1) \end{equation*}
      Simplifying to slope-intercept form:
      \begin{equation*} y = -3x + 6 \end{equation*}
      🔗
      🔗
    🔗
    🔗
    🔗
    Suppose an object moves along a straight line according to an equation of motion \(s(t)\text{,}\) where \(s\) is the displacement of the object from the origin at time \(t\text{.}\) The function \(s\) that describes the motion is called the position function of the object. The average velocity over the interval of time \([a, a+h]\) is
    \begin{equation*} \text{Average Velocity} = \frac{\text{Difference in distance}}{\text{Difference in time}} = \frac{s(t+h)-s(t)}{h}\text{.} \end{equation*}
    Suppose we want to compute the average velocity for the shorter time interval \([a, a+h]\) as \(h \to 0\text{.}\)
    🔗

    Instantaneous Velocity.

    We define the velocity (or instantaneous velocity) \(v(a)\) at time \(t=a\) as:
    \begin{equation*} v(a) = \lim_{h \to 0} \frac{s(a+h) - s(a)}{h} = s'(a) \end{equation*}
    🔗
    🔗

    Example 98.

    Suppose that a ball is dropped from a tower which is 450 m above the ground.
    1. What is the velocity of the ball after 5 seconds?
      🔗
      🔗
    2. How fast is the ball traveling when it hits the ground?
      🔗
      🔗
    🔗
    Answer.
    The equation of motion is \(s(t) = -4.9t^2 + 450\text{.}\) The velocity at 5 seconds is \(v(5) = -49 \text{ m/s}\text{,}\) and the speed when it hits the ground is approximately \(94 \text{ m/s}\text{.}\)
    🔗
    🔗
    Solution.
    Using the position function \(s(t) = -4.9t^2 + 450\text{,}\) we first find the velocity function by taking the derivative:
    \begin{equation*} v(t) = s'(t) = -9.8t \end{equation*}
    🔗
    1. After 5 seconds, the velocity is:
      \begin{equation*} v(5) = -9.8(5) = -49 \text{ m/s} \end{equation*}
      🔗
      🔗
    2. The ball hits the ground when \(s(t) = 0\text{:}\)
      \begin{equation*} -4.9t^2 + 450 = 0 \implies t^2 = \frac{450}{4.9} \approx 91.84 \end{equation*}
      So, \(t \approx 9.58 \text{ seconds}\text{.}\) The velocity at this time is:
      \begin{equation*} v(9.58) = -9.8(9.58) \approx -93.9 \text{ m/s} \end{equation*}
      The speed is the magnitude of velocity, approximately \(94 \text{ m/s}\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Checkpoint 100.

    A sandbag is dropped from a hot-air balloon that is hovering at a height of 512 feet above the ground. If air resistance is discarded, then the distance \(s(t)\) from the ground to the sandbag after \(t\) seconds is given by
    \begin{equation*} s(t) = -16t^2 + 512\text{.} \end{equation*}
    🔗
    Find the velocity of the sandbag at \(t=a\) and \(t=2\) seconds.
    🔗
    Solution.
    To find the velocity, we take the derivative of the position function \(s(t)\text{:}\)
    \begin{equation*} v(t) = s'(t) = \frac{d}{dt}(-16t^2 + 512) = -32t\text{.} \end{equation*}
    🔗
    At time \(t=a\text{,}\) the velocity is:
    \begin{equation*} v(a) = -32a \text{ ft/sec}\text{.} \end{equation*}
    🔗
    At time \(t=2\) seconds, the velocity is:
    \begin{equation*} v(2) = -32(2) = -64 \text{ ft/sec}\text{.} \end{equation*}
    🔗
    🔗
    🔗

    Definition 102. Rate of Change.

    Let \(y=f(x)\) where \(f\) is defined on an open interval containing \(a\text{.}\)
    1. The average rate of change of \(y=f(x)\) with respect to \(x\) on the interval \([a,a+h]\) is
      \begin{equation*} y_{av} = \frac{f(a+h)-f(a)}{h}\text{.} \end{equation*}
      🔗
      🔗
    2. The instantaneous rate of change of \(y=f(x)\) with respect to \(x\) at \(a\) is
      \begin{equation*} y_a = \lim_{h \to 0} \frac{f(a+h)-f(a)}{h}\text{,} \end{equation*}
      if the limit exists.
      🔗
      🔗
    🔗
    🔗

    Definition 103.

    The derivative \(f'(a)\) is the instantaneous rate of change of \(y=f(x)\) with respect to \(x\) at \(x=a\text{.}\)
    🔗
    🔗
    If an object is thrown into the air from a given height (in feet) \(h\text{,}\) with an initial upward velocity of \(v\text{,}\) its height above the ground at the time \(t\) is given by the following function:
    \begin{equation*} s(t) = \frac{1}{2}gt^2 + vt + h\text{,} \end{equation*}
    where \(g\) is the gravitational constant \(-32 \text{ feet/second}^2\text{.}\) This is the acceleration of an object due to gravity near the Earth’s surface. Substituting this value for \(g\) into the above equation, we obtain:
    \begin{equation*} s(t) = -16t^2 + vt + h\text{.} \end{equation*}
    🔗
    To determine how long the object will be in the air (ignoring the effects of friction and wind), set the left hand side of the equation to 0, and solve for \(t\) using the quadratic formula. We set this to 0 because \(s(t)\) is the height of the object above the ground; when the object reaches the ground, this height is 0. When the quadratic formula is used, two solutions are obtained: one positive and one negative. Since our answer refers to how long the object will be airborne, the positive root should be selected.
    🔗
    To determine the velocity of the object at a particular time \(t_0\), compute the derivative of \(s\) with respect to \(t\) and substitute \(t_0\) into \(s'(t)\text{.}\) In this case, it is important to note that the sign of the velocity determines its direction. An object moving upward has positive velocity, and an object going down has a negative velocity. The unit for velocity is feet/second.
    🔗

    Checkpoint 104.

    If an object is thrown into the air from a height of 200 feet at an initial velocity of 20 feet/second, how long is it in the air? Also, what is its velocity at \(t=3\) seconds?
    🔗
    Solution.
    Using the position function \(s(t) = -16t^2 + v_0t + h_0\) with \(v_0 = 20\) and \(h_0 = 200\text{:}\)
    \begin{equation*} s(t) = -16t^2 + 20t + 200 \end{equation*}
    🔗
    To find how long it is in the air, set \(s(t) = 0\text{:}\)
    \begin{equation*} -16t^2 + 20t + 200 = 0 \implies -4(4t^2 - 5t - 50) = 0 \end{equation*}
    Using the quadratic formula:
    \begin{equation*} t = \frac{5 \pm \sqrt{(-5)^2 - 4(4)(-50)}}{2(4)} = \frac{5 \pm \sqrt{825}}{8} \end{equation*}
    The positive root is \(t \approx 4.22\) seconds.
    🔗
    To find the velocity at \(t=3\text{,}\) take the derivative:
    \begin{equation*} v(t) = s'(t) = -32t + 20 \end{equation*}
    At \(t=3\text{:}\)
    \begin{equation*} v(3) = -32(3) + 20 = -96 + 20 = -76 \text{ ft/sec} \end{equation*}
