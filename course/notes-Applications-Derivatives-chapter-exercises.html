    Section 3. Applications of Derivatives- Chapter Exercises

    This cumulative review module provides a comprehensive synthesis of the core applications of differentiation and basic antidifferentiation methods covered throughout this chapter. Working through these exercises will help reinforce your understanding of function optimization, linear curve behavior analysis, limit evaluations, and numerical root approximations.
    🔗
    These problems mimic standard exam configurations, prompting you to determine absolute boundaries on closed domains, perform complete first and second derivative graphing tests, model dynamic rate-of-change word problems, and seamlessly switch back and forth between derivative and integral operations.
    🔗

    Exercises Exercises

    1.

    (a)
    \(f(x)=x^2-1\) on \([-1, 2]\)
    🔗
    Solution.
    First, find the critical numbers by setting the derivative to zero:
    \begin{equation*} f'(x) = 2x \implies 2x = 0 \implies x = 0 \end{equation*}
    Since \(x = 0\) is in the interval \([-1, 2]\text{,}\) evaluate \(f(x)\) at the critical number and the endpoints:
    \begin{align*} f(0) \amp = (0)^2 - 1 = -1\\ f(-1) \amp = (-1)^2 - 1 = 0\\ f(2) \amp = (2)^2 - 1 = 3 \end{align*}
    Comparing these values, the absolute minimum is \(-1\) at \(x = 0\text{,}\) and the absolute maximum is \(3\) at \(x = 2\text{.}\)
    🔗
    🔗
    🔗
    (b)
    \(g(x)=xe^{-x}\) on \([-1, 1]\)
    🔗
    Solution.
    Find the critical numbers using the product rule:
    \begin{equation*} g'(x) = 1 \cdot e^{-x} + x \cdot (-e^{-x}) = e^{-x}(1 - x) \end{equation*}
    Setting \(g'(x) = 0\) gives \(1 - x = 0 \implies x = 1\)(since \(e^{-x} \neq 0\)). Evaluate \(g(x)\) at the boundary endpoints \(x = -1\) and \(x = 1\text{:}\)
    \begin{align*} g(-1) \amp = -1 \cdot e^{-(-1)} = -e \approx -2.718\\ g(1) \amp = 1 \cdot e^{-1} = \frac{1}{e} \approx 0.368 \end{align*}
    Therefore, the absolute minimum is \(-e\) at \(x = -1\text{,}\) and the absolute maximum is \(\frac{1}{e}\) at \(x = 1\text{.}\)
    🔗
    🔗
    🔗
    🔗

    2.

    (a)
    \(y'=2x\)
    🔗
    Solution.
    Integrate using the power rule: \(y = \int 2x \, dx = x^2 + C\text{.}\)
    🔗
    🔗
    🔗
    (b)
    \(y'=\dfrac{1}{x}\)
    🔗
    Solution.
    The basic antiderivative of \(\dfrac{1}{x}\) is the natural logarithm function: \(y = \int \dfrac{1}{x} \, dx = \ln|x| + C\text{.}\)
    🔗
    🔗
    🔗
    (c)
    \(y'=3x^2+2x-1\)
    🔗
    Solution.
    Integrate term by term:
    \begin{equation*} y = \int (3x^2+2x-1) \, dx = 3\left(\frac{x^3}{3}\right) + 2\left(\frac{x^2}{2}\right) - x + C = x^3 + x^2 - x + C \end{equation*}

    3.

    Find the critical numbers of the functions.
    🔗
    (a)
    \(\displaystyle f(x)=\frac{1+\sin x}{1-\sin x}\)
    🔗
    Solution.
    Apply the quotient rule to find \(f'(x)\text{:}\)
    \begin{align*} f'(x) \amp = \frac{(\cos x)(1 - \sin x) - (1 + \sin x)(-\cos x)}{(1 - \sin x)^2}\\ \amp = \frac{\cos x - \sin x \cos x + \cos x + \sin x \cos x}{(1 - \sin x)^2} = \frac{2\cos x}{(1 - \sin x)^2} \end{align*}
    Set the numerator to zero: \(2\cos x = 0 \implies x = \dfrac{\pi}{2} + k\pi\) for any integer \(k\text{.}\) However, notice that when \(x = \frac{\pi}{2} + 2k\pi\text{,}\) \(\sin x = 1\text{,}\) causing the original function denominator to be zero (undefined).
    🔗
    Thus, the critical numbers are only where the derivative equals zero and the function is defined: \(x = \dfrac{3\pi}{2} + 2k\pi\) for \(k \in \mathbb{Z}\text{.}\)
    🔗
    🔗
    🔗
    (b)
    \(K(z)=4z^3+5z^2-42z+7\)
    🔗
    Solution.
    Differentiate and set equal to zero:
    \begin{equation*} K'(z) = 12z^2 + 10z - 42 = 2(6z^2 + 5z - 21) = 0 \end{equation*}
    Factor the quadratic binomial: \(2(2z - 3)(3z + 7) = 0\text{.}\) The critical numbers are \(z = \dfrac{3}{2}\) and \(z = -\dfrac{7}{3}\text{.}\)
    🔗
    🔗
    🔗
    (c)
    \(f(x)=\sin(x)\)
    🔗
    Solution.
    Differentiate and set to zero: \(f'(x) = \cos x = 0\text{.}\) The critical numbers occur at \(x = \dfrac{\pi}{2} + k\pi\) for all integers \(k\text{.}\)
    🔗
    🔗
    🔗
    🔗

    4.

    If \(f(x) = x^3+x^2-x-1\text{,}\) determine intervals on which the graph of \(f\) is concave up or down.
    🔗
    Solution.
    Find the first and second derivatives:
    \begin{equation*} f'(x) = 3x^2 + 2x - 1 \implies f''(x) = 6x + 2 \end{equation*}
    Set \(f''(x) = 0 \implies 6x + 2 = 0 \implies x = -\frac{1}{3}\text{.}\)
    🔗
    We test the intervals around the inflection point candidate \(x = -\frac{1}{3}\) using the sign of the second derivative:
    🔗
    Interval \(\left(-\infty, -\frac{1}{3}\right)\) \(\left(-\frac{1}{3}, \infty\right)\)
    Test Value \(x = -1\) \(x = 0\)
    Sign of \(f''(x)\) \(f''(-1) = -4 \lt 0\) \(f''(0) = 2 \gt 0\)
    Behavior / Concavity Concave Down Concave Up

    5.

    If \(f'(x) = x^4-4x^3\text{,}\) find the local extrema of \(f\text{.}\) Determine the concavity and find the point of inflection.
    🔗
    Solution.
    Find critical numbers by setting the first derivative to zero:
    \begin{equation*} f'(x) = x^4 - 4x^3 = x^3(x - 4) = 0 \implies x=0, \text{ or } x=4 \end{equation*}
    🔗
    We test the intervals around our critical numbers using the first derivative sign test:
    🔗
    Interval \((-\infty, 0)\) \((0, 4)\) \((4, \infty)\)
    Test Value \(x = -1\) \(x = 1\) \(x = 5\)
    Sign of \(f'(x)\) \(f'(-1) = 5 \gt 0\) \(f'(1) = -3 \lt 0\) \(f'(5) = 125 \gt 0\)
    Behavior of \(f(x)\) Increasing \(\nearrow\) Decreasing \(\searrow\) Increasing \(\nearrow\)
    Because the derivative changes from positive to negative at \(x = 0\text{,}\) there is a local maximum at \(x = 0\text{.}\) Because it changes from negative to positive at \(x = 4\text{,}\) there is a local minimum at \(x = 4\text{.}\)
    🔗
    Now compute the second derivative for concavity:
    \begin{equation*} f''(x) = 4x^3 - 12x^2 = 4x^2(x - 3) \end{equation*}
    Setting \(f''(x) = 0 \implies x = 0\) or \(x = 3\text{.}\) We analyze the intervals across these boundary targets:
    🔗
    Interval \((-\infty, 0)\) \((0, 3)\) \((3, \infty)\)
    Test Value \(x = -1\) \(x = 1\) \(x = 4\)
    Sign of \(f''(x)\) \(f'(-1) = -16 \lt 0\) \(f''(1) = -8 \lt 0\) \(f''(4) = 64 \gt 0\)
    Concavity Concave Down Concave Down Concave Up
    Because the concavity changes signs strictly at \(x = 3\text{,}\) the inflection point occurs at \(x = 3\text{.}\)

    6.

    For each function below, perform a full derivative analysis to analyze its graph components:
    🔗
    (a)
    \(f(x)=x^4-8x^2+1\)
    🔗
    Solution.
    First, find the critical numbers by evaluating where \(f'(x) = 0\text{:}\)
    \begin{equation*} f'(x) = 4x^3 - 16x = 4x(x^2 - 4) = 0 \implies x = 0, \, x = -2, \, \text{or } x = 2 \end{equation*}
    🔗
    We test the intervals around our critical numbers using the first derivative sign test:
    🔗
    Interval \((-\infty, -2)\) \((-2, 0)\) \((0, 2)\) \((2, \infty)\)
    Test Value \(x = -3\) \(x = -1\) \(x = 1\) \(x = 3\)
    Sign of \(f'(x)\) \(f'(-3) = -60 \lt 0\) \(f'(-1) = 12 \gt 0\) \(f'(1) = -12 \lt 0\) \(f'(3) = 60 \gt 0\)
    Behavior of \(f(x)\) Decreasing \(\searrow\) Increasing \(\nearrow\) Decreasing \(\searrow\) Increasing \(\nearrow\)
    Local minima occur at \(x = -2\) and \(x = 2\) with a value of \(-15\text{.}\) A local maximum occurs at \(x = 0\) with a value of \(1\text{.}\)
    🔗
    Next, compute the second derivative to evaluate concavity and identify inflection points:
    \begin{equation*} f''(x) = 12x^2 - 16 = 4(3x^2 - 4) = 0 \implies x = \pm \frac{2}{\sqrt{3}} \approx \pm 1.155 \end{equation*}
    🔗
    We test the intervals across these structural boundary conditions:
    🔗
    Interval \(\left(-\infty, -\frac{2}{\sqrt{3}}\right)\) \(\left(-\frac{2}{\sqrt{3}}, \frac{2}{\sqrt{3}}\right)\) \(\left(\frac{2}{\sqrt{3}}, \infty\right)\)
    Test Value \(x = -2\) \(x = 0\) \(x = 2\)
    Sign of \(f''(x)\) \(f''(-2) = 32 \gt 0\) \(f''(0) = -16 \lt 0\) \(f''(2) = 32 \gt 0\)
    Concavity Concave Up Concave Down Concave Up
    Inflection points occur at \(x = \pm \frac{2}{\sqrt{3}}\) where the coordinates are approximately \((\pm 1.16, -7.89)\text{.}\)
    🔗
    🔗
    🔗
    (b)
    \(f(x)=x^4-x^2\)
    🔗
    Solution.
    First, find the critical numbers by setting the first derivative to zero:
    \begin{equation*} f'(x) = 4x^3 - 2x = 2x(2x^2 - 1) = 0 \implies x = 0, \, x = -\dfrac{1}{\sqrt{2}} \approx -0.707, \, \text{or } x = \dfrac{1}{\sqrt{2}} \approx 0.707 \end{equation*}
    🔗
    We test the intervals around our critical numbers using the first derivative sign test:
    🔗
    Interval \(\left(-\infty, -\dfrac{1}{\sqrt{2}}\right)\) \(\left(-\dfrac{1}{\sqrt{2}}, 0\right)\) \(\left(0, \dfrac{1}{\sqrt{2}}\right)\) \(\left(\dfrac{1}{\sqrt{2}}, \infty\right)\)
    Test Value \(x = -1\) \(x = -0.5\) \(x = 0.5\) \(x = 1\)
    Sign of \(f'(x)\) \(f'(-1) = -2 \lt 0\) \(f'(-0.5) = 0.5 \gt 0\) \(f'(0.5) = -0.5 \lt 0\) \(f'(1) = 2 \gt 0\)
    Behavior of \(f(x)\) Decreasing \(\searrow\) Increasing \(\nearrow\) Decreasing \(\searrow\) Increasing \(\nearrow\)
    Local minima occur at \(x = \pm \dfrac{1}{\sqrt{2}}\) with a value of \(-\dfrac{1}{4} = -0.25\text{.}\) A local maximum occurs at \(x = 0\) with a value of \(0\text{.}\)
    🔗
    Next, compute the second derivative to evaluate concavity and identify inflection points:
    \begin{equation*} f''(x) = 12x^2 - 2 = 2(6x^2 - 1) = 0 \implies x = \pm \dfrac{1}{\sqrt{6}} \approx \pm 0.408 \end{equation*}
    🔗
    We test the intervals across these boundary conditions:
    🔗
    Interval \(\left(-\infty, -\dfrac{1}{\sqrt{6}}\right)\) \(\left(-\dfrac{1}{\sqrt{6}}, \dfrac{1}{\sqrt{6}}\right)\) \(\left(\dfrac{1}{\sqrt{6}}, \infty\right)\)
    Test Value \(x = -1\) \(x = 0\) \(x = 1\)
    Sign of \(f''(x)\) \(f''(-1) = 10 \gt 0\) \(f''(0) = -2 \lt 0\) \(f''(1) = 10 \gt 0\)
    Concavity Concave Up Concave Down Concave Up
    Inflection points occur at \(x = \pm \dfrac{1}{\sqrt{6}}\) where the coordinates are exactly \(\left(\pm \dfrac{1}{\sqrt{6}}, -\dfrac{5}{36}\right) \approx (\pm 0.41, -0.14)\text{.}\)

    7.

    A rectangle is to be inscribed in a semicircle of radius 2. What is the largest area the rectangle can have?
    🔗
    Solution.
    Let the base of the rectangle lie along the \(x\)-axis, centered at the origin, with upper vertices touching the upper semicircle equation \(y = \sqrt{4-x^2}\text{.}\) The total base width is \(2x\) and the height is \(y\text{.}\)
    \begin{equation*} A(x) = 2xy = 2x\sqrt{4-x^2} \end{equation*}
    Differentiate \(A(x)\) with respect to \(x\) using the product rule:
    \begin{equation*} A'(x) = 2\sqrt{4-x^2} + 2x \cdot \left(\dfrac{-x}{\sqrt{4-x^2}}\right) = \dfrac{2(4-x^2) - 2x^2}{\sqrt{4-x^2}} = \dfrac{8 - 4x^2}{\sqrt{4-x^2}} \end{equation*}
    Set \(A'(x) = 0 \implies 8 - 4x^2 = 0 \implies x^2 = 2 \implies x = \sqrt{2}\text{.}\) The largest area is \(A(\sqrt{2}) = 2(\sqrt{2})\sqrt{4 - 2} = 2\sqrt{2}\sqrt{2} = 4\text{.}\)
    🔗
    🔗
    🔗

    8.

    A rectangle has its base on the \(x\)-axis and its upper two vertices on the parabola \(y=12-x^2\text{.}\) What is the largest area the rectangle can have, and what are its dimensions?
    🔗
    Solution.
    The base of the rectangle spans from \(-x\) to \(x\text{,}\) giving a width of \(2x\text{.}\) The height is given by \(y = 12-x^2\text{.}\)
    \begin{equation*} A(x) = 2x(12 - x^2) = 24x - 2x^3 \end{equation*}
    Differentiate and locate critical roots:
    \begin{equation*} A'(x) = 24 - 6x^2 = 0 \implies 6x^2 = 24 \implies x^2 = 4 \implies x = 2 \end{equation*}
    The dimensions are width = \(4\) and height = \(12 - (2)^2 = 8\text{.}\) The maximum area is \(A(2) = 4 \times 8 = 32\text{.}\)
    🔗
    🔗
    🔗

    9.

    An open-top rectangular box is constructed from a 10-in.-by-10-in. piece of cardboard by cutting squares of equal side length \(x\) from the corners and folding up the sides. Find analytically the dimensions of the box of largest volume and the maximum volume.
    🔗
    Solution.
    The box length is \(10-2x\text{,}\) width is \(10-2x\text{,}\) and height is \(x\text{.}\)
    \begin{equation*} V(x) = x(10-2x)^2 = x(100 - 40x + 4x^2) = 4x^3 - 40x^2 + 100x \end{equation*}
    Find the derivative and set it to zero:
    \begin{equation*} V'(x) = 12x^2 - 80x + 100 = 4(3x^2 - 20x + 25) = 4(3x - 5)(x - 5) = 0 \end{equation*}
    This yields roots \(x = 5\) (which cuts away the entire piece of cardboard) or \(x = \dfrac{5}{3}\text{.}\) The optimal corner cut length is \(x = \dfrac{5}{3}\) in. The base dimensions are \(\dfrac{20}{3}\) in. by \(\dfrac{20}{3}\) in., creating a maximum volume of:
    \begin{equation*} V\left(\dfrac{5}{3}\right) = \dfrac{5}{3}\left(\dfrac{20}{3}\right)^2 = \dfrac{2000}{27} \approx 74.07 \text{ in}^3 \end{equation*}
    🔗
    🔗
    🔗

    10.

    Approximate \(\cos(61^\circ)\) from \(\cos(60^\circ)\) using linear approximation.
    🔗
    Solution.
    Convert values to radians: center point \(a = 60^\circ = \dfrac{\pi}{3}\text{,}\) target point \(x = 61^\circ = \dfrac{\pi}{3} + \dfrac{\pi}{180}\text{,}\) meaning \(dx = \dfrac{\pi}{180}\text{.}\) Let \(f(x) = \cos x \implies f'(x) = -\sin x\text{.}\)
    \begin{align*} f(a) \amp = \cos\left(\frac{\pi}{3}\right) = \frac{1}{2}\\ f'(a) \amp = -\sin\left(\frac{\pi}{3}\right) = -\frac{\sqrt{3}}{2} \end{align*}
    Construct the linear tangent line: \(L(x) = f(a) + f'(a)(x-a)\text{:}\)
    \begin{equation*} \cos(61^\circ) \approx \frac{1}{2} - \frac{\sqrt{3}}{2}\left(\frac{\pi}{180}\right) \approx 0.5 - 0.86603(0.01745) \approx 0.4849 \end{equation*}
    🔗
    🔗
    🔗

    11.

    Use l’Hôpital’s rule to evaluate the limit.
    🔗
    (a)
    \(\displaystyle\lim_{x\to 2}\frac{x-2}{x^2-4}\)
    🔗
    Solution.
    This yields an indeterminate form of type \(\frac{0}{0}\text{.}\) Differentiating the numerator and denominator gives:
    \begin{equation*} \lim_{x\to 2}\frac{\frac{d}{dx}(x-2)}{\frac{d}{dx}(x^2-4)} = \lim_{x\to 2}\frac{1}{2x} = \frac{1}{2(2)} = \frac{1}{4} \end{equation*}
    🔗
    🔗
    🔗
    (b)
    \(\displaystyle\lim_{x\to -3}\frac{x^3-4x+15}{x^2-x-12}\)
    🔗
    Solution.
    Direct substitution yields \(\frac{(-3)^3-4(-3)+15}{(-3)^2-(-3)-12} = \frac{0}{0}\text{.}\) Differentiate via L’Hôpital’s rule:
    \begin{equation*} \lim_{x\to -3}\frac{3x^2-4}{2x-1} = \frac{3(-3)^2-4}{2(-3)-1} = \frac{27-4}{-6-1} = -\frac{23}{7} \end{equation*}
    🔗
    🔗
    🔗
    (c)
    \(\displaystyle\lim_{x\to \infty}\frac{5x^3-2x}{7x^3+3}\)
    🔗
    Solution.
    This yields the form \(\frac{\infty}{\infty}\text{.}\) Differentiating three consecutive times or checking dominant trailing polynomial coefficients yields:
    \begin{equation*} \lim_{x\to \infty}\frac{15x^2-2}{21x^2} \implies \lim_{x\to \infty}\frac{30x}{42x} = \frac{30}{42} = \frac{5}{7} \end{equation*}
    🔗
    🔗
    🔗
    (d)
    \(\displaystyle\lim_{x\to 0^1}(1+x)^{1/x}\)
    🔗
    Solution.
    This is an indeterminate power form \(1^\infty\text{.}\) Let \(y = (1+x)^{1/x}\text{,}\) taking the natural log gives \(\ln y = \frac{\ln(1+x)}{x}\text{.}\) Evaluate the limit using L’Hôpital’s rule for \(\frac{0}{0}\text{:}\)
    \begin{equation*} \lim_{x\to 0^+}\frac{\ln(1+x)}{x} = \lim_{x\to 0^+}\frac{\frac{1}{1+x}}{1} = 1 \end{equation*}
    Since \(\lim \ln y = 1\text{,}\) raising back over base \(e\) yields \(e^1 = e\text{.}\)
    🔗
    🔗
    🔗
    🔗

    12.

    Use Newton’s method to estimate the solution of the equation \(x^2+x-1=0\text{.}\) Start with \(x_0=-1\) to find \(x_2\text{.}\)
    🔗
    Solution.
    Let \(f(x) = x^2 + x - 1 \implies f'(x) = 2x + 1\text{.}\) The iterative formula is \(x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}\text{.}\)
    \begin{align*} x_1 \amp = x_0 - \frac{f(-1)}{f'(-1)} = -1 - \frac{(-1)^2 + (-1) - 1}{2(-1) + 1} = -1 - \frac{-1}{-1} = -2\\ x_2 \amp = x_1 - \frac{f(-2)}{f'(-2)} = -2 - \frac{(-2)^2 + (-2) - 1}{2(-2) + 1} = -2 - \frac{1}{-3} = -2 + \frac{1}{3} = -\frac{5}{3} \approx -1.667 \end{align*}
    🔗
    🔗
    🔗

    13.

    Evaluate \(\displaystyle\int^2_1 \dfrac{5~dx}{x}\)
    🔗
    Solution.
    Factor out the constant and integrate:
    \begin{equation*} \int^2_1 \frac{5}{x}\,dx = 5\left[\ln|x|\right]^2_1 = 5(\ln 2 - \ln 1) = 5\ln 2 \approx 3.465 \end{equation*}
    🔗
    🔗
    🔗

    14.

    Complete the table below by filling in the missing derivative and indefinite integral formulas:
    🔗
    \(f(x)\) \(\dfrac{d}{dx}\left[f(x)\right]\) \(\qquad\qquad\) \(\displaystyle\int f(x)\,dx + C\) \(\qquad\qquad\)
    \(x^n \quad (n \neq -1)\)\(\rule{0pt}{3ex}\) \(\qquad\qquad\) \(\qquad\qquad\)
    \(\sin 2x\)\(\rule{0pt}{4ex}\)
    \(\cos 3x\)\(\rule{0pt}{4ex}\)
    \(\tan x\)\(\rule{0pt}{4ex}\)
    \(e^{-x}\)\(\rule{0pt}{4ex}\)
    Solution.
    The completed table values are evaluated as follows:
