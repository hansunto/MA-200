    Section 3.1 Extreme Values of Functions

    This section introduces the foundational concepts used to identify where functions reach their largest and smallest values.
    🔗

    Definition 219. Increasing and Decreasing Functions.

    If the graph of a function rises from left to right over an interval \(I\text{,}\) it is said to be increasing on \(I\text{.}\) If the graph of a function drops from left to right over an interval \(I\text{,}\) it is said to be decreasing on \(I\text{.}\) Let a function \(f\) be defined on an interval \(I\text{,}\) and let \(x_{1}, x_{2}\) denote numbers in \(I\text{.}\)
    🔗
    1. \(f\) is increasing on \(I\) if \(f(x_{1}) \lt f(x_{2})\) for \(x_{1} \lt x_{2}\text{.}\)
      🔗
      🔗
    2. \(f\) is decreasing on \(I\) if \(f(x_{1}) \gt f(x_{2})\) for \(x_{1} \lt x_{2}\text{.}\)
      🔗
      🔗
    3. \(f\) is constant on \(I\) if \(f(x_{1}) = f(x_{2})\) for \(x_{1} \lt x_{2}\text{.}\)
      🔗
      🔗
    🔗

    Definition 220. Maximum and Minimum Values.

    Let a function \(f\) be defined on a set \(S\) of real numbers, and let \(c\) be a number in \(S\text{.}\)
    🔗
    1. \(f(c)\) is the maximum value of \(f\) on \(S\) if \(f(x) \le f(c)\) for every \(x\) in \(S\text{.}\)
      🔗
      🔗
    2. \(f(c)\) is the minimum value of \(f\) on \(S\) if \(f(x) \ge f(c)\) for every \(x\) in \(S\text{.}\)
      🔗
      🔗
    🔗
    If \(f(c)\) is the maximum value of \(f\) on \(S\text{,}\) we say that \(f\) takes on its maximum value at \(c\text{.}\) The point \((c,f(c))\) is a highest point on the graph of \(f\text{.}\) If \(f(c)\) is the minimum value of \(f\) on \(S\text{,}\) we say that \(f\) takes on its minimum value at \(c\text{.}\) The point \((c,f(c))\) is a lowest point on the graph of \(f\text{.}\) Maximum and minimum values are sometimes called extreme values or extrema of \(f\text{.}\) If \(D\) is the domain of \(f\text{,}\) then the maximum and minimum values of \(f\) on \(D\text{,}\) if they exist, are called the absolute maximum and absolute minimum of \(f\text{.}\)
    🔗

    Example 221.

    Let \(f(x)=4-x^{2}\text{.}\) Find the extrema of \(f\) on the following intervals:
    🔗

    (a)

    (a) \([-2,1]\)
    🔗
    Solution.
    The critical point is \(x = 0\text{.}\) Evaluating key points yields \(f(0)=4\text{,}\) \(f(-2)=0\text{,}\) and \(f(1)=3\text{.}\)
    🔗
    The absolute maximum is \(4\) at \(x=0\text{.}\) The absolute minimum is \(0\) at \(x=-2\text{.}\)
    🔗
    🔗
    🔗

    (b)

    (b) \((-2,1)\)
    🔗
    Solution.
    The critical point \(x = 0\) lies inside the interval. As \(x \to -2^+\text{,}\) the function value approaches \(0\text{.}\)
    🔗
    The absolute maximum is \(4\) at \(x=0\text{.}\) There is no absolute minimum.
    🔗
    🔗
    🔗

    (c)

    (c) \((1,2]\)
    🔗
    Solution.
    No critical points lie within this interval. As \(x \to 1^+\text{,}\) the function value approaches \(3\text{.}\) At the boundary, \(f(2)=0\text{.}\)
    🔗
    There is no absolute maximum. The absolute minimum is \(0\) at \(x=2\text{.}\)
    🔗
    🔗
    🔗

    (d)

    (d) \((1,2)\)
    🔗
    Solution.
    No critical points lie within this open interval. As \(x \to 1^+\text{,}\) \(f(x) \to 3\text{,}\) and as \(x \to 2^-\text{,}\) \(f(x) \to 0\text{.}\)
    🔗
    There is no absolute maximum and no absolute minimum.
    🔗
    🔗
    🔗
    🔗

    Checkpoint 223.

    Let \(f(x)=\frac{1}{x^{2}}\text{.}\) Find the extrema of \(f\) on the following intervals:
    🔗

    (a)

    (a) \([-1,2]\)
    🔗
    Solution.
    The interval contains an infinite discontinuity at \(x = 0\text{.}\) As \(x \to 0\text{,}\) \(f(x) \to \infty\text{,}\) so there is no absolute maximum.
    🔗
    Evaluating the included endpoints gives \(f(-1) = 1\) and \(f(2) = \frac{1}{4}\text{.}\) Since the function is strictly decreasing on \((0, \infty)\text{,}\) the absolute minimum is \(\frac{1}{4}\) at \(x=2\text{.}\)
    🔗
    🔗
    🔗

    (b)

    (b) \([-1,2)\)
    🔗
    Solution.
    As in part (a), the vertical asymptote at \(x = 0\) means \(f(x) \to \infty\text{,}\) so there is no absolute maximum.
    🔗
    As \(x \to 2^-\text{,}\) \(f(x) \to \frac{1}{4}\text{.}\) Because the endpoint \(x = 2\) is excluded from this open boundary, and all other points in the interval yield values greater than \(\frac{1}{4}\text{,}\) there is no absolute minimum.
    🔗
    🔗
    🔗
    🔗

    Theorem 225. Extreme Value Theorem.

    If a function \(f\) is continuous on a closed interval \([a,b]\text{,}\) then \(f\) takes on a maximum value and a minimum value at least once in \([a,b]\text{.}\)
    🔗
    🔗
    The importance of this theorem is that it guarantee the existence of extrema if \(f\) is continuous on a closed interval. But, extrema may occur on intervals that are not closed and for functions that are not continuous.
    🔗

    Definition 226. Local Extrema.

    Let \(c\) be a number in the domain of a function \(f\text{.}\)
    1. \(f(c)\) is a local maximum of \(f\) if there exists an open interval \((a,b)\) containing \(c\) such that \(f(x)\leq f(c)\) for every \(x\) in \((a,b)\text{.}\)
      🔗
      🔗
    2. \(f(c)\) is a local minimum of \(f\) if there exists an open interval \((a,b)\) containing \(c\) such that \(f(x)\geq f(c)\) for every \(x\) in \((a,b)\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Local Extrema.

    If a function \(f\) has a local (relative) extreme value \(f(c)\) on an open interval, then \(c\) is a critical point, meaning that either:
    \begin{equation*} f'(c)=0 \quad \text{or} \quad f'(c) \text{ does not exist.} \end{equation*}
    🔗
    🔗
    Note that when we are looking for points that are relative extrema, the only points we need consider are those where the derivative is 0 or where the derivative does not exist.
    🔗

    Definition 227. Critical Point.

    A critical point of a function is an interior point \(c\) of its domain at which the tangent line to the graph at \((c,f(c))\) is horizontal or at which the derivative does not exist. That is, \(c\) is a critical point if:
    \begin{equation*} f'(c)=0 \quad \text{or} \quad f'(c) \text{ does not exist.} \end{equation*}
    🔗
    🔗

    Example 228.

    If \(f(x)=x^{3}-12x\text{,}\) find the maximum and minimum values of \(f\) on the interval \([-3,5]\) and sketch the graph of \(f\text{.}\)
    🔗
    Solution.
    First, we locate the critical points by finding the derivative of \(f(x)\text{:}\)
    \begin{equation*} f'(x) = 3x^2 - 12 \end{equation*}
    🔗
    Setting the derivative equal to zero to find the critical numbers:
    \begin{equation*} 3x^2 - 12 = 0 \implies 3(x-2)(x+2) = 0 \end{equation*}
    This yields the interior critical numbers \(x = 2\) and \(x = -2\text{.}\) Both values lie within the given closed interval \([-3,5]\text{.}\)
    🔗
    Next, we evaluate the function at the critical points and the boundary endpoints:
    • Left endpoint: \(f(-3) = (-3)^3 - 12(-3) = -27 + 36 = 9\)
      🔗
      🔗
    • Critical point: \(f(-2) = (-2)^3 - 12(-2) = -8 + 24 = 16\)
      🔗
      🔗
    • Critical point: \(f(2) = (2)^3 - 12(2) = 8 - 24 = -16\)
      🔗
      🔗
    • Right endpoint: \(f(5) = (5)^3 - 12(5) = 125 - 60 = 65\)
      🔗
      🔗
    🔗
    By comparing these values, the absolute maximum value is \(65\) occurring at the right endpoint \(x = 5\text{.}\) The absolute minimum value is \(-16\) occurring at the critical point \(x = 2\text{.}\)
    🔗
    🔗
    🔗

    Example 230.

    If \(f(x)=x^{3}\text{,}\) prove that \(f\) has no local extremum.
    🔗
    Solution.
    To find potential local extrema, we compute the first derivative of \(f(x) = x^3\text{:}\)
    \begin{equation*} f'(x) = 3x^2 \end{equation*}
    🔗
    Setting the derivative equal to zero gives our critical number:
    \begin{equation*} 3x^2 = 0 \implies x = 0 \end{equation*}
    🔗
    To determine if a local extremum exists at \(x = 0\text{,}\) we examine the behavior of \(f'(x)\) on either side of this critical number:
    • For \(x \lt 0\text{,}\) \(f'(x) = 3x^2 \gt 0\text{,}\) which means \(f\) is strictly increasing.
      🔗
      🔗
    • For \(x \gt 0\text{,}\) \(f'(x) = 3x^2 \gt 0\text{,}\) which means \(f\) is also strictly increasing.
      🔗
      🔗
    🔗
    Because \(f'(x)\) does not change sign at \(x = 0\text{,}\) the First Derivative Test confirms that the point \((0,0)\) is an inflection point rather than a local extremum. Since there are no other critical numbers, the function \(f\) has no local extremum.
    🔗
    🔗
    🔗

    Example 232.

    If \(f(x)=(x-1)^{2/3}\text{,}\) find the maximum and minimum values of \(f\) on the interval \([0,9]\) and sketch the graph of \(f\text{.}\)
    🔗
    Solution.
    First, we differentiate \(f(x)\) using the Chain Rule to locate the critical numbers:
    \begin{equation*} f'(x) = \dfrac{2}{3}(x-1)^{-1/3} = \dfrac{2}{3\sqrt[3]{x-1}} \end{equation*}
    🔗
    We analyze the derivative to discover critical points inside the interior domain \((0,9)\text{:}\)
    • The equation \(f'(x) = 0\) has no solution because the numerator is a constant (\(2 \neq 0\)).
      🔗
      🔗
    • The derivative \(f'(x)\) does not exist when the denominator equals zero: \(3\sqrt[3]{x-1} = 0 \implies x = 1\text{.}\)
      🔗
      🔗
    Since \(x = 1\) lies in the domain of \(f\text{,}\) it is our critical point. The vertical tangent profile indicates a sharp cusp point at this coordinate.
    🔗
    Next, we evaluate the function values at the critical point and the two interval boundaries:
    • Left endpoint: \(f(0) = (0-1)^{2/3} = (-1)^{2/3} = 1\)
      🔗
      🔗
    • Critical point: \(f(1) = (1-1)^{2/3} = 0^{2/3} = 0\)
      🔗
      🔗
    • Right endpoint: \(f(9) = (9-1)^{2/3} = 8^{2/3} = (\sqrt[3]{8})^2 = 2^2 = 4\)
      🔗
      🔗
    🔗
    Comparing these values, the absolute minimum value is \(0\) occurring at the critical point cusp \(x = 1\text{.}\) The absolute maximum value is \(4\) occurring at the right endpoint boundary \(x = 9\text{.}\)
    🔗
    🔗
    🔗

    Example 234.

    Find the critical numbers of \(f\) if \(\displaystyle f'(x)=\frac{(x+5)(x-2)}{x^{2}-9}\text{.}\)
    🔗
    Solution.
    By definition, a critical number of a function \(f\) must lie within the domain of \(f\) where either \(f'(x) = 0\) or \(f'(x)\) does not exist. We begin by evaluating where these conditions occur for the given rational derivative.
    🔗
    First, we find where \(f'(x) = 0\text{.}\) A fraction equals zero when its numerator equals zero, provided the denominator is non-zero:
    \begin{equation*} (x+5)(x-2) = 0 \implies x = -5 \text{ or } x = 2 \end{equation*}
    🔗
    Next, we look for values where \(f'(x)\) does not exist. A rational function fails to exist where its denominator equals zero:
    \begin{equation*} x^2 - 9 = 0 \implies (x-3)(x+3) = 0 \implies x = 3 \text{ or } x = -3 \end{equation*}
    🔗
    Because we are given the explicit formula for \(f'(x)\) without the original function \(f(x)\text{,}\) the natural domain of \(f\) must exclude the vertical asymptotes of its derivative at \(x = \pm 3\text{,}\) where the function itself is undefined. Therefore, only the values making the derivative zero qualify as interior domain critical numbers.
    🔗
    🔗
    🔗

    Checkpoint 235.

    Find the critical numbers of \(f\) if \(f(x)=x^{3}-2x+4\text{.}\)
    🔗
    Solution.
    We find the critical numbers by differentiating the polynomial function \(f(x)\text{:}\)
    \begin{equation*} f'(x) = 3x^2 - 2 \end{equation*}
    🔗
    Since \(f'(x)\) is a polynomial, it is defined everywhere. We set \(f'(x) = 0\) to find the critical numbers:
    \begin{equation*} 3x^2 - 2 = 0 \implies x^2 = \dfrac{2}{3} \implies x = \pm\sqrt{\dfrac{2}{3}} \end{equation*}
    🔗
    Both values belong to the domain of \(f\text{.}\) Thus, the critical numbers are \(x = \sqrt{\dfrac{2}{3}}\) and \(x = -\sqrt{\dfrac{2}{3}}\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 236.

    Find the critical numbers of \(f\) if \(f(x)=x\ln x\text{.}\)
    🔗
    Solution.
    The natural domain of \(f(x) = x\ln x\) is restricted to \((0, \infty)\) due to the logarithmic term. We apply the Product Rule to compute the derivative:
    \begin{equation*} f'(x) = (1)\ln x + x\left(\frac{1}{x}\right) = \ln x + 1 \end{equation*}
    🔗
    The derivative \(f'(x)\) is defined for all values in the function’s domain \((0, \infty)\text{.}\) Setting the derivative equal to zero yields:
    \begin{equation*} \ln x + 1 = 0 \implies \ln x = -1 \implies x = e^{-1} = \frac{1}{e} \end{equation*}
    🔗
    Since \(\dfrac{1}{e} \gt 0\text{,}\) it lies within the domain. Therefore, the only critical number is \(x = \dfrac{1}{e}\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 237.

    If \(f(x)=2\sin x+ \cos 2x\text{,}\) find the critical numbers of \(f\) that are in the interval \([0,2\pi]\text{.}\)
    🔗
    Solution.
    We differentiate \(f(x)\) using the Chain Rule on the second term:
    \begin{equation*} f'(x) = 2\cos x - 2\sin 2x \end{equation*}
    🔗
    Using the double-angle identity \(\sin 2x = 2\sin x\cos x\text{,}\) we rewrite the derivative equation:
    \begin{equation*} f'(x) = 2\cos x - 4\sin x\cos x = 2\cos x(1 - 2\sin x) \end{equation*}
    🔗
    The derivative exists everywhere. We locate the critical numbers inside \([0, 2\pi]\) by setting \(f'(x) = 0\text{:}\)
    \begin{equation*} 2\cos x(1 - 2\sin x) = 0 \end{equation*}
    🔗
    This produces two separate trigonometric cases to evaluate on the given interval:
    • \(\cos x = 0 \implies x = \dfrac{\pi}{2}\) or \(x = \dfrac{3\pi}{2}\)
      🔗
      🔗
    • \(1 - 2\sin x = 0 \implies \sin x = \dfrac{1}{2} \implies x = \dfrac{\pi}{6}\) or \(x = \dfrac{5\pi}{6}\)
      🔗
      🔗
    🔗
    Thus, the critical numbers in the interval \([0, 2\pi]\) are \(x = \dfrac{\pi}{6}\text{,}\) \(x = \dfrac{\pi}{2}\text{,}\) \(x = \dfrac{5\pi}{6}\text{,}\) and \(x = \dfrac{3\pi}{2}\text{.}\)
