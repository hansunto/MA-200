    Section The Derivative as a Function

    In the previous section, we defined the derivative at a point as the limit of the difference quotient. Now, we will explore how to find the derivative as a function, which gives us the rate of change at any point in the domain of the original function.
    🔗

    Definition 77. The Derivative.

    The derivative of a function \(f\text{,}\) denoted by \(f'\text{,}\) is defined by
    \begin{equation*} f'(x) = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h} \end{equation*}
    if the limit exists.
    🔗
    🔗

    Example 78.

    For \(f(x)=3x-4\text{,}\) find \(f'(x)\text{.}\)
    🔗
    Solution.
    We use the limit definition of the derivative:
    \begin{align*} f'(x) \amp = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}\\ \amp = \lim_{h \to 0} \frac{[3(x+h)-4] - (3x-4)}{h}\\ \amp = \lim_{h \to 0} \frac{3x + 3h - 4 - 3x + 4}{h}\\ \amp = \lim_{h \to 0} \frac{3h}{h}\\ \amp = \lim_{h \to 0} 3 = 3 \end{align*}
    🔗
    The derivative is \(f'(x) = 3\text{,}\) which makes sense because the slope of the line \(y = 3x - 4\) is constant at \(3\text{.}\)
    🔗
    🔗
    🔗

    Example 79.

    For \(f(x)=x^2\text{,}\) find \(f'(4)\text{.}\)
    🔗
    Solution.
    We apply the limit definition of the derivative at the point \(a=4\text{:}\)
    \begin{align*} f'(4) \amp = \lim_{h \to 0} \frac{f(4+h) - f(4)}{h}\\ \amp = \lim_{h \to 0} \frac{(4+h)^2 - 4^2}{h}\\ \amp = \lim_{h \to 0} \frac{(16 + 8h + h^2) - 16}{h}\\ \amp = \lim_{h \to 0} \frac{8h + h^2}{h}\\ \amp = \lim_{h \to 0} (8 + h)\\ \amp = 8 \end{align*}
    🔗
    Alternatively, using the \(x \to a\) form:
    \begin{align*} f'(4) \amp = \lim_{x \to 4} \frac{f(x) - f(4)}{x - 4}\\ \amp = \lim_{x \to 4} \frac{x^2 - 16}{x - 4}\\ \amp = \lim_{x \to 4} \frac{(x-4)(x+4)}{x - 4}\\ \amp = \lim_{x \to 4} (x + 4) = 8 \end{align*}
    🔗
    🔗
    🔗

    Checkpoint 80.

    For \(f(x)=x^3\text{,}\) find \(f'(x)\text{.}\) Then, evaluate \(f'(-1)\) and \(f'(1.5)\text{.}\)
    🔗
    Solution.
    First, we find the general derivative function \(f'(x)\) using the limit definition:
    \begin{align*} f'(x) \amp = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}\\ \amp = \lim_{h \to 0} \frac{(x+h)^3 - x^3}{h}\\ \amp = \lim_{h \to 0} \frac{x^3 + 3x^2h + 3xh^2 + h^3 - x^3}{h}\\ \amp = \lim_{h \to 0} \frac{3x^2h + 3xh^2 + h^3}{h}\\ \amp = \lim_{h \to 0} (3x^2 + 3xh + h^2)\\ \amp = 3x^2 \end{align*}
    🔗
    Now, we evaluate the derivative at the specific points:
    1. At \(x = -1\text{:}\) \(f'(-1) = 3(-1)^2 = 3\text{.}\)
      🔗
      🔗
    2. At \(x = 1.5\text{:}\) \(f'(1.5) = 3(1.5)^2 = 3(2.25) = 6.75\text{.}\)
      🔗
      🔗
    🔗
    🔗
    🔗

    Definition 81. Alternative definition of derivative.

    \begin{equation*} f'(a) = \lim_{x \to a} \frac{f(x)-f(a)}{x-a} \end{equation*}
    🔗
    🔗

    Example 82.

    Find the derivative of the function \(f(x)=x^2-5x+6\) at the number \(a\) using the alternative definition.
    🔗
    Solution.
    We use the alternative definition of the derivative:
    \begin{equation*} f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a} \end{equation*}
    🔗
    Substituting the function \(f(x) = x^2 - 5x + 6\text{:}\)
    \begin{align*} f'(a) \amp = \lim_{x \to a} \frac{(x^2 - 5x + 6) - (a^2 - 5a + 6)}{x - a}\\ \amp = \lim_{x \to a} \frac{x^2 - a^2 - 5x + 5a}{x - a}\\ \amp = \lim_{x \to a} \frac{(x - a)(x + a) - 5(x - a)}{x - a} \end{align*}
    🔗
    Factoring out \((x - a)\) from the numerator:
    \begin{align*} \amp = \lim_{x \to a} \frac{(x - a)(x + a - 5)}{x - a}\\ \amp = \lim_{x \to a} (x + a - 5)\\ \amp = a + a - 5 = 2a - 5 \end{align*}
    🔗
    As expected, we obtain the same result: \(f'(a) = 2a - 5\text{.}\)
    🔗
    🔗
    🔗

    Definition 83. Differentiability on a Closed Interval.

    A function f is differentiable on the closed interval \([a,b]\) if \(f\) is differentiable on the open interval \((a,b)\) and if the following limits exist:
    \begin{equation*} \lim_{h \to 0^+} \frac{f(a+h)-f(a)}{h} \quad \text{and} \quad \lim_{h \to 0^-} \frac{f(b+h)-f(b)}{h} \end{equation*}
    🔗
    🔗
    A function \(f(x)\) is said to be differentiable at a point \(x=x_0\) in its domain if the derivative \(f'(x_0)\) exists. Remember, the derivative is defined as a limit of a difference quotient as follows:
    \begin{equation*} f'(x_0) = \lim_{h\to 0} \frac{f(x_0+h) - f(x_0)}{h} \end{equation*}
    So \(f\) is differentiable at \(x=x_0\) if this limit exists. That means:
    🔗
    1. The right-hand limit \(L^+ = \lim_{h\to 0^+} \frac{f(x_0+h) - f(x_0)}{h}\) exists.
      🔗
      🔗
    2. The left-hand limit \(L^- = \lim_{h\to 0^-} \frac{f(x_0+h) - f(x_0)}{h}\) exists.
      🔗
      🔗
    3. They are equal: \(L^+ = L^-\text{.}\)
      🔗
      🔗
    If \(x_0\) is a point at which this limit fails to exist for some reason—either because the function is not continuous, one or both of the one-sided limits don’t exist, or they exist but do not match—then we say that \(x_0\) is a point of non-differentiability of \(f\text{,}\) or more simply, \(x_0\) is a singular point of \(f\text{.}\)
    🔗
    If \(f(x)\) is defined in an open interval \((a,b)\text{,}\) then we say \(f\) is differentiable in \((a,b)\) if it is differentiable at each point in the interval. Since the endpoints are not actually in the interval, we do not have to concern ourselves with them. However, if \(f\) is defined piecewise, we must check the right and left hand limits at each of the points separating adjacent intervals to verify differentiability. If either one-sided limit fails to exist or if they do not match, the point is a singularity.
    🔗

    Remark 84.

    A function is not differentiable (does not have a derivative \(f'\)) at a point \(x=a\) if any of the following occur:
    🔗
    1. The graph of \(f\) is not continuous at \(x=a\text{.}\)
      🔗
      🔗
    2. The graph of \(f\) has a vertical tangent line at \(x=a\text{;}\) that is:
      \begin{equation*} \lim_{h \to 0} |f'(x)| = \infty \end{equation*}
      🔗
      🔗
    3. The graph of \(f\) has a cusp (or a sharp corner) at \(x=a\text{.}\) This occurs if \(f\) is continuous but \(f'(x) \to \infty\) as \(x \to a\) from one side, and \(f'(x) \to -\infty\) as \(x \to a\) from the other side.
      🔗
      🔗
    🔗

    Example 85.

    Consider the piecewise function \(f\text{:}\)
    \begin{equation*} f(x) = \begin{cases} 3x - x^2 \amp \text{if } x \in (1,2] \\ 4x - x^2 - 2 \amp \text{if } x \in (2,3] \end{cases} \end{equation*}
    🔗
    Solution.
    To determine if \(x=2\) is a singularity, we check both continuity and differentiability at that point:
    🔗
    • Continuity: On the left, as \(x \to 2^-\text{,}\) \(f(x) = 3x - x^2 \to 3(2) - (2)^2 = 2\text{.}\) On the right, as \(x \to 2^+\text{,}\) \(f(x) = 4x - x^2 - 2 \to 4(2) - (2)^2 - 2 = 2\text{.}\) Since the limits match the function value \(f(2)=2\text{,}\) the function is continuous.
      🔗
      🔗
    • Differentiability: We examine the slopes of the tangent lines from each side.
      • On the left \((x \lt 2)\text{:}\) \(f'(x) = 3 - 2x\text{.}\) As \(x \to 2^-\text{,}\) \(f'(x) \to 3 - 4 = -1\text{.}\)
        🔗
        🔗
      • On the right \((x \gt 2)\text{:}\) \(f'(x) = 4 - 2x\text{.}\) As \(x \to 2^+\text{,}\) \(f'(x) \to 4 - 4 = 0\text{.}\)
        🔗
        🔗
      🔗
      🔗
    While the function values match, the slopes do not (\(-1 \neq 0\)). This creates a sharp corner in the graph as seen in Figure 86, making \(x=2\) a singularity of \(f\text{.}\)
    🔗
    🔗
    🔗

    Example 87.

    If \(f(x)=|x|\text{,}\) show that \(f\) is not differentiable at \(0\text{.}\)
    🔗
    Solution.
    To show that \(f(x) = |x|\) is not differentiable at \(x = 0\text{,}\) we must check if the limit of the difference quotient exists at that point:
    \begin{equation*} f'(0) = \lim_{h \to 0} \frac{f(0+h) - f(0)}{h} = \lim_{h \to 0} \frac{|h| - |0|}{h} = \lim_{h \to 0} \frac{|h|}{h} \end{equation*}
    🔗
    We examine the one-sided limits:
    🔗
    • From the right (\(h \to 0^+\)), \(|h| = h\text{,}\) so:
      \begin{equation*} \lim_{h \to 0^+} \frac{h}{h} = 1 \end{equation*}
      🔗
      🔗
    • From the left (\(h \to 0^-\)), \(|h| = -h\text{,}\) so:
      \begin{equation*} \lim_{h \to 0^-} \frac{-h}{h} = -1 \end{equation*}
      🔗
      🔗
    Since the left-hand and right-hand limits are not equal (\(1 \neq -1\)), the two-sided limit does not exist. Therefore, \(f(x) = |x|\) is not differentiable at \(x = 0\text{.}\) This corresponds to the sharp corner (or cusp) seen at the origin on its graph.
    🔗
    🔗
    🔗

    Example 89.

    If \(f(x)=\sqrt[3]{x}\text{,}\) show that \(f\) is not differentiable at \(0\text{.}\)
    🔗
    Solution.
    We use the limit definition of the derivative at \(x = 0\text{:}\)
    \begin{align*} f'(0) \amp = \lim_{h \to 0} \frac{f(0+h) - f(0)}{h}\\ \amp = \lim_{h \to 0} \frac{\sqrt[3]{h} - 0}{h}\\ \amp = \lim_{h \to 0} \frac{h^{1/3}}{h}\\ \amp = \lim_{h \to 0} \frac{1}{h^{2/3}} \end{align*}
    🔗
    As \(h \to 0\text{,}\) the denominator \(h^{2/3}\) is always positive (since it is a square of a cube root) and approaches \(0\text{.}\) Therefore:
    \begin{equation*} \lim_{h \to 0} \frac{1}{h^{2/3}} = \infty \end{equation*}
    🔗
    Since the limit of the difference quotient is infinite, the derivative \(f'(0)\) does not exist. Geometrically, this means the graph has a vertical tangent line at the origin, as illustrated in Figure 90.
    🔗
    🔗
    🔗

    Theorem 91.

    If \(f\) is differentiable at \(a\text{,}\) then \(f\) is continuous at \(a\text{.}\)
    🔗
    🔗

    Proof.

    Since \(f\) is differentiable at \(a\text{,}\) we know that
    \begin{equation*} f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a} \end{equation*}
    exists. To show that \(f\) is continuous at \(a\text{,}\) we must show that \(\lim_{x \to a} f(x) = f(a)\text{,}\) or equivalently, \(\lim_{x \to a} [f(x) - f(a)] = 0\text{.}\)
    🔗
    For \(x \neq a\text{,}\) we can write:
    \begin{equation*} f(x) - f(a) = \frac{f(x) - f(a)}{x - a}(x - a) \end{equation*}
    🔗
    Using the limit laws, we get:
    \begin{align*} \lim_{x \to a} [f(x) - f(a)] \amp = \lim_{x \to a} \left[ \frac{f(x) - f(a)}{x - a} (x - a) \right]\\ \amp = \left( \lim_{x \to a} \frac{f(x) - f(a)}{x - a} \right) \left( \lim_{x \to a} (x - a) \right)\\ \amp = f'(a) \cdot 0\\ \amp = 0 \end{align*}
    🔗
    Since \(\lim_{x \to a} [f(x) - f(a)] = 0\text{,}\) it follows that \(\lim_{x \to a} f(x) = f(a)\text{.}\) Therefore, by the definition of continuity, \(f\) is continuous at \(a\text{.}\)
    🔗
    🔗

    Remark 92.

    Note that the converse is not true. See the example (Example 87).
    🔗
    🔗

    Observation 93.

    When \(y\) is a function of \(x\text{,}\) \(y=f(x)\text{,}\) we will also designate the derivative,
    \begin{equation*} f'(x) = \frac{d}{dx}f(x) = \frac{dy}{dx}\text{,} \end{equation*}
    reads as “the derivative of \(y\) with respect to \(x\text{.}\)” The value of \(dy/dx\) when \(x=a\) can be denoted by
    \begin{equation*} \left.\frac{dy}{dx}\right|_{x=a} = f'(a)\text{.} \end{equation*}
