    Section Techniques for Finding Limits

    Theorem 13. Limit Principles.

    If \(\displaystyle \lim_{x \to a}f(x)=L\) and \(\displaystyle \lim_{x \to a}g(x)=M\text{,}\) then:
    1. \(\displaystyle \displaystyle \lim_{x \to a}c=c\)
      🔗
      🔗
    2. \(\displaystyle \displaystyle \lim_{x \to a}[f(x)]^n = L^n\)
      🔗
      🔗
    3. \(\displaystyle \displaystyle \lim_{x \to a}\sqrt[n]{f(x)} = \sqrt[n]{L}\)
      🔗
      🔗
    4. Sum/Difference: \(\displaystyle \lim_{x \to a}[f(x)\pm g(x)] = L \pm M\)
      🔗
      🔗
    5. Product: \(\displaystyle \lim_{x \to a}[f(x)\cdot g(x)] = L \cdot M\)
      🔗
      🔗
    6. Quotient: \(\displaystyle \lim_{x \to a}\frac{g(x)}{f(x)} = \frac{M}{L}\text{,}\) if \(L \neq 0\)
      🔗
      🔗
    7. \(\displaystyle \displaystyle \lim_{x \to a}cf(x) = c \cdot L\)
      🔗
      🔗
    8. If \(f\) is a polynomial, \(\displaystyle \lim_{x \to a}f(x)=f(a)\)
      🔗
      🔗
    9. If \(r\) is a rational function, \(\displaystyle \lim_{x \to a}r(x)=r(a)\) (where defined)
      🔗
      🔗
    🔗
    🔗
    We can therefore use ordinary substitution and algebraic simplification, such as canceling out common factors in the numerator and denominator of a rational function, to help us determine limits.
    🔗

    Example 14. Limit by Direct Substitution.

    Find \(\displaystyle\lim_{x\to 2}\frac{x^3+1}{2x}\text{.}\)
    🔗
    Solution.
    By direct substitution: to calculate this limit we "plug in" 2 in place of \(x\) to get:
    \begin{equation*} \lim_{x\to 2}\frac{x^3+1}{2x} = \frac{2^3+1}{2(2)} = \frac{9}{4}\text{.} \end{equation*}
    🔗
    🔗
    🔗

    Example 15. Limit by Factoring.

    Find \(\displaystyle\lim_{x\to -3}\frac{x+3}{x^2-9}\text{.}\)
    🔗
    Solution.
    Here, when we "plug in" -3 we get \(0/0\text{.}\) We factor the denominator: this means that -3 is a root of both the numerator and the denominator. Hence we can factor out \(x-(-3) = x+3\) from both the numerator and the denominator to get:
    \begin{equation*} \lim_{x\to -3}\frac{x+3}{(x+3)(x-3)} = \lim_{x\to -3}\frac{1}{x-3} = \frac{1}{-3-3} = -\frac{1}{6}\text{.} \end{equation*}
    🔗
    🔗
    🔗

    Example 16. Limit involving Square Roots.

    If \(f(x)= \frac{x-9}{\sqrt{x}-3}\text{,}\) find \(\displaystyle\lim_{x \to 9} f(x)\text{.}\)
    🔗
    Solution.
    Factoring the numerator as a difference of squares:
    \begin{equation*} \lim_{x \to 9} \frac{(\sqrt{x}-3)(\sqrt{x}+3)}{\sqrt{x}-3} = \lim_{x \to 9} (\sqrt{x}+3) = \sqrt{9}+3 = 6\text{.} \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 17. Mixed Limit Practice.

    Find the following limits:
    1. \(\displaystyle \displaystyle \lim_{x \to 2}(x^4-5x^3+x^2-7)\)
      🔗
      🔗
    2. \(\displaystyle \displaystyle \lim_{x \to 0}\sqrt{x^2-3x+2}\)
      🔗
      🔗
    3. \(\displaystyle \displaystyle \lim_{x \to -3}\frac{x^2-9}{x+3}\)
      🔗
      🔗
    🔗
    Solution.
    1. \(\displaystyle 2^4 - 5(2^3) + 2^2 - 7 = 16 - 40 + 4 - 7 = -27\)
      🔗
      🔗
    2. \(\displaystyle \sqrt{0^2 - 3(0) + 2} = \sqrt{2}\)
      🔗
      🔗
    3. \(\displaystyle \lim_{x \to -3} \frac{(x-3)(x+3)}{x+3} = \lim_{x \to -3} (x-3) = -6\)
      🔗
      🔗
    🔗
    🔗
    🔗

    Checkpoint 18. Limit of a Piecewise Function.

    Find \(\displaystyle\lim_{x\to 1} g(x)\) where
    \begin{equation*} g(x)=\begin{cases} x+1 \amp \text{if } x \neq 1 \\ \pi \amp \text{if } x=1 \end{cases} \end{equation*}
    🔗
    Solution.
    The limit depends only on values near 1, not at \(x=1\text{.}\) As \(x \to 1\text{,}\) \(g(x) = x+1\text{.}\) Thus, the limit is \(1+1=2\text{.}\)
    🔗
    🔗

    Exercises Limits Practice

    1.

    Evaluate \(\displaystyle \lim_{h \rightarrow 0}\frac{4-\sqrt{16+h}}{h}\)
    🔗
    Solution.
    Direct substitution results in the indeterminate form \(0/0\text{.}\) We rationalize the numerator by multiplying by the conjugate:
    \begin{equation*} \lim_{h \to 0} \frac{4-\sqrt{16+h}}{h} \cdot \frac{4+\sqrt{16+h}}{4+\sqrt{16+h}} = \lim_{h \to 0} \frac{16-(16+h)}{h(4+\sqrt{16+h})} \end{equation*}
    Simplifying the numerator gives \(-h\text{,}\) which allows us to cancel the \(h\) in the denominator:
    \begin{equation*} \lim_{h \to 0} \frac{-h}{h(4+\sqrt{16+h})} = \lim_{h \to 0} \frac{-1}{4+\sqrt{16+h}} = -\frac{1}{8} \end{equation*}
    🔗
    🔗
    🔗

    2.

    Evaluate \(\displaystyle \lim_{x \rightarrow 5^+}(\sqrt{x^2-25}+3)\)
    🔗
    Solution.
    Since we are approaching 5 from the right (\(x > 5\)), the term \(x^2 - 25\) is a small positive number. We can evaluate this by direct substitution:
    \begin{equation*} \sqrt{5^2-25}+3 = \sqrt{0}+3 = 3 \end{equation*}
    🔗
    🔗
    🔗

    3.

    Evaluate \(\displaystyle \lim_{h \rightarrow 0}\left(\frac{1}{h}\right)\left(\frac{1}{\sqrt{1+h}}-1\right)\)
    🔗
    Solution.
    First, find a common denominator for the second term:
    \begin{equation*} \frac{1}{h} \left( \frac{1 - \sqrt{1+h}}{\sqrt{1+h}} \right) \end{equation*}
    Now multiply by the conjugate \(1 + \sqrt{1+h}\text{:}\)
    \begin{equation*} \lim_{h \to 0} \frac{1-(1+h)}{h\sqrt{1+h}(1+\sqrt{1+h})} = \lim_{h \to 0} \frac{-h}{h\sqrt{1+h}(1+\sqrt{1+h})} \end{equation*}
    Canceling \(h\) and substituting \(h=0\) gives \(\frac{-1}{1(1+1)} = -1/2\text{.}\)
    🔗
    🔗
    🔗

    4.

    Evaluate \(\displaystyle \lim_{x \rightarrow 1}\left(\frac{x^2}{x-1}-\frac{1}{x-1}\right)\)
    🔗
    Solution.
    Combine the fractions over the common denominator:
    \begin{equation*} \lim_{x \to 1} \frac{x^2-1}{x-1} \end{equation*}
    Factor the difference of squares:
    \begin{equation*} \lim_{x \to 1} \frac{(x-1)(x+1)}{x-1} = \lim_{x \to 1} (x+1) = 2 \end{equation*}
    🔗
    🔗
    🔗

    5.

    Evaluate \(\displaystyle \lim_{x \rightarrow 1} \frac{x-1}{\sqrt{x+3}-2}\)
    🔗
    Solution.
    Multiply by the conjugate of the denominator, \(\sqrt{x+3}+2\text{:}\)
    \begin{equation*} \lim_{x \to 1} \frac{(x-1)(\sqrt{x+3}+2)}{(x+3)-4} = \lim_{x \to 1} \frac{(x-1)(\sqrt{x+3}+2)}{x-1} \end{equation*}
    Canceling \(x-1\) leaves \(\sqrt{1+3}+2 = 4\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Theorem 20. Sandwich Theorem (Squeeze Theorem).

    Suppose \(f(x) \leq h(x) \leq g(x)\) near \(a\) (except possibly at \(a\)). If \(\displaystyle \lim_{x \to a}f(x)=L=\lim_{x \to a}g(x)\text{,}\) then \(\displaystyle \lim_{x \to a}h(x)=L\text{.}\)
    🔗
    🔗

    Example 21. Proving a Limit with Sandwich Theorem.

    Prove \(\displaystyle \lim_{x \to 0}x^2\sin\left(\frac{1}{x^2}\right)=0\text{.}\)
    🔗
    Solution.
    Since \(-1 \leq \sin(\theta) \leq 1\text{,}\) we have:
    \begin{equation*} -1 \leq \sin\left(\frac{1}{x^2}\right) \leq 1 \end{equation*}
    Multiply by \(x^2\) (which is always \(\geq 0\)):
    \begin{equation*} -x^2 \leq x^2\sin\left(\frac{1}{x^2}\right) \leq x^2 \end{equation*}
    Since \(\lim_{x \to 0}(-x^2) = 0\) and \(\lim_{x \to 0}(x^2) = 0\text{,}\) by the Sandwich Theorem, the limit is 0.
    🔗
    🔗
    🔗

    Checkpoint 22.

    Find \(\displaystyle\lim_{x\to 0} |x|\) by using the Sandwich Theorem.
    🔗
    Solution.
    For any real number \(x\text{,}\) we know the absolute value is bounded by:
    \begin{equation*} -|x| \le x \le |x| \end{equation*}
    To squeeze \(|x|\) specifically, we use the fact that:
    \begin{equation*} 0 \le |x| \le |x| \end{equation*}
    More formally, observe that for all \(x\) in the interval \((-1, 1)\text{:}\)
    \begin{equation*} 0 \le |x| \le \sqrt{x^2} \end{equation*}
    Since \(\displaystyle\lim_{x \to 0} 0 = 0\) and \(\displaystyle\lim_{x \to 0} \sqrt{x^2} = 0\text{,}\) by the Sandwich Theorem:
    \begin{equation*} \lim_{x \to 0} |x| = 0 \end{equation*}
