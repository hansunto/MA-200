    Section 4.1 Area and Summation Notations

    In development of the definite integral we shall employ sums of many numbers. To express such sums compactly, it is convenient to use summation notation.
    🔗

    Definition 309. Summation Notation.

    Given a collection of numbers \(\{a_{1},a_{2}, \dots, a_{n}\},\) the symbol \(\sum^{n}_{k=1}a_{k}\) represents the sum and is written as
    \begin{equation*} \displaystyle \sum^{n}_{k=1}a_{k}=a_{1}+a_{2}+ \dots+ a_{n} \end{equation*}
    🔗
    🔗

    Example 310.

    Evaluate \(\displaystyle \sum^{4}_{k=1}k(k-3)\)
    🔗
    Solution.
    We expand the summation by substituting the values \(k = 1, 2, 3, 4\) into the expression:
    🔗
    \begin{align*} \sum^{4}_{k=1}k(k-3) \amp = 1(1-3) + 2(2-3) + 3(3-3) + 4(4-3)\\ \amp = 1(-2) + 2(-1) + 3(0) + 4(1)\\ \amp = -2 - 2 + 0 + 4\\ \amp = 0 \end{align*}
    🔗
    🔗
    🔗

    Example 311.

    Evaluate \(\displaystyle \sum^{3}_{k=0}\frac{2^{k}}{(k+1)}\)
    🔗
    Solution.
    We expand the summation by substituting the values \(k = 0, 1, 2, 3\) into the expression:
    🔗
    \begin{align*} \sum^{3}_{k=0}\frac{2^{k}}{(k+1)} \amp = \frac{2^{0}}{0+1} + \frac{2^{1}}{1+1} + \frac{2^{2}}{2+1} + \frac{2^{3}}{3+1}\\ \amp = \frac{1}{1} + \frac{2}{2} + \frac{4}{3} + \frac{8}{4}\\ \amp = 1 + 1 + \frac{4}{3} + 2\\ \amp = 4 + \frac{4}{3} = \frac{16}{3} \end{align*}
    🔗
    🔗
    🔗

    Theorem 312. Properties of Summation.

    If \(n\) is any positive integer and \(\{a_{1},a_{2}, \dots, a_{n}\}\) and \(\{b_{1},b_{2}, \dots, b_{n}\}\) are sets of real numbers, then:
    🔗
    1. \(\displaystyle \displaystyle \sum^{n}_{k=1}(a_{k}\pm b_{k})=\displaystyle \sum^{n}_{k=1}a_{k}\pm \displaystyle \sum^{n}_{k=1}b_{k}\)
      🔗
      🔗
    2. \(\displaystyle \sum^{n}_{k=1}ca_{k}=c\left(\displaystyle \sum^{n}_{k=1}a_{k}\right)\) for every real number \(c\)
      🔗
      🔗
    3. \(\displaystyle \displaystyle \sum^{n}_{k=1}c=nc\)
      🔗
      🔗
    🔗
    🔗

    Theorem 313. Standard Summation Formulas.

    1. \(\displaystyle \displaystyle \sum^{n}_{k=1}k=1+2+ \dots +n=\frac{n(n+1)}{2}\)
      🔗
      🔗
    2. \(\displaystyle \displaystyle \sum^{n}_{k=1}k^{2}=1^{2}+2^{2}+ \dots +n^{2}=\frac{n(n+1)(2n+1)}{6}\)
      🔗
      🔗
    3. \(\displaystyle \displaystyle \sum^{n}_{k=1}k^{3}=1^{3}+2^{3}+ \dots +n^{3}=\left[\frac{n(n+1)}{2}\right]^{2}\)
      🔗
      🔗
    🔗
    🔗

    Example 314.

    Evaluate \(\displaystyle \sum^{100}_{k=1}k\) and \(\displaystyle \sum^{20}_{k=1}k^{2}\text{.}\)
    🔗
    Solution.
    For the first sum, we apply the identity \(\sum_{k=1}^{n} k = \dfrac{n(n+1)}{2}\) with \(n = 100\text{:}\)
    \begin{equation*} \sum^{100}_{k=1}k = \dfrac{100(101)}{2} = 50 \cdot 101 = 5050 \end{equation*}
    🔗
    For the second sum, we apply the identity \(\sum_{k=1}^{n} k^2 = \dfrac{n(n+1)(2n+1)}{6}\) with \(n = 20\text{:}\)
    \begin{equation*} \sum^{20}_{k=1}k^{2} = \dfrac{20(21)(41)}{6} = \dfrac{17220}{6} = 2870 \end{equation*}
    🔗
    🔗
    🔗

    Example 315.

    Express \(\displaystyle \sum^{n}_{k=1}(k^{2}-4k+3)\) in terms of \(n.\)
    🔗
    Solution.
    We first split the sum using linearity properties:
    \begin{equation*} \sum^{n}_{k=1}(k^{2}-4k+3) = \sum^{n}_{k=1}k^{2} - 4\sum^{n}_{k=1}k + \sum^{n}_{k=1}3 \end{equation*}
    🔗
    Substituting the standard summation formulas yields:
    \begin{align*} \amp = \frac{n(n+1)(2n+1)}{6} - 4\left(\frac{n(n+1)}{2}\right) + 3n\\ \amp = \frac{2n^3 + 3n^2 + n}{6} - 2n(n+1) + 3n\\ \amp = \frac{2n^3 + 3n^2 + n}{6} - 2n^2 - 2n + 3n\\ \amp = \frac{2n^3 + 3n^2 + n}{6} - \frac{12n^2}{6} + \frac{6n}{6}\\ \amp = \frac{2n^3 - 9n^2 + 7n}{6}\\ \amp = \frac{n(2n-7)(n-1)}{6} \end{align*}
    🔗
    🔗
    🔗

    Checkpoint 316. Equivalence of Index Shifts.

    Which formula is not equivalent to the other two?
    🔗
    \begin{align*} \sum^{4}_{k=2}\frac{(-1)^{k-1}}{k-1} \amp\qquad \sum^{2}_{k=0}\frac{(-1)^{k}}{k+1} \amp\qquad \sum^{1}_{k=-1}\frac{(-1)^{k}}{k+2} \end{align*}
    Solution.
    We expand each summation term by term to compare their values:
    🔗
    1. First sum (let \(S_1\)): For \(k=2,3,4\text{,}\) we get:
      \begin{equation*} S_1 = \frac{(-1)^{2-1}}{2-1} + \frac{(-1)^{3-1}}{3-1} + \frac{(-1)^{4-1}}{4-1} = \frac{-1}{1} + \frac{1}{2} + \frac{-1}{3} = -1 + \frac{1}{2} - \frac{1}{3} \end{equation*}
      🔗
      🔗
    2. Second sum (let \(S_2\)): For \(k=0,1,2\text{,}\) we get:
      \begin{equation*} S_2 = \frac{(-1)^{0}}{0+1} + \frac{(-1)^{1}}{1+1} + \frac{(-1)^{2}}{2+1} = \frac{1}{1} + \frac{-1}{2} + \frac{1}{3} = 1 - \frac{1}{2} + \frac{1}{3} \end{equation*}
      🔗
      🔗
    3. Third sum (let \(S_3\)): For \(k=-1,0,1\text{,}\) we get:
      \begin{equation*} S_3 = \frac{(-1)^{-1}}{-1+2} + \frac{(-1)^{0}}{0+2} + \frac{(-1)^{1}}{1+2} = \frac{-1}{1} + \frac{1}{2} + \frac{-1}{3} = -1 + \frac{1}{2} - \frac{1}{3} \end{equation*}
      🔗
      🔗
    🔗
    Comparing the terms shows that \(S_1 = S_3 = -\frac{5}{6}\text{,}\) while \(S_2 = \frac{5}{6}\text{.}\) Therefore, the second formula, \(\sum^{2}_{k=0}\frac{(-1)^{k}}{k+1}\text{,}\) is not equivalent to the other two.
    🔗
    🔗
    🔗

    Checkpoint 317. Linearity Properties of Sums.

    Suppose that \(\displaystyle\sum^{n}_{k=1}a_{k}=-5\) and \(\displaystyle\sum^{n}_{k=1}b_{k}=6\text{.}\) Find the value of:
    \begin{equation*} \displaystyle\sum^{n}_{k=1}(2a_{k}-3b_{k}+1) \end{equation*}
    🔗
    Solution.
    Using the linearity properties of summation notation, we split the target expression into three separate sums:
    \begin{equation*} \sum^{n}_{k=1}(2a_{k}-3b_{k}+1) = 2\sum^{n}_{k=1}a_{k} - 3\sum^{n}_{k=1}b_{k} + \sum^{n}_{k=1}1 \end{equation*}
    🔗
    We are given the values for the first two sums, and we know that summing a constant \(c\) from \(1\) to \(n\) results in \(nc\) (here, \(n \cdot 1 = n\)). Substituting these values gives:
    \begin{align*} \amp = 2(-5) - 3(6) + n\\ \amp = -10 - 18 + n\\ \amp = n - 28 \end{align*}
    🔗
    🔗
    🔗

    Checkpoint 318. Simplifying Cube Identities.

    Evaluate the sum:
    \begin{equation*} \displaystyle\sum^{5}_{k=1}\frac{k^{3}}{225}-\left(\sum^{5}_{k=1}k\right)^{3} \end{equation*}
    🔗
    Solution.
    First, we factor out the constant from the first summation and compute the inner sum of the second term:
    \begin{equation*} \frac{1}{225}\left(\sum^{5}_{k=1}k^{3}\right) - \left(\sum^{5}_{k=1}k\right)^{3} \end{equation*}
    🔗
    Using the formulas \(\sum_{k=1}^n k = \dfrac{n(n+1)}{2}\) and \(\sum_{k=1}^n k^3 = \left[\dfrac{n(n+1)}{2}\right]^2\) for \(n=5\text{:}\)
    \begin{equation*} \sum^{5}_{k=1}k = \frac{5(6)}{2} = 15 \end{equation*}
    \begin{equation*} \sum^{5}_{k=1}k^{3} = (15)^2 = 225 \end{equation*}
    🔗
    Substituting these evaluated pieces back into our original expression yields:
    \begin{align*} \amp = \frac{1}{225}(225) - (15)^3\\ \amp = 1 - 3375\\ \amp = -3374 \end{align*}
    🔗
    🔗
